# 📁 Project Management

FloWorks saves your flows in files with the **`.sflow`** extension. These files contain all project information: nodes, connections, configuration and sticky notes.

---

## Create, open and save

| Action | Menu | Shortcut |
|--------|------|----------|
| **New project** | File → New | `Ctrl + N` |
| **Open project** | File → Open | `Ctrl + O` |
| **Save** | File → Save | `Ctrl + S` |
| **Save as…** | File → Save as… | `Ctrl + Shift + S` |

**Golden Rule:**
Flows are **fully compatible across all versions** of FloWorks (Core, Lite, Pro). You do not need to convert or modify anything: just open and run.

---

## Export and import

- To **share a flow**, copy the `.sflow` file to another computer.
- To **bring in an external flow**, use **File → Open** and select the file.
- If you need to **export numerical data** (for example, to CSV), use the **Spreadsheet** tool in the side panel and save the table from there.

---

## Recovery from unexpected shutdowns

FloWorks **does not auto-save**. That is why it is important to:

- Save frequently (`Ctrl + S`), especially before running flows with real hardware.
- If the application closes unexpectedly, unsaved changes may be lost.
- To work with total peace of mind, get used to saving after every important modification.

---

## Recommended organization

- Create one folder per project or client, and save all related `.sflow` files there.
- Use **sticky notes** inside the canvas to document sections of the flow.
- Assign **descriptive names to nodes** (double-click → name) so it is easier to find and understand the flow weeks later.

---

## Good practices

- Before running a flow with real instruments, save the file.
- If you work in a team, use a version control system (Git, manual copies) so you do not overwrite important flows.
- Make backups of critical calibration or diagnostic flows.

---

> **Tip:** A well-organized and saved flow is the foundation of professional work in FloWorks. Do not underestimate the power of a clear name and an orderly folder.
