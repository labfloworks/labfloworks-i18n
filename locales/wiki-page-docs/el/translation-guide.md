# 🌐 Οδηγός Διεθνοποίησης (i18n)

Το παρόν έγγραφο εξηγεί πώς να προσθέσετε μια νέα γλώσσα στο FloWorks και να διαχειρίζεστε αποτελεσματικά τα αρχεία μετάφρασης.

---

## ➕ Πώς να Προσθέσετε μια Νέα Γλώσσα

### Βήμα 1: Δημιουργία του Αρχείου JSON
Μεταβείτε στον φάκελο `locales/`. Αντιγράψτε το `en.json` και μετονομάστε το χρησιμοποιώντας τον αντίστοιχο δύο γραμμάτων κωδικό [ISO 639-1](https://el.wikipedia.org/wiki/ISO_639-1) (π.χ. `fr.json` για γαλλικά, `de.json` για γερμανικά).

### Βήμα 2: Μετάφραση των Συμβολοσειρών
Ανοίξτε το νέο αρχείο JSON σε έναν επεξεργαστή κειμένου.

!!! warning "Μην Τροποποιείτε τα Κλειδιά"
    **Μην αλλάζετε ποτέ τα κλειδιά** (την αριστερή πλευρά κάθε ζεύγους). Μεταφράστε μόνο τις τιμές (τη δεξιά πλευρά).

**Πρωτότυπο (`en.json`):**
```json
{
  "app_title": "FloWorks",
  "menu": {
    "file": "File",
    "edit": "Edit"
  }
}
```

**Μεταφρασμένο Παράδειγμα (`es.json`):**
```json
{
  "app_title": "FloWorks",
  "menu": {
    "file": "Archivo",
    "edit": "Editar"
  }
}
```
Βεβαιωθείτε ότι η ριζική κλειδί `"language_name"` περιέχει την εγχώρια ονομασία της γλώσσας (π.χ. `"Français"`, `"Deutsch"`, `"Español"`).

### Βήμα 3: Επικύρωση JSON
Επαληθεύστε ότι το αρχείο είναι έγκυρο JSON (χωρίς τελικές κόμμες, σωστά εισαγωγικά, κατάλληλα escapes). Μπορείτε να χρησιμοποιήσετε online επαληθευτές όπως το [JSONLint](https://jsonlint.com) ή να εκτελέσετε:
```bash
python -m json.tool locales/es.json
```

### Βήμα 4: Δοκιμή της Νέας Γλώσσας
1. Εκκινήστε το FloWorks.
2. Μεταβείτε σε **INFO → Γλώσσα** και επιλέξτε τη νέα γλώσσα.
3. Επαληθεύστε ότι όλα τα στοιχεία της διεπαφής ενημερώνονται άμεσα (μενού, πάνελ, διάλογοι, ετικέτες κόμβων κ.λπ.).

### Βήμα 5: Αυτόματος Εντοπισμός (Προαιρετικό)
Αν η τοπική ρύθμιση του συστήματος του χρήστη συμπίπτει με τον κωδικό της νέας γλώσσας, το FloWorks θα τη χρησιμοποιήσει αυτόματα στην πρώτη εκκίνηση (εφόσον δεν έχει αποθηκευτεί προηγούμενη προτίμηση στα `QSettings`).

---

## 🌍 Διαθέσιμες Γλώσσες
- **Αγγλικά** (`en`) – Βασική / εφεδρική γλώσσα
- **Ισπανικά** (`es`)

---

## ⚙️ Σημαντικές Σημειώσεις και Καλές Πρακτικές

!!! info "Μηχανισμός Εφεδρείας"
    Η βασική γλώσσα είναι τα **αγγλικά**. Αν λείπει ένα κλειδί μετάφρασης σε ένα αρχείο γλώσσας, το FloWorks χρησιμοποιεί αυτόματα το αγγλικό κείμενο ως εφεδρεία.

!!! warning "Πρόληψη Υπερχείλισης UI"
    Διατηρήστε τις μεταφράσεις συνοπτικές για να αποφύγετε σπασίματα στη σχεδίαση. Αν ένα μεταφρασμένο κείμενο είναι σημαντικά μεγαλύτερο, σκεφτείτε να το συντομεύσετε ή να βασιστείτε στο σύστημα θεμάτων για δυναμική κλιμάκωση.

!!! tip "Διατήρηση HTML και Placeholders"
    - **Ετικέτες HTML:** Διατηρήστε όλες τις ετικέτες HTML ακριβώς όπως είναι (π.χ. `<h3>`, `<b>`, `<pre>`, `<br>`).
    - **Placeholders:** Διατηρήστε τη σύνταξη `{variable}` όπου χρησιμοποιείται (π.χ. `"Idioma cambiado a: {name} ({code})"`). Μην τα αναδιατάξετε ή τα αφαιρέσετε.
