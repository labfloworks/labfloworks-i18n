# 📊 Οδηγός υπολογιστικού φύλλου

Βασικό υπολογιστικό φύλλο σε στυλ Excel, ελαφρύ και ενσωματώσιμο.

---

## 1. Τι είναι το Spreadsheet;

Είναι μια συνιστώσα υπολογιστικού φύλλου που προσφέρει:

- Κελιά με υποστήριξη τύπων (ξεκινούν με `=`)
- Προκαθορισμένες συναρτήσεις (SUM, AVERAGE, ΣΥΝΘΗΚΗ, κ.λπ.)
- Αριθμητικούς, λογικούς και συγκριτικούς τελεστές
- Μινιμαλιστική διεπαφή, ιδανική για ενσωμάτωση σε εφαρμογές Qt

---

## 2. Βασική πλοήγηση

- Κάντε κλικ σε ένα κελί για να το επιλέξετε.
- Πληκτρολογήστε απευθείας για να εισαγάγετε κείμενο ή αριθμούς.
- Για να γράψετε **τύπο**, ξεκινήστε με `=` (π.χ. `=SUM(A1:A5)`).
- Πατήστε **Enter** για επιβεβαίωση της επεξεργασίας.
- Χρησιμοποιήστε τα βελάκια ή το ποντίκι για μετακίνηση.

---

## 3. Τύποι: διαθέσιμες συναρτήσεις

Όλες οι συναρτήσεις γράφονται με κεφαλαία και υποστηρίζουν εύρη (π.χ. `A1:A5`) ή ορίσματα χωρισμένα με κόμμα.

| Συνάρτηση | Τι κάνει | Παράδειγμα |
| ---------- | -------- | ---------- |
| `SUM` | Αθροίζει αριθμούς | `=SUM(A1:A5)` |
| `AVG` / `AVERAGE` | Μέσος όρος | `=AVG(A1:A5)` |
| `COUNT` | Μετρά αριθμούς (όχι κενά) | `=COUNT(A1:A5)` |
| `MAX` | Μέγιστη τιμή | `=MAX(A1:A5)` |
| `MIN` | Ελάχιστη τιμή | `=MIN(A1:A5)` |
| `ABS` | Απόλυτη τιμή | `=ABS(A1)` |
| `ROUND` | Στρογγυλοποίηση (2ο όρισμα = δεκαδικά) | `=ROUND(A1, 2)` |
| `IF` | Συνθήκη (αν, τότε, αλλιώς) | `=IF(A1>10, "Ναι", "Όχι")` |
| `CONCAT` / `CONCATENATE` | Ενώνει κείμενα | `=CONCAT(A1, " ", B1)` |
| `LEN` | Μήκος κειμένου | `=LEN(A1)` |
| `INT` | Ακέραιο μέρος | `=INT(A1)` |
| `SQRT` | Τετραγωνική ρίζα | `=SQRT(A1)` |

### 3.1. Σημειώσεις για τις συναρτήσεις

- Τα εύρη υποδεικνύονται με **άνω-κάτω τελεία**: `A1:A5` περιλαμβάνει όλα τα κελιά από A1 έως A5.
- Οι συναρτήσεις μπορούν να εμφωλευθούν: `=SUM(A1:A5) + MAX(B1:B5)`.
- Τα ορίσματα κειμένου πρέπει να είναι μέσα σε διπλά ή μονά εισαγωγικά.

---

## 4. Τελεστές χωρίς συναρτήσεις

Εκτός από συναρτήσεις, μπορείτε να χρησιμοποιήσετε τελεστές απευθείας στον τύπο. Η σύνταξη είναι παρόμοια με την Python.

### 4.1. Αριθμητκοί

| Πράξη | Παράδειγμα |
| ------- | ---------- |
| Πρόσθεση | `=A1+A2+A3` |
| Αφαίρεση | `=A1-A2` |
| Πολλαπλασιασμός | `=A1*B1` |
| Διαίρεση | `=A1/B1` |
| Υπόλοιπο | `=A1%B1` |
| Δύναμη | `=A1**2` (ή `=A1^2`) |

### 4.2. Συγκρίσεις

Επιστρέφουν `True` ή `False` (εμφανίζονται ως `Αληθής` / `Ψευδής`).

| Τελεστής | Σημασία | Παράδειγμα |
| -------- | ------- | ---------- |
| `>` | Μεγαλύτερο από | `=A1>B1` |
| `<` | Μικρότερο από | `=A1<B1` |
| `>=` | Μεγαλύτερο ή ίσο | `=A1>=10` |
| `<=` | Μικρότερο ή ίσο | `=A1<=10` |
| `==` | Ίσο | `=A1==B1` |
| `!=` | Διάφορο | `=A1!=B1` |

### 4.3. Λογικοί και συνθετικοί

Μπορείτε να συνδυάσετε συνθήκες με `and`, `or`, `not`.

```excel
= A1>5 and B1<10
= not(A1==0)
= 10 if A1>5 else 0
```

Ο τριαδικός τελεστής `if` `else` υποστηρίζεται επίσης απευθείας.

---

## 5. Πρακτικά παραδείγματα

### 5.1. Άθροισμα πωλήσεων

Υποθέστε ότι έχετε πωλήσεις στο `B2:B10` και θέλετε το σύνολο:

```excel
=SUM(B2:B10)
```

### 5.2. Προϋποθετική έκπτωση

Αν το σύνολο (στο `B12`) υπερβαίνει το 100, εφαρμόστε έκπτωση 10%· αλλιώς 0:

```excel
= IF(B12>100, B12*0.9, B12)
```

### 5.3. Μέσος όρος και μέτρηση

Μέσος όρος βαθμών στο `C2:C20`, αλλά μόνο αν υπάρχουν τουλάχιστον 5 τιμές:

```excel
= IF(COUNT(C2:C20)>=5, AVG(C2:C20), "Μη επαρκή δεδομένα")
```

### 5.4. Συνδυασμένο κείμενο

Ένωση ονόματος (A2) και επωνύμου (B2) με κενό:

```excel
= CONCAT(A2, " ", B2)
```

### 5.5. Τετραγωνική ρίζα αριθμού

```excel
= SQRT(A1)
```

### 5.6. Στρογγυλοποίηση σε 2 δεκαδικά

```excel
= ROUND(A1, 2)
```

---

## 6. Συμβουλς και κόλπα

- **Σχετικές/απόλυτες αναφορές:** προς το παρόν, όλες οι αναφορές είναι σχετικές (όπως στο Excel). Το `$A$1` δεν υποστηρίζεται ακόμη.
- **Δυναμικά εύρη:** μπορείτε να χρησιμοποιήσετε εύρη όπως `A:A` (ολόκληρη στήλη) ή `1:1` (ολόκληρη γραμμή).
- **Αυτόματη συμπλήρωση:** κατά την πληκτρολόγηση `=`, εμφανίζεται μενού με διαθέσιμες συναρτήσεις.
- **Σφάλματα:** αν ένας τύπος είναι άκυρος, το κελί εμφανίζει `#ERROR` και το λεπτομερές μήνυμα στη γραμμή κατάστασης.
- **Επαναϋπολογισμός:** οι τύποι ενημερώνονται αυτόματα κατά την τροποποίηση εξαρτημένων κελιών.
