# Αυτοκόλλητα σημειώματα (Sticky Notes) – Οδηγός χρήστη

## Τι είναι τα αυτοκόλλητα σημειώματα;

Τα αυτοκόλλητα σημειώματα (ή *sticky notes*) είναι μικρά μπλοκ κειμένου που μπορείτε να τοποθετήσετε ελεύθερα πάνω στο διάγραμμα. Χρησιμεύουν για να:

- Προσθέτετε υπενθυμίσεις, τίτλους ή επεξηγήσεις απευθείας στον Καμβά.
- Δημιουργείτε οδηγούς βήμα προς βήμα που καθοδηγούν τον χρήστη του έργου σας.
- Τεκμηριώνετε τμήματα της ροής εργασίας χωρίς να χρειάζεται να βγείτε από το FloWorks.
- Αφήνετε σχόλια για τον εαυτό σας ή για άλλους συνεργάτες.

Τα σημειώματα μπορούν να αλλάξουν μέγεθος (σύροντας τις γωνίες τους), να μετακινηθούν οπουδήποτε στο διάγραμμα και αποθηκεύονται μαζί με το έργο. Κατά το άνοιγμα ενός αρχείου `.sflow`, όλα τα σημειώματα εμφανίζονται ακριβώς εκεί που τα αφήσατε.

---

## Το νέο: πολύγλωσσα σημειώματα

Τα αυτοκόλλητα σημειώματα μπορούν να εμφανίζουν αυτόματα το κείμενο στη γλώσσα που επιλέγετε για την εφαρμογή.  
Αντί να γράψετε το τελικό μήνυμα σε μία μόνο γλώσσα, μπορείτε να εισαγάγετε **ειδικούς δείκτες** που θα μεταφραστούν αυτόματα όταν αλλάζετε γλώσσα στο FloWorks.

Έτσι, το ίδιο σημείωμα μπορεί να διαβαστεί στα ισπανικά, στα αγγλικά ή σε οποιαδήποτε άλλη διαθέσιμη γλώσσα χωρίς να χρειάζεται να επεξεργάζεστε το κείμενο κάθε φορά.

---

## Πώς να γράψετε ένα πολύγλωσσο σημείωμα

Μέσα σε ένα σημείωμα (δημιουργήστε το με διπλό κλικ ή με το κουμπί 📝 στη Γραμμή εργαλείων), μπορείτε να χρησιμοποιήσετε δύο τύπους δεικτών:

### 1. Με τη λέξη `tr(…)`
Γράψτε `tr("κλειδί")` και αντικαταστήστε το `κλειδί` με ένα περιγραφικό όνομα της φράσης.

Παράδειγμα:

```
tr("tutorial.paso1.titulo")
tr("tutorial.paso1.mensaje")
```

### 2. Με διπλές αγκύλες `{{…}}`
Γράψτε `{{κλειδί}}` με τον ίδιο τρόπο.

Παράδειγμα:

```
{{tutorial.paso1.titulo}}
{{tutorial.paso1.mensaje}}
```

Κι οι δύο μορφές λειτουργούν με τον ίδιο τρόπο· επιλέξτε αυτή που σας βολεύει (μπορείτε ακόμη και να τις συνδυάσετε στο ίδιο σημείωμα).

> **Σημαντικό**: Το κείμενο που βλέπετε κατά την επεξεργασία του σημειώματος περιέχει τους αρχικούς δείκτες (π.χ. `{{tutorial.paso1.titulo}}`).  
> Όταν ολοκληρώσετε την επεξεργασία και επιστρέψετε στην κανονική προβολή του διαγράμματος, οι δείκτες αντικαθίστανται από τη φράση μεταφρασμένη στην τρέχουσα γλώσσα της εφαρμογής.

---

## Συμπεριφορά κατά την αλλαγή γλώσσας

- Εάν αλλάξετε γλώσσα από το μενού του FloWorks (π.χ. από ισπανικά σε γγλικά), **όλα τα αυτοκόλλητα σημειώματα που περιέχουν δείκτες ενημερώνονται αυτόματα**.
- Δεν χρειάζεται να κλείσετε και να ανοίξετε ξανά το έργο, ούτε να επεξεργαστείτε χειροκίνητα κάθε σημείωμα.
- Τα σημειώματα που περιέχουν μόνο κανονικό κείμενο (χωρίς δείκτες) δεν επηρεάζονται· εμφανίζουν το ίδιο σε κάθε γλώσσα.

---

## Πλεονεκτήματα της χρήσης δεικτών

- **Στιγμιαίοι πολύγλωσσοι οδηγοί** – Ένα μόνο σημείωμα μπορεί να καθοδηγήσει χρήστες διαφορετικών γλωσσών.
- **Συνέπεια** – Εάν τροποποιήσετε τη μετάφραση σε ένα μόνο σημείο (το αρχείο γλωσσών που συντηρεί η ομάδα ανάπτυξής σας), όλα τα σημειώματα που χρησιμοποιούν αυτό το κλειδί θα νημερωθούν.
- **Εύκολη συντήρηση** – Μπορείτε να γράψετε το περιεχόμενο μία φορά και να το επαναχρησιμοποιήσετε σε πολλά σημειώματα.
- **Ευελιξία** – Συνδυάστε σταθερό κείμενο με δείκτες. Για παράδειγμα:

```
🎯 ΒΗΜΑ 1
{{tutorial.paso1.titulo}}
{{tutorial.paso1.mensaje}}
```

---

## Πρακτικό παράδειγμα: οδηγός βήμα προς βήμα

Υποθέστε ότι θέλετε να προσθέσετε ένα σημείωμα που εξηγεί το πρώτο βήμα ενός οδηγού.  
Σε λειτουργία επεξεργασίας γράφετε:

```
🎯 ΒΗΜΑ 1
{{tutorial.paso1.titulo}}
{{tutorial.paso1.mensaje}}
```

Μετά την ολοκλήρωση της επεξεργασίας και χρησιμοποιώντας την εφαρμογή στα ισπανικά, θα δείτε:

```
🎯 PASO 1
¡Bienvenido a FloWorks!
Arrastre un nodo fuente de señal para comenzar.
```

Εάν αλλάξετε γλώσσα σε αγγλικά, το ίδιο σημείωμα θα εμφανίσει:

```
🎯 STEP 1
Welcome to FloWorks!
Drag a signal source node to begin.
```

Και ούτω καθεξής για οποιαδήποτε άλλη διαμορφωμένη γλώσσα.

---

## Περίληψη

- Τα αυτοκόλλητα σημειώματα εμπλουτίζουν τα διαγράμματά σας με πληροφορίες κειμένου.
- Τώρα μπορούν να είναι **πολύγλωσσα** χρησιμοποιώντας τους δείκτες `tr("κλειδί")` ή `{{κλειδί}}`.
- Κατά την επεξεργασία βλέπετε τα κλειδιά· κατά την προβολή, το μεταφρασμένο κείμενο.
- Αλλάξτε τη γλώσσα της εφαρμογής και όλα τα σημειώματα προσαρμόζονται αμέσως.
- Ιδανικά για τη δημιουργία οπτικής τεκμηρίωσης, οδηγών ή ειδοποιήσεων που πρέπει να λειτουργούν σε πολλές γλσσες.

Αξιοποιήστε αυτή τη λειτουργικότητα για να κάνετε τα έργα σας πιο προσβάσιμα και ευκολότερα κοινοποιήσιμα!
