# 🧪 Διαδραστικό σεμινάριο κονσόλας FloWorks

Καλώς ήρθατε στο πειραματικό εργαστήριο του FloWorks. Αυτή η ενότητα απευθύνεται σε πιο προχωρημένους χρήστες· πρόκειται για ένα τερματικό **Python** για τον έλεγχο όλων όσων σχετίζονται με τον καμβά, δηλαδή των κόμβων και των συνδέσεών τους, με σειριακό τρόπο και μέσω γραμμών κώδικα. Είναι ένα τερματικό συνδεδεμένο με το πρόγραμμα που μπορεί να το ελέγξει και να καθορίσει συμπεριφορές ή ρουτίνες για πιο απαιτητικούς χρήστες.

Αυτός ο οδηγός θα σας δείξει **βήμα προς βήμα** πώς να ελέγχετε και να αναλύετε τα διαγράμματα ροής σας χωρίς να αγγίζετε το ποντίκι. Κάθε παράδειγμα έχει επαληθευτεί στην διαδραστική κονσόλα και αντανακλά την πραγματική δομή δεδομένων του προγράμματος.

## 1. Γνωρίζοντας το έδαφος

Η κονσόλα εγχέει τρία καθολικ αντικείμενα: `app` (κύριο παράθυρο), `graph` (σκηνή/διάγραμμα) και `selected_node` (ο κόμβος που είναι επιλεγμένος αυτήν τη στιγμή στον καμβά). Όλες οι εντολές ξεκινούν από αυτά τα τρία.

### Προβολή όλων των κόμβων

```python
>>> graph.nodes
```

**Παράδειγμα εξόδου:**
```
Κόμβοι στη σκηνή:
  [0] Προηγμένος Γεννήτρια Σήματος (τύπος: SignalSourceNode, κατηγορία: Sources)
  [1] FFT (τύπος: FFTNode, κατηγορία: Processing)
```

Ο δείκτης μέσα σε αγκύλες (`[0]`, `[1]`) είναι ο κύριος τρόπος πρόσβασης σε έναν κόμβο. Η σειρά είναι αυτή της δημιουργίας στον καμβά.

#### Εναλλακτικό: μέτρηση κόμβων ή φιλτράρισμα κατά τύπο

```python
>>> len(graph.nodes)
>>> [n for n in graph.nodes if 'FFT' in type(n).__name__]
```

### Προβολή όλων των συνδέσεων

```python
>>> graph.connections
```

**Παράδειγμα εξόδου:**
```
Συνδέσεις στη σκηνή:
  [0] Προηγμένος Γεννήτρια Σήματος (out) → FFT (input)
```

Η έξοδος δείχνει το όνομα του κόμβου πηγής, τη θύρα εξόδου, το βέλος, τον κόμβο προορισμού και τη θύρα εισόδου. Αν μια σύνδεση δεν εμφανίζεται, η ροή δεν μπορεί να εκτελεστεί.

#### Εναλλακτικό: προβολή συνδέσεων ενός μόνο κόμβου

```python
>>> selected_node.connectors
```

### Προβολή του επιλεγμένου κόμβου

Κάντε κλικ σε έναν κόμβο στον καμβά και στη συνέχεια εκτελέστε:

```python
>>> selected_node
```

**Παράδειγμα εξόδου:**
```
Κόμβος: FFT
  Τύπος: FFTNode
  Κατηγορία: Processing
  Θύρες: ['input', 'output', 'magnitude', 'phase']
```

> **💡 Σημείωση:** Αν δεν είναι επιλεγμένος κανένας κόμβος, το `selected_node` έχει τιμή `None`. Η επιλογή ενός κόμβου ενημερώνει επίσης αυτόματα τον πλευρικό πίνακα παραμέτρων.

#### Εναλλακτικό: επιλογή κόμβου μέσω κώδικα

```python
>>> graph.nodes[0].setSelected(True)
>>> app.console.update_namespace(selected_node=graph.nodes[0])
```

## 2. Χειρισμός κόμβων και συνδέσεων χωρίς ποντίκι

### Δημιουργία νέου κόμβου

Πρέπει να γνωρίζετε το ακριβές όνομα της κλάσης του κόμβου (όπως στον κατάλογο). Τα ορίσματα είναι: `(τύπος, x, y)`.

```python
>>> graph.add_catalog_node('SumNode', 300, 200)
```

Ο κόμβος εμφανίζεται στον καμβά στις συντεταγμένες (300, 200). Αν δεν γνωρίζετε το ακιβές όνομα, απαριθμήστε τις κατηγορίες (δείτε ενότητα 7).

#### Εναλλακτικό: δημιουργία πολλαπλών κόμβων ταυτόχρονα

```python
>>> for i, typos in enumerate(['SignalSourceNode', 'FFTNode', 'OscilloscopeNode']):
...     graph.add_catalog_node(typos, 100 + i*200, 300)
```

### Χειροκίνητη σύνδεση κόμβων

Σύνταξη: `graph.connect_nodes(πηγή, προορισμός, 'θύρα_εξόδου', 'θύρα_εισόδου')`. Οι θύρες εξαρτώνται από κάθε κόμβο· μην υποθέτετε ποτέ τα ονόματά τους.

```python
>>> graph.connect_nodes(graph.nodes[0], graph.nodes[2], 'output', 'port_a')
```

> **💡 Σημείωση:** Ελέγχετε πάντα `graph.nodes[N].PORTS` πριν συνδέσετε. Ένας κόμβος FFT έχει `'input'` και `'magnitude'`· ένας γεννήτριας έχει `'output'`.

#### Εναλλακτικό: σύνδεση στην προεπιλεγμένη θύρα

Αν δεν γνωρίζετε το ακριβές όνομα της θύρας εισόδου, ορισμένοι κόμβοι δέχονται `None` για να χρησιμοποιήσουν την πρώτη διαθέσιμη:

```python
>>> graph.connect_nodes(graph.nodes[0], graph.nodes[2], 'output', None)
```

### Διαγραφή κόμβου

```python
>>> graph.remove_node(graph.nodes[2])
```

Διαγράφει τον κόμβο και όλες τις συσχετισμένες συνδέσεις. Οι δείκτες στο `graph.nodes` αναδιατάσσονται, οπότε μην κρατάτε παλιές αναφορές.

#### Εναλλακτικό: διαγραφή όλων των κόμβων μιας κατηγορίας

```python
>>> for n in list(graph.nodes):
...     if n.META.get('category') == 'Processing':
...         graph.remove_node(n)
```

### Προβολή θυρών ενός κόμβου

```python
>>> graph.nodes[1].PORTS
```

**Παράδειγμα εξόδου:**
```
{'input': ('left', 0.5), 'output': ('right', 0.25), 'magnitude': ('right', 0.5), 'phase': ('right', 0.75)}
```

Το κλειδί είναι το όνομα της θύρας (string). Η τιμή είναι μια πλειάδα με τη θέση οπτικοποίησης. Μόνο τα κλειδιά σας ενδιαφέρουν για σύνδεση.

#### Εναλλακτικό: προβολή θυρών ως απλή λίστα

```python
>>> list(graph.nodes[1].PORTS.keys())
```

## 3. Εκτέλεση ροής και προβολή αποτελεσμάτων

### Εκτέλεση ολόκληρου του γράφου

```python
>>> graph.execute_flow()
```

Αυτή η μέθοδος ανήκει στο διάγραμμα (`graph`), όχι στο κύριο παράθυρο. Διασχίζει όλους τους κόμβους σε τοπολογική σειρά, εκτελεί τον καθένα και αποθηκεύει τα αποτελέσματα στην cache. Δεν επιστρέφει τίποτα· τα δεδομένα παραμέουν εσωτερικά αποθηκευμένα.

#### Εναλλακτικό: εξαναγκασμός υπολογισμού συγκεκριμένου κλάδου

```python
>>> result = graph.get_node_branch_value(graph.nodes[1])
```

Αυτό επαναυπολογίζει ολόκληρο το δέντρο ανάντη του υποδεικνυόμενου κόμβου και επιστρέφει το αποτέλεσμα απευθείας, χωρίς να τροποποιεί την καθολική cache.

### Προβολή cached δεδομένων ενός κόμβου

Αν χρειάζεστε πρόσβαση στα επεξεργασμένα δεδομένα ενός συγκεκριμένου κόμβου, μπορείτε να το κάνετε με δύο τρόπους:

#### Άμεσος τρόπος (ανά αντικείμενο)
```python
>>> graph.node_values[graph.nodes[1]]
```

**Παράδειγμα εξόδου:**
```
{'output': None, 'magnitude': (array([0., 78.125, ...]), array([0.0013, 0.0183, ...])), 'phase': (array([0., 78.125, ...]), array([0., 0.687, ...]))}
```

> **⚠️ Προειδοποίηση:** Αυτή η μορφή μπορεί να αποτύχει με `KeyError` αν η σειρά των κόμβων στη σκηνή άλλαξε (π.χ. με διαγραφή ή προσθήκη κόμβων) ή αν το στιγμιότυπο του αντικειμένου δεν ταιριάζει ακριβώς με το κλειδί που είναι αποθηκευμένο στο λεξικό.

#### Εναλλακτικός τρόπος (ανά θέση)
```python
>>> list(graph.node_values.values())[1]
```

Αυτή η μορφή είναι **πιο σταθερή** επειδή δεν εξαρτάται από την ακριβή ταυτότητα του αντικειμένου. Η σειρά των τιμών ακολουθεί τη σειρά με την οποία οι κόμβοι εκτελέστηκαν κατά την τελευταία `graph.execute_flow()`. Ο δείκτης `[1]` αντιστοιχεί στον δεύτερο κόμβο σε αυτή τη σειρά.

> **💡 Σημείωση:** Αν θέλετε να δείτε τον δείκτη κάθε κόμβου στη σειρά εκτέλεσης, μπορείτε να χρησιμοποιήσετε:
> ```python
> >>> list(graph.node_values.keys())
> ```

> **⚠️ Προσοχή:** Το `graph.node_values` δεν επιστρέφει πάντα απευθείας έναν πίνακα. Για κόμβους επεξεργασίας (FFT, φίλτρα κ.λπ.) επιστρέφει ένα **λεξικό** όπου κάθε κλειδί είναι μια θύρα εξόδου. Για κόμβους πηγής, επιστρέφει μια πλειάδα `(x, y)`.

#### Εναλλακτικό: προβολή δεδομένων όλων των κόμβων σε μία γραμμή
```python
>>> {n.name: type(v).__name__ for n, v in graph.node_values.items()}
```

### Πρόσβαση στον άξονα Υ ενός κόμβου πηγής

Οι κόμβοι γεννήτριας (SignalSourceNode, FileInputNode κ.λπ.) επιστρέφουν μια πλειάδα `(χρόνος, σήμα)` κατά την εκτέλεση. Για να πάρετε μόνο τον άξονα Υ:

```python
>>> result = graph.get_node_branch_value(graph.nodes[0])
>>> y = result[1]
>>> y.max()
```

**Παράδειγμα εξόδου:**
```
Scalar NumPy (float64): 1.0
```

#### Εναλλακτικό: λήψη άξονα Χ (χρόνος)

```python
>>> x = result[0]
>>> x[:5]
```

### Αναθέσεις σε Python: μια ζωτικής σημασίας λεπτομέρεια

Στην Python, οι αναθέσεις (`=`) είναι **δηλώσεις**, όχι εκφράσεις. Η κονσόλα δεν τυπώνει τίποτα μετά από `x, y = ...` επειδή δεν υπάρχει τιμή επιστροφής.

```python
>>> x, y = graph.get_node_branch_value(graph.nodes[0])
```

Για να επαληθεύσετε ότι λειτούργησε, αξιολογήστε τη μεταβλητή στην επόμενη γραμμή:

```python
>>> x
>>> y.shape
```

Ή χρησιμοποιήστε `;` για να αλυσιδώσετε μια έκφραση στην ίδια γραμμή:

```python
>>> x, y = graph.get_node_branch_value(graph.nodes[0]); y.max()
```

Ή χρησιμοποιήστε ρητό `print()`:

```python
>>> x, y = graph.get_node_branch_value(graph.nodes[0]); print(y.max())
```

## 4. Σχεδίαση στο κύριο γράφημα

### Καθαρισμός γραφήματος

```python
>>> app.plot_widget.clear_plot()
```

#### Εναλλακτικό: καθαρισμός και άμεση επανασχεδίαση

```python
>>> app.plot_widget.clear_plot(); graph.execute_flow()
```

### Σχεδίαση αυθαίρετου σήματος από την κονσόλα

Μπορείτε να δημιουργήσετε πίνακες με NumPy και να τους στείλετε απευθείας στο widget σχεδίασης, χωρίς να περάσετε από κανέναν κόμβο.

```python
>>> import numpy as np
>>> x = np.linspace(0, 1, 1000)
>>> y = np.sin(2 * np.pi * 10 * x)
>>> app.plot_widget.plot_waveform(x, y)
```

#### Εναλλακτικό: σχεδίαση αθροίσματος ημιτόνων

```python
>>> y = np.sin(2*np.pi*5*x) + 0.3*np.sin(2*np.pi*50*x) + 0.1*np.random.randn(1000)
>>> app.plot_widget.plot_waveform(x, y)
```

### Σχεδίαση αποτελέσματος κόμβου πηγής

Επειδή ο κόμβος πηγής επιστρέφει `(x, y)`, μπορείτε να το αποσυσκευάσετε απευθείας:

```python
>>> x, y = graph.get_node_branch_value(graph.nodes[0])
>>> app.plot_widget.plot_waveform(x, y)
```

### Σχεδίαση αποτελέσματος κόμβου FFT (πολλαπλές θύρες)

Οι κόμβοι με πολλαπλές εξόδους (FFT, ανάλυση χρόνου-συχνότητας κ.λπ.) δεν επιστρέφουν απλή πλειάδα. Επιστρέφουν `dict`, όπου κάθε κλειδί είναι μια θύρα εξόδου.

```python
>>> result = graph.get_node_branch_value(graph.nodes[1])
>>> result.keys()
```

**Παράδειγμα εξόδου:**
```
dict_keys(['output', 'magnitude', 'phase'])
```

Παρατηρήστε ότι το `'output'` μπορεί να είναι `None` αν ο κόμβος δεν έχει γενική θύρα. Οι χρήσιμες έξοδοι είναι `'magnitude'` και `'phase'`, οι οποίες με τη σειρά τους είναι πλειάδες `(συχνότητες, τιμές)`:

```python
>>> f, mag = result['magnitude']
>>> app.plot_widget.plot_waveform(f, mag)
```

#### Εναλλακτικό: σχεδίαση φάσης αντί μέτρου

```python
>>> f, phase = result['phase']
>>> app.plot_widget.plot_waveform(f, phase)
```

#### Εναλλακτικό: επικάλυψη δύο σημάτων

```python
>>> x1, y1 = graph.get_node_branch_value(graph.nodes[0])
>>> app.plot_widget.plot_waveform(x1, y1)
>>> x2, y2 = graph.get_node_branch_value(graph.nodes[2])  # άλλος κόμβος
>>> app.plot_widget.plot_waveform(x2, y2)  # επικαλύπτεται
```

> **💡 Σημείωση:** Αν προσπαθήσετε να κάνετε `x, y = result` με dict, η Python θα εγείρει `ValueError: too many values to unpack`. Ελέγχετε πάντα με `type(result)` και `result.keys()` πριν το αποσυσκευάσετε.

## 6. Πλοήγηση και παραγωγικότητα στην κονσόλα

Η κονσόλα δεν είναι απλώς `print()`. Έχει ιστορικό, αυτόματη συμπλήρωση και πολυγραμμικά μπλοκ.

| Πλήκτρο / Εντολή           | Ενέργεια                                                         |
|---------------------------|----------------------------------------------------------------|
| `↑` / `↓`                 | Πλοήγηση στο ιστορικό εντολών που εκτελέστηκαν                |
| `Tab`                     | Αυτόματη συμπλήρωση μεταβλητών, χαρακτηριστικών και μεθόδων του namespace     |
| `Ctrl + L`                | Εκκαθάριση ολόκληρης της κονσόλας (διαγράφει κείμενο, όχι την κατάσταση Python)  |
| `if`, `for`, `def`, `class` | Το prompt αλλάζει από `>>>` σε `...` για πολυγραμμικά μπλοκ     |
| `Ctrl+C` (σε επιλογή)   | Αντιγραφή κειμένου από την κονσόλα                                     |
| `Ctrl+A`                  | Επιλογή όλου του περιεχομένου                                  |

> **💡 Σημείωση:** Η αυτόματη συμπλήρωση χρησιμοποιεί `rlcompleter` και αναγνωρίζει ολόκληρο το εγχυμένο namespace (`app`, `graph`, `selected_node`) συν οποιαδήποτε μεταβλητή ορίσετε στη συνεδρία.

## 7. Προχωρημένες συνταγές

### Αλλαγή εσωτερικής παραμέτρου κόμβου

Οι παράμετροι των κόμβων δεν είναι επίπεδα χαρακτηριστικά. Είναι εμφωλιασμένοι μέσα στο λεξικό `params`, το οποίο με τη σειρά του έχει υποενότητες όπως `'preset'`, `'formula'` ή `'advanced'`. Μην κάνετε ποτέ `komvos.amplitude = 3.0`· αυτό δημιουργεί ένα νέο χαρακτηριστικό στο αντικείμενο, αλλά δεν τροποποιεί την πραγματική παράμετρο.

#### Περίπτωση Α: τροποποίηση preset (ημίτονο, τετράγωνο κ.λπ.)

```python
>>> selected_node.params['mode'] = 'preset'
>>> selected_node.params['preset']['type'] = 'SINE'
>>> selected_node.params['preset']['amplitude'] = 2.0
>>> selected_node.params['preset']['frequency'] = 1000.0
>>> selected_node._generate_signal()
>>> graph.execute_flow()
```

#### Περίπτωση Β: χρήση προσαρμοσμένου τύπου

```python
>>> selected_node.params['mode'] = 'formula'
>>> selected_node.params['formula']['expr'] = '2 * sin(2*pi*1000*t)'
>>> selected_node.params['formula']['vars'] = {'amp': 2.0, 'freq': 1000.0, 'offset': 0.0}
>>> selected_node._generate_signal()
>>> graph.execute_flow()
```

Η έκφραση χρησιμοποιεί `t` ως μεταβλητή χρόνου. Οι τιμές στο `vars` είναι τα σύμβολα στα οποία μπορείτε να αναφερθείτε στον τύπο. Αν παραλείψετε το `vars`, ο κόμβος θα χρησιμοποιήσει προεπιλεγμένες τιμές και ο τύπος μπορεί να μην αντικατοπτρίζει την αλλαγή.

#### Περίπτωση Γ: αλλαγή προχωρημένων παραμέτρων (ρυθμός δειγματοληψίας, διάρκεια)

```python
>>> selected_node.params['advanced']['duration'] = 0.02
>>> selected_node.params['advanced']['sample_rate'] = 44100
>>> selected_node._generate_signal()
>>> graph.execute_flow()
```

#### Περίπτωση Δ: αλλαγή παραμέτρου μη γεννήτριας κόμβου (π.χ. FFT)

```python
>>> selected_node.params['window'] = 'hann'
>>> graph.execute_flow()
```

> **💡 Σημείωση:** Το `getattr(obj, '_generate_signal', lambda: None)()` είναι ένα ασφαλές μοτίβο: αν η μέθοδος υπάρχει (κόμβοι γεννήτριες), την καλεί· αν όχι, δεν κάνει τίποτα και δεν εγείρει σφάλμα. Για κόμβους επεξεργασίας, αρκεί μόνο το `graph.execute_flow()`.

### Καταχώρηση όλων των διαθέσιμων κατηγοριών κόμβων

Η εισαγωγή φορτώνει τον κατάλογο, αλλά δεν τον εμφανίζει αυτόματα. Θυμηθείτε ότι στην Python μια επιτυχημένη εισαγωγή δεν τυπώνει τίποτα· πρέπει να αξιολογήσετε το αντικείμενο.

```python
>>> from nodes.node_catalog import NODE_CATEGORIES
>>> NODE_CATEGORIES
```

Για μια ευανάγνωστη περίληψη:

```python
>>> for cat, komvoi in NODE_CATEGORIES.items():
...     print(f"{cat}: {len(komvoi)} komvoi")
```

#### Εναλλακτικό: καταχώρηση ονομάτων κόμβων ανά κατηγορία

```python
>>> {cat: [n.__name__ for n in komvoi] for cat, komvoi in NODE_CATEGORIES.items()}
```

### Προβολή βοήθειας οποιασδήποτε μεθόδου

```python
>>> help(graph.connect_nodes)
```

Το docstring εμφανίζεται απευθείας στην κονσόλα. Είναι χρήσιμο για να ανακαλύψετε ποια ορίσματα περιμένει μια μέθοδος χωρίς να ανοίξετε τον πηγαίο κώδικα.

#### Εναλλακτικό: προβολή φιλτραρισμένων χαρακτηριστικών

```python
>>> [m for m in dir(graph) if 'connect' in m.lower()]
>>> [m for m in dir(selected_node) if 'param' in m.lower()]
```

## 8. Τι να κάνετε αν κάτι πάει στραβά;

- **Σφάλμα σε κόκκινο στην κονσόλα:** το traceback εμφανίζεται πλήρες. Η εφαρμογή δεν κλείνει· μπορείτε να διορθώσετε την εντολή και να ξαναπροσπαθήσετε.
- **Η διεπαφή παγώνει:** πιθανώς γράψατε έναν ατέρμονο βρόχο. Η κονσόλα εκτελείται σε ξεχωριστό νήμα, αλλά αν ο βρόχος επηρεάζει το νήμα GUI, επανεκκινήστε την εφαρμογή.
- **Απρόσμενο `None`:** αν ένας κόμβος επιστρέφει `None` αντί για δεδομένα, επαληθεύστε ότι είναι συνδεδεμένος ανάντη (`graph.connections`) και ότι η ροή έχει εκτελεστεί (`graph.execute_flow()`).
- **`ValueError: too many values to unpack`:** προσπαθείτε να αποσυσκευάσετε ένα dict σαν να ήταν πλειάδα. Χρησιμοποιήστε πρώτα `result.keys()`.
- **`ValueError: not enough values to unpack`:** περιμένετε 2 τιμές αλλά ο κόμβος επιστρέφει 1 (dict) ή 3 (φασματογράφημα). Ελέγξτε με `type(result)` πριν αποσυσκευάσετε.
- **`AttributeError`:** το αντικείμενο δεν έχει αυτό το χαρακτηριστικό. Χρησιμοποιήστε `dir(obj)` ή `[a for a in dir(obj) if 'lexi' in a.lower()]` για να ανακαλύψετε το σωστό όνομα.
- **Δεν συμβαίνει τίποτα κατά την εκτέλεση:** ελέγξτε ότι υπάρχει τουλάχιστον ένας κόμβος πηγής συνδεδεμένος στην αλυσίδα και ότι έχει κληθεί `graph.execute_flow()`. Οι κόμβοι επεξεργασίας δεν παράγουν δεδομένα μόνοι τους.
- **Το γράφημα δεν αλλάζει:** βεβαιωθείτε ότι καλείτε `graph.execute_flow()` μετά την τροποποίηση παραμέτρων. Η αλλαγή μόνο του `params` δεν επαναϋπολογίζει αυτόματα.
