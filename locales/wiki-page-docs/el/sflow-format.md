# 📄 Μορφή αρχείου `.sflow`

Η μορφή `.sflow` είναι το εγγενές πρότπο ανταλλαγής και επιμονής του **FloWorks**. Επιτρέπει την ενσωμάτωση μιας πλήρους ροής εργασίας σε ένα ενιαίο αρχείο που περιλαμβάνει την τοπολογία του γράφου, τις παραμέτρους των κόμβων, τα επεξεργασμένα δεδομένα και τις αυτοκόλλητες σημειώσεις, διευκολύνοντας την κοινή χρήση, την αρχειοθέτηση ή τν ντετερμινιστική αναπαραγωγή πειραμάτων.

---

## 📦 Τι είναι ένα αρχείο `.sflow`;

Ένα αρχείο `.sflow` είναι, στην ουσία, **ένα μετονομασμένο αρχείο ZIP**. Αλλάζοντας την επέκταση σε `.zip`, μπορείτε να επιθεωρήσετε τα περιεχόμενά του με οποιονδήποτε διαχειριστή αρχείων ή εργαλείο γραμμής εντολών.

Η ελάχιστη εσωτερική του δομή αποτελείται από:

| Συστατικό | Περιγραφή |
|------------|-------------|
| `diagram.json` | Κύριο μανιφέστο: ορίζει κόμβους, συνδέσεις, προβολή, αυτοκόλλητες σημειώσεις και μεταδεδομένα σειριοποίησης. |
| `data/` | Φάκελος με τα δεδομένα κάθε κόμβου σε μορφή `.npy` (δυαδικοί πίνακες NumPy). |
| `metadata.json` *(προαιρετικό)* | Συμπληρωματικές πληροφορίες: συγγραφέας, έκδοση FloWorks, περιγραφή και ετικέτες. |

=== "🌳 Οπτική Δομή"
    ```text
    mi-flujo.sflow
    ├── diagram.json
    ├── metadata.json
    └── data/
        ├── node_1.npy
        ├── node_2.npy
        └── script_state.npy (προαιρετικό, για ScriptNode persist)
    ```

---

## 🧩 `diagram.json` – Η Καρδιά της Ροής

Αυτό το αρχείο JSON περιγράφει την πλήρη τοπολογία, τη θέση των στοιχείων στον καμβά και την κατάσταση της προβολής κατά τη στιγμή της αποθήκευσης.

### Ελάχιστο Παράδειγμα
```json
{
  "nodes": [
    {
      "id": "n1",
      "type": "OscilloscopeNode",
      "pos": [150, 200],
      "params": { "channel": "primary", "simulation": false }
    },
    {
      "id": "n2",
      "type": "GraphExporterNode",
      "pos": [450, 200],
      "params": { "theme": "dark", "export_format": "png" }
    }
  ],
  "connections": [
    {
      "from": "n1",
      "to": "n2",
      "from_port": "out",
      "to_port": "data_in"
    }
  ],
  "viewport": { "x": 0, "y": 0, "scale": 1.0 },
  "stickers": [
    { "x": 600, "y": 100, "width": 200, "height": 150, "text": "Έλεγξε το κατώφλι", "user_modified": true }
  ]
}
```

### Κύρια Πεδία
| Πεδίο | Τύπος | Περιγραφή |
|-------|------|-------------|
| `nodes` | `Array` | Λίστα αντικειμένων `{id, type, pos, params}`. Το `type` πρέπει να συμπίπτει με το `node_registry.py`. |
| `connections` | `Array` | Λίστα συνδέσεων `{from, to, from_port, to_port}`. Οι θύρες είναι συμβολοσειρές, όχι δείκτες. |
| `viewport` | `Object` | `(x, y, scale)` για την αποκατάσταση της ακριβούς θέσης και εστίασης του καμβ. |
| `stickers` | `Array` | Σειριοποιημένες αυτοκόλλητες σημειώσεις με συντεταγμένες κανονικοποιημένες σε 96 dpi. |

!!! tip "Σειριοποίηση Κόμβων"
    Οι συγκεκριμένες παράμετροι κάθε κόμβου διαχειρίζονται μέσω `SerializableMixin`. Αποθηκεύονται μόνο τα χαρακτηριστικά που δηλώνονται στο `SERIALISABLE = [...]`. Οι κόμβοι που δεν είναι εγγεγραμμένοι στο σύστημα παραλείπονται αυτόματα κατά τη φόρτωση.

## 💾 `data/` – Επεξεργασμένα Δεδομένα και Πίνακες NumPy

Όταν μια ροή εκτελείται, οι κόμβοι μπορούν να αποθηκεύουν τα αποτελέσματά τους σε αρχεία `.npy` μέσα σε αυτόν τον φάκελο.

- Το όνομα του αρχείου συνήθως συμπίπτει με το `id` του κόμβου ή με εσωτερικές αναφορές.
- ι πίνακες αποθηκεύονται σε δυαδική μορφή NumPy, **διατηρώντας αυστηρά την αρχική διαστατικότητα** (1D, 2D, 3D, κ.λπ.). Ο μηχανισμός δεν εφαρμόζει ποτέ `flatten()`.
- Στο `diagram.json`, τα δεδομένα αναφέρονται με το πρόθεμα `__npy__:`:
  ```json
  "params": { "cached_output": "__npy__:node_2.npy" }
  ```
- Αν ένας κόμβος δεν παράγει δεδομένα ή είναι διαμορφωμένος να μην τα επιμένει, το αντίστοιχο αρχείο μπορεί να παραλειφθεί.

??? note "Εξωτερική Συμβατότητα"
    Τα αρχεία `.npy` είναι καθολικά στο οικοσύστημα Python. Μπορείτε να τα διαβάσετε εκτός FloWorks με:
    ```python
    import numpy as np
    dedomena = np.load("data/node_1.npy")
    print(dedomena.shape)
    ```

## 🏷️ `metadata.json` (Προαιρετικό)

Περιέχει περιγραφικές πληροφορίες που δεν επηρεάζουν την εκτέλεση, ιδανικό για ιχνηλασιμότητα και διαχείριση έργων:

```json
{
  "floworks_version": "2.1.0",
  "author": "María Gómez",
  "description": "Ανάλυση δονήσεων σε τριφασικό κινητήρα",
  "created": "2026-05-10T10:30:00Z",
  "tags": ["μηχανολογία", "δονήσεις", "FFT", "πολυκαναλικό"]
}
```

## 🔄 Διαδικασία Αποθήκευσης και Φόρτωσης

Το FloWorks υλοποιεί έναν ισχυρό μηχανισμό για τη διασφάλιση της ακεραιότητας των δεδομένων:

1. **Αποθήκευση:**
   - Ο γράφος διασχίζεται και οι κόμβοι σειριοποιούνται μέσω `SerializableMixin`.
   - Οι πίνακες εξάγονται στο `data/` και αναφέρονται στο JSON με `__npy__:`.
   - Τα πάντα συσκευάζονται σε ZIP με επέκταση `.sflow`.
2. **Ασφαλής Φόρτωση:**
   - Δημιουργείται ένα **προσωρινό αντίγραφο ασφαλείας στη μνήμη** του τρέχοντος διαγράμματος.
   - Το νέο `.sflow` εξάγεται και αναλύεται.
   - Αν προκύψει οποιοδήποτε σφάλμα (άκυρο JSON, ελλείποντες κόμβοι, καταστροφή `.npy`), **το αντίγραφο ασφαλείας αποκαθίσταται αυτόματα** χωρίς απώλεια εργασίας.
3. **Ειδικό ScriptNode:**
   - Αποθηκεύει `script`, `params`, `dynamic_inputs`, `dynamic_outputs`, `persist` και `python_path`.
   - Κατά τη φόρτωση, ο κώδικας επαναμεταγλωττίζεται, οι δυναμικές θύρες αναδομούνται και η κατάσταση `persist` αποκαθίσταται αυτόματα.
4. **StickyNotes και DPI:**
   - Οι συντεταγμένες και τα μεγέθη καννικοποούνται σε **96 dpi** κατά την αποθήκευση.
   - Κατά τη φόρτωση, κλιμακώνονται στο DPI της τρέχουσας οθόνης, εγγυώμενη οπτική συνέπεια μεταξύ διαφορετικών αναλύσεων.

## 🛠️ Εξωτερική Χρήση και Αυτοματοποίηση

Η μορφή `.sflow` έχει σχεδιαστεί για να είναι διαφανής και προγραμματιστική. Μπορείτε να τη διαβάσετε ή να τη δημιουργήσετε από εξωτερικά σενάρια:

=== "🐍 Python (Ανάγνωση)"
    ```python
    import zipfile
    import json
    import numpy as np

    with zipfile.ZipFile("mi-flujo.sflow") as z:
        graph = json.loads(z.read("diagram.json"))
        if "metadata.json" in z.namelist():
            meta = json.loads(z.read("metadata.json"))

        dedomena_n1 = np.load(z.open("data/node_1.npy"))
        print(f"Κόμβοι: {len(graph['nodes'])}")
        print(f"Δεδομένα: {dedomena_n1.shape}")
    ```

=== "📤 Python (Βασική Δημιουργία)"
    ```python
    import zipfile
    import json
    import numpy as np

    graph = {
        "nodes": [{"id": "gen", "type": "GeneratorNode", "pos": [100, 100], "params": {}}],
        "connections": [],
        "viewport": {"x": 0, "y": 0, "scale": 1.0}
    }

    with zipfile.ZipFile("nuevo.sflow", "w", zipfile.ZIP_DEFLATED) as z:
        z.writestr("diagram.json", json.dumps(graph, indent=2))
        z.writestr("data/gen.npy", np.array([1.0, 2.0, 3.0]))
    ```

## 🔮 Συμβατότητα και Μελλοντική Επεκτασιμότητα

Η μορφή `.sflow` ακολουθεί τις αρχές **επεκτάσιμου και συμβατού προς τα πίσω σχεδιασμού**:

- ✅ **Νέες ενότητες:** Μελλοντικές εκδόσεις μπορούν να προσθέτουν φακέλους όπως `thumbnails/`, `logs/` ή `plugins/` χωρίς να σπάνε παλαιότερους φορτωτές.
- ✅ **Προαιρετικά πεδία:** Ο αναλυτής αγνοεί άγνωστα κλειδιά στο `diagram.json`, επιτρέποντας την προσθήκη πειραματικών μεταδεδομένων.
- ✅ **Έκδοση:** Το πεδίο `floworks_version` στο `metadata.json` επιτρέπει στην εφαρμογή να εφαρμόζει αυτόματες μεταναστεύσεις αν η μορφή εξελίσσεται.

!!! warning "Χρυσός Κανόνας"
    Ποτέ μην τροποποιείτε χειροκίνητα το `diagram.json` ενώ η εφαρμογή είναι ανοιχτή. Το σύστημα εξαρτάται από τη συνέπεια μεταξύ τοπολογίας, πινάκων και κατάστασης προβολής. Χρησιμοποιείτε πάντα τις εγγενείς ροές αποθήκευσης/φόρτωσης.
