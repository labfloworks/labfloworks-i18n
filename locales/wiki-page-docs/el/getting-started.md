# 🚀 Πρώτα βήματα με το FloWorks

Αυτός ο οδηγός θα σας οδηγήσει από το μηδέν μέχρι την εκτέλεση της πρώτης σας ροής επεξεργασίας σημάτων. Το FloWorks είναι μια εφαρμογή διαγραμμάτων ροής για σήματα, χτισμένη με Python και PySide6, που υποστηρίζει πραγματικό υλικό (VISA/SCPI), ενσωματωμένη προσομοίωση, προχωρημένα σενάρια και αλλαγή γλώσσας σε πραγματικό χρόνο.

---

## 🌊 Η πρώτη σας δείγμα ροή

Ας δημιουργήσουμε μια απλή ροή: θα παράγουμε ένα ημιτονοειδές σήμα και θα το οπτικοποιήσουμε σε πραγματικό χρόνο.

1. **Προσθήκη κόμβων**
   Στην επάνω γραμμή εργαλείων, επιλέξτε `Πηγή` → επιλέξτε `Προηγμένος Γεννήτρια Σήματος`. Στη συνέχεια, από `Επεξεργασία` → επιλέξτε, για παράδειγμα, `Φασματικός`.
2. **Σύνδεση**
   Πατήστε `Ctrl+Κλικ` στη θύρα εξόδου (`δεξιά`) του γεννήτριας. Στη συνέχεια, κάντε κλικ στη θύρα εισόδου (`αριστερά`) του παλμογράφου. Ή απλώς κάντε κλικ στη θύρα εξόδου και σύρετε (κρατώντας πατημένο) μέχρι τη θύρα εισόδου του επόμενου κόμβου.
3. **Διαμόρφωση (προαιρετικά)**
   Κάντε κλικ σε έναν κόμβο, στο αριστερό πλαϊνό πάνελ θα εμφανιστεί ένας επεξεργαστής με τις παραμέτρους του επιλεγμένου κόμβου για προσαρμογή των συνθηκών λειτουργίας. Στο κάτω μέρος υπάρχει μια γραφική οπτικοποίηση που αναπαριστά οπτικά τα δεδομένα που παράγονται ή αποκτώνται από τους κόμβους.
4. **Εκτέλεση**
   Πατήστε `F5` ή το κουμπί ▶ στη γραμμή εργαλείων. Ο τοπολογικός μηχανισμός θα υπολογίσει τη σειρά εκτέλεσης, θα επεξεργαστεί τα δεδομένα και θα δείτε το κύμα στο γραφικό πάνελ. **Ο σύνδεσμος θα εμφανίσει κίνηση υποδεικνύοντας τη ροή ενεργή!**

## 🧠 Κατανόηση των θυρών: κατηγορίες ανά χρώμα

Στο FloWorks, κάθε θύρα ανήκει σε μια **λειτουργική κατηγορία** που αναγνωρίζεται από ένα χρώμα. Οι έγκυρες συνδέσεις γίνονται **πάντα μεταξύ θυρών του ίδιου χρώματος**: μια έξοδος μιας κατηγορίας συνδέεται αποκλειστικά με μια είσοδο της ίδιας κατηγορίας. Επιπλέον, η γραμμή σύνδεσης υιοθετεί αυτόματα το χρώμα των θυρών που ενώνει, διευκολύνοντας την οπική ανάγνωση.

| Τύπος | Χρώμα | Σκοπός | Τυπικό παράδειγμα |
|------|-------|-----------|----------------|
| `control` | Λευκό | Ροή ελέγχου / ενεργοποίηση. | Σήμα εκκίνησης προς έναν κόμβο απόκτησης. |
| `exec` | Γκρι | Εκτέλεση λειτουργιών ή βημάτων. | Ενεργοποίηση μιας συνάρτησης ή callback. |
| `data` | Πράσινο | Γενικά δεδομένα / αριθμητικά σήματα. | Έξοδος γεννήτριας ή αισθητήρα. |
| `int` | Μπλε | Ακέραιοι αριθμοί. | Δείκτης, μέγεθος ενδιάμεσης μνήμης, ID. |
| `float` | Κυανό | Αριθμοί κινητής υποδιαστολής. | Πλάτος, συχνότητα, κατώφλι. |
| `string` | Μωβ | Αλυσίδες κειμένου. | Όνομα αρχείου, ετικέτα. |
| `bool` | Ροζ | Μπουλιανές τιμές (`True`/`False`). | Σημαία κατάστασης, ενεργοποίηση. |
| `array` | Σκούρο μπλε | Πίνακες / διανύσματα. | Πολυκαναλικό σήμα, λίστα δειγμάτων. |
| `trigger` | Πορτοκαλί | Εναύσματα / διακριτά γεγονότα. | Παλμός συγχρονισμού, ακμή. |

**Χρυσός κανόνας:**

- Συνδέονται μόνο θύρες με **ακριβώς το ίδιο χρώμα** (έξοδος ↔ είσοδος της ίδιας κατηγορίας).
- Το σύστημα αποτρέπει άκυρες συνδέσεις και επισημαίνει οπτικά συμβατές θύρες κατά το σύρσιμο.
- Η γραμμή σύνδεσης παίρνει το χρώμα των συνδεδεμένων θυρών· έτσι κάθε διαδρομή αναγνωρίζεται με μια ματιά.

**Φιλοσοφία FloWorks:**
Οι θύρες δεδομένων **διατηρούν τη διαστατικότητα** των πινάκων. Ποτέ δεν εφαρμόζεται αυτόματη ισοπέδωση: αν μπαίνει πίνακας, βγαίνει πίνακας, διατηρώντας την ακεραιότητα των πολυδιάστατων σημάτων σας.

## 🖱️ Πλοήγηση στον καμβά (Canvas)

Κυριαρχήστε στο χώρο εργασίας με αυτές τις κινήσεις:

| Ενέργεια | Πώς να το κάνετε |
|--------|--------------|
| **Εστίαση** | Τροχός ποντικιού ή `Ctrl + τροχός` |
| **Μετατόπιση (pan)** | Κρατήστε πατημένο `Διάστημα` και σύρετε, ή χρησιμοποιήστε το μεσαίο κουμπί του ποντικιού |
| **Επιλογή κόμβου** | Αριστερό κλικ στον κόμβο |
| **Πολλαπλή επιλογή** | Σύρετε ένα ορθογώνιο με αριστερό κλικ, ή `Ctrl + κλικ` σε πολλούς κόμβους |
| **Μετακίνηση επιλογής** | Σύρετε οποιονδήποτε από τους επιλεγμένους κόμβους |
| **Άνοιγμα διαμόρφωσης** | Διπλό κλικ στον κόμβο |

**Συμβουλή:** Το αριστερό πλαϊνό πάνελ ενημερώνεται αυτόματα με τη διαμόρφωση του επιλεγμένου κόμβου, χωρίς ανάγκη ανοίγματος επιπλέον παραθύρων.

## ⚡ Συντομεύσεις πληκτρολογίου και προχωρημένες κινήσεις

Αυτές οι συντομεύσεις μετατρέπουν έναν κανονικό χρήστη σε **power user**:

| Συντόμευση | Ενέργεια |
|-------|--------|
| `F5` | Εκτέλεση ροής |
| `Ctrl + S` | Αποθήκευση έργου (`.sflow`) |
| `Ctrl + Κλικ` | Σύνδεση κόμβων (κλικ σε θύρα εξόδου → κλικ σε θύρα εισόδου) |
| `Ctrl + C` / `Ctrl + V` | Αντιγραφή / επικόλληση επιλεγμένων κόμβων |
| `Ctrl + Z` / `Ctrl + Y` | Αναίρεση / επανάληψη |
| `Ctrl + Shift + L` | Αυτόματη οργάνωση κόμβων στον καμβά |
| `Del` | Διαγραφή επιλεγμένων κόμβων |
| `Ctrl + A` | Επιλογή όλων των κόμβων |

**Προχωρημένες κινήσεις:**

- **Αναπαραγωγή ροής:** επιλέξτε μια ομάδα κόμβων, `Ctrl + C`, `Ctrl + V` και σύρετε το αντίγραφο σε άλλη ζώνη.
- **Καθαρισμός πλέγματος:** χρησιμοποιήστε `Ctrl + Shift + L` για να τακτοποιήσετε ολόκληρο τον καμβά με μια εντολή.
- **Γρήγορη σύνδεση:** `Ctrl + Κλικ` σε θύρα εξόδου και μετά κανονικό κλικ σε θύρα εισόδου· το FloWorks σχεδιάζει τη σύνδεση αυτόματα.

## 🎨 Εξατομίκευση περιβάλλοντος

Το FloWorks προσαρμόζεται σε εσάς, όχι το αντίστροφο.

### Αλλαγή θέματος σε πραγματικό χρόνο
Από την επάνω γραμμή, μενού **Προβολή → Θέμα**, επιλέξτε μεταξύ φωτεινού, σκοτεινού και άλλων. Η διεπαφή αλλάζει **στιγμιαία**, χωρίς επανεκκίνηση και χωρίς απώλεια ροής εργασίας.

### Μέγεθος γραμματοσειράς
Στο **Προβολή → Μέγεθος γραμματοσειράς** επιλέξτε μια προκαθορισμένη ή προσαρμοσμένη τιμή. Ολόκληρη η διεπαφή προσαρμόζεται αμέσως.

### Γλώσσα
Στο **Προβολή → Γλώσσα** επιλέξτε την επιθυμητή γλώσσα. Το FloWorks υποστηρίζει **αλλαγή σε πραγματικό χρόνο**: τα μενού, τα κουμπιά και τα μηνύματα μεταφράζονται χωρίς επανεκκίνηση της εφαρμογής.

## ❗ Επίλυση συνηθισμένων προβλημάτων

| Πρόβλημα | Πιθανή αιτία | Λύση |
|----------|---------------|----------|
| Η ροή δεν εκτελείται | Υπάρχουν μη διαμορφωμένοι κόμβοι ή σπασμένες συνδέσεις | Ελέγξτε ότι όλοι οι κόμβοι έχουν έγκυρες παραμέτρους και ότι οι συνδέσεις είναι μεταξύ συμβατών θυρών |
| Το γράφημα δεν ενημερώνεται | Η ροή είναι σε παύση ή δεν ρέουν δεδομένα | Βεβαιωθείτε ότι πατήσατε `F5` ή ▶, και ότι οι κόμβοι πηγής παράγουν δεδομένα |
| Δεν μπορώ να συνδέσω δύο κόμβους | Οι θύρες είναι διαφορετικού τύπου | Επιβεβαιώστε ότι και οι δύο θύρες είναι **δεδομένα** ή και οι δύο **έλεγχος** |
| Το πρόγραμμα είναι αργό με μεγάλες ροές | Πάρα πολλοί κόμβοι ή γραφήματα σε πραγματικό χρόνο | Κλείστε μη χρησιμοποιούμενα πάνελ ανάλυσης ή μειώστε το ρυθμό δειγματοληψίας των κόμβων πηγής |
| Το θέμα δεν αλλάζει | Ορισμένα widget μπορεί να μην είναι καταχωρημένα | Επανεκκιήστε την εφαρμογή και δοκιμάστε ξανά (θα διορθωθεί σε μελλοντικές εκδόσεις) |

## 🧪 Γρήγορα πρακτικά παραδείγματα

Εκτός από την αρχική ημιτονοειδή ροή, δοκιμάστε αυτά τα μίνι έργα για να κυριαρχήσετε το FloWorks:

| Παράδειγμα | Εμπλεκόμενοι κόμβοι | Αναμενόμενο αποτέλεσμα |
|---------|-------------------|--------------------|
| **Χαμηλοπερατό φίλτρο** | Γεννήτρι → Φίλτρο → Οπτικοποιητής γραφημάτων | Θα δείτε το φιλτραρισμένο σήμα |
| **Προσομοιωμένη απόκτηση** | Γεννήτρια → Αναλυτής THD | Τιμή αρμονικής παραμόρφωσης του σήματος |
| **Χειροκίνητος έλεγχος** | Γεννήτρια → Επιθεωρητής δεδομένων | Πίνακας με τις τιμές του σήματος που αποστέλλει η γεννήτρια |
| **Σύγκριση σημάτων** | Δύο γεννήτριες → Αθροιστής → Οπτικοποιητής γραφημάτων | Το αποτέλεσμα της πράξης (άθροισμα, διαφορά, πολλαπλασιασμός ή διαίρεση) δύο κυμάτων σε ένα μόνο γράφημα |

Κάθε μία από αυτές τις ροές μπορεί να συναρμολογηθεί σε λιγότερο από ένα λεπτό, αποδεικνύοντας την ευελιξία του FloWorks σε σχέση με τον παραδοσιακό κώδικα.

!!! warning "Σημειώσεις συμβατότητας και χρήσης"
    1. **Έκδοση Python:** Μπορείτε να χρησιμοποιήσετε 3.9+ και συστήματα 64 bit.
    2. **Τείχος προστασίας Windows:** Εάν χρησιμοποιείτε πραγματικό υλικό (παλμογράφος VISA/SCPI), επιτρέψτε το `FloWorks.exe` στο τείχος προστασίας. Η εφαρμογή εμφανίζει έναν προσαρμοσμένο διάλογο εάν η σύνδεση αποκλείεται (ο διάλογος του λειτουργικού δεν εμφανίζεται σε λειτουργία `--windowed`).
    3. **Βασικές συντομεύσεις:** `F5` (εκτέλεση), `Ctrl+S` (αποθήκευση `.sflow`), `Ctrl+Κλικ` (σύνδεση), `Διάστημα+κλικ` (ελεύθερο pan), `Ctrl+Shift+L` (αυτόματη διάταξη).
    4. **Διατήρηση δεδομένων:** Ο μηχανισμός **ποτέ** δεν εφαρμόζει `flatten()` σε πίνακες. Εργαστείτε ε τοπικά αντίγραφα εάν χρειάζεστε διανυσματοποίηση.
