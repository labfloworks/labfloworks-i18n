# FloWorks 架构 – 用户视角

FloWorks 是一款桌面应用程序，可让您通过流程图构建信号处理链。您在交互式画布上连接模块（节点），并实时查看结果。为实现这一点，应用程序由个协同工作的模块组成。下面以非技术方式解释每个部分的功能及其相互关系。

---

## 整体结构

应用程序由以下功能区域组成：

| 区域 | 功能 |
|------|------------|
| **启动和主窗口** | 启动程序，显示窗口、菜单，并协调所有用户操作。 |
| **执行引擎** | 计算节点应按何种顺序执行，检测依赖关系和循环，并将数据从一个节点传递到另一个节点。 |
| **场景和图表** | 管理放置节点的画布、节点之间的连接、便利贴以及撤销/重做操作。 |
| **节点和处理** | 包含您可以使用的所有模块类型：信号源、数学运算、自定义脚本、图形导出等。 |
| **视觉连接器** | 绘制连接节点的线条（平滑曲线或正交路径），通过动画展示数据流，并避免重叠。 |
| **用户界面** | 包括图表视图（缩放、平移）、工具栏、参数表、分析面板（统计、光标）和配置对话框。 |
| **真实硬件支持** | 支持与实验室仪器（示波器、发生器、LCR 表）通信，以采集或生成真实信号。 |
| **图形导出** | 成高质量图像（PNG、PDF、SVG），支持完整的视觉自定义。 |
| **主题和外观** | 更改整个应用程序的外观（深色、浅色、高对比度），并允许调整字体大小。 |
| **语言** | 将整个界面翻译成多种语言，并允许即时切换语言。 |
| **项目管理** | 保存和打开包含整个图表的 `.sflow` 文件，包括配置、脚本和结果。 |
| **测试和诊断** | 用于验证一切是否正常运行的内部工具（对最终用户不可见）。 |

## 内部工作原理

### 启和主窗口
打开 FloWorks 时，会配置图形环境，检测屏幕像素密度（以便在 4K 或普通显示器上一切看起来清晰），并显示主窗口。该窗口集中了所有元素：绘图区域、菜单、工具栏和侧面板。

### 流引擎
当您按“运行”（或按 F5）时，内部引擎会按照正确的顺序遍历所有节点，并遵循连接关系。它知道哪些节点依赖于其他节点，并防止无限循环。它支持一个节点接收多个命名输入并产生多个输出。数据在节点之间传输时不会失去其原始结构。

### 图表场景
您构建图表的画布是一个智能场景：

- 允许添加、移动、连接和选择节点。
- 支持对任何操作进行无限制的撤销和重做。
- 包含可调整大小的便利贴，您可以自由放置，并随项目一起保存。
- 具有自动整理功能，可以整齐地重新排列节点（使用 Ctrl+Shift+L）。
- 保存时，整个图表被打包到一个 `.sflow` 文件中，其中包含节点描述、连接、便签和相关数值数据。

### 连接器
连接节点的线条被绘制为平滑曲线或正交路径。点或虚线的柔和动画指示流动方向。通道管理器可防止相同节点之间的多个连接堆积；它会自动将它们分开，以便一切保持可读。

### 节点类型
节点是基本单元。它们分为三类：

- **源** – 生成信号。可以模拟波形（正弦波、方波等）或从连接的示波器或万用表读取真实数据。支持多个同时通道（例如，来自 LCR 的阻抗和相位）。
- **处理** – 转换数据。包括算术运算（加、减、乘、除）、条件决策（是/否分支）以及一个强大的脚本节点，可让您在可视辅助下编写自己的 Python 代码。
- **接收器** – 显示或导出结果。最常见的是图形查看器（虚拟示波器），但也有专业品质的图形导出器。

每个节点都有输入端口（左/上）和输出端口（右/下）。将输出端口连接到输入端口时，信号就会在它们之间流动。

#### 高级脚本节点
脚本节点值得一提。它专为希望在不离开 FloWorks 的情况下添加自己处理逻辑的高级用户设计。它提供：

- 具有语法高亮、自动完成和行号的编辑器。
- 能够从节点面板定义可编辑参数，而无需触碰代码（例如，一个在脚本中使用的数值）。
- 动态输入和输出端口：通过在脚本中添加特殊注释，可以创建新的连接器。
- 持久内存：一个特殊变量（`persist`），在运行之间保持其值，适用于累加器或状态机。
- 现成的脚本模板以及保存您自己模板的功能。
- 内置帮助系统和显示运行时错误的控制台。

### 用户界面
除了画布之外，界面还包括：

- **工具栏**，包含按类别组织的所有节点、语言、主题和字体大小菜单，以及日志查看器访问入口。
- **参数表**，显示所选节点的信息，并突出显示可能的不兼容性（例如，尝试对不同长度的信号进行操作）。
- **可停靠分析面板**：统计（最大值、最小值、均方根）、用于测量差异的 A/B 光标，以及带峰值标记的十字线。
- **欢迎对话框**，可适应您的屏幕分辨率并提供初始选项。

### 与真实仪器的连接
如果您有兼容的硬件（Siglent SDS 示波器、LCR 表、SDG 发生器），FloWorks 可以通过标准 VISA/SCPI 协议与它们通信。配置在应用程序内的特定面板中完成。当您捕获多通道信号（例如，来自 LCR 的幅度和相位）时，源节点会打包所有通道，您可以通过简单的上下文菜单选择要查看的通道。

### 专业图形导出
图形导出器节点可让您生成适用于报告或出版物的图像。双击它会打开一个包含多个选项的对话框：您可以自定义颜色、线型、标、刻度，选择 PNG、PDF 或 SVG 格式并将您的首选项保存为可重复使用的配置文件。

### 视觉自定义
FloWorks 包含多个主题（深色、浅色、高对比度），可即时更改整个界面的外观，无需重启。此外，您可以从菜单（信息 → 字体大小）调整全局字体大小，所有元素都会相应调整大小，包括节点内的文本、便利贴和图形。

### 语言系统
应用程序在首次启动时自动检测系统语言并保存您的偏好。您可以随时从菜单更改语言；所有文本、菜单和帮助都会即时更新。

### 项目和 `.sflow` 文件
您的所有工作都保存在一个扩展名为 `.sflow` 的单个文件中。该文件包含完整的图表：节点、连接、便签、配置、脚本和生成的数值数据。您可以与其他用户共享；在另一台计算机上打开时，便签和节点会自动重新缩放以适应该屏幕的像素密度。

## 典型工作流

1. **创建简单图表**
   从工具栏选择一个源节点（例如，发生器）和一个查看器节点。
   将发生器的输出连接到查看器的输入（在输出端口上 Ctrl+单击，然后在输入端口上单击）。
   按 F5 运行。您将在图形上看到信号。

2. **使用自定义脚本**
   添加一个脚本节点。
   在编辑器中编写 Python 代码；您可以定义可编辑参数和额外端口。
   像连接任何其他节点一样连接其输入和输出。
   运行流程；脚本将使用您的数据进行处理。

3. **从真实示波器捕获数据**
   连接仪器并从示波器节点面板配置通信。
   节点获取信号并通过其输出端口传递（每通道一个）。
   将这些端口连接到其他处理节点或查看器。

4. **导出报告用图形**
   将所需信号连接到图形导出器节点。
   选择节点（右键单击）以配置图形的视觉外观。
   还可以加载/保存配置文件，以加快获取适合报告的图形，并以所选扩展名获取图像文件。

## 这一切的用途

此架构旨在让您专注于信号分析，而无需担心程序内部的组织方式。每个组件都有明确的功能，并协同工作以提供流畅的体验，从仿真到真实仪器，再到视觉自定义和结果导出。

如果您需要扩展 FloWorks 的功能（例如，添加新节点类型或连接不同的仪器），请知道存在一个允许这样做的模块化结构，尽管这属于开发人员的领域。作为最终用户，请享受此设计提供的灵活性。
