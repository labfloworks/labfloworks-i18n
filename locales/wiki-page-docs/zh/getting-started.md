# 🚀 FloWorks 入门

本指南将带您从零开始，直到运行您的第一个信号处理流。FloWorks 是一款用于信号处理的流程图应用程序，使用 Python 和 PySide6 构建，支持真实硬件（VISA/SCPI）、集成仿真、高级脚本编写和热语言切换。

---

## 🌊 您的第一个示例流

让我们创建一个简单的流：生成一个正弦波信号并实时可视化它。

1. **添加节点**
   在顶部工具栏中，选择 `源` → 选择 `高级信号发生器`。然后，从 `处理` → 例如选择 `频谱`。
2. **连接**
   在发生器的输出端口（`右侧`）上执行 `Ctrl+单击`。然后，在示波器的输入端口（`左侧`）上 `单击`。或者只需单击输出端口并拖动（按住单击）到下一个节点的输入端口。
3. **配置（可选）**
   单击一个节点，左侧边栏中将出现一个编辑器，其中包含所选节点的参数，以调整操作条件。底部有一个可视化图，以可视化方式表示节点生成或获取的数据。
4. **运行**
   按 `F5` 或工具栏上的 ▶ 按钮。拓扑引擎将计算执行顺序，处理数据，您将在图形面板上看到波形。连接器将动画显示，指示活动流！

## 🧠 理解端口：按颜色分类

在 FloWorks 中，每个端口都属于一个由颜色标识的**功能类别**。有效连接**始终在相同颜色的端口之间进行**：一个类别的输出仅连接到同一类别的输入。此外，连接线会自动采用它所连接端口的颜色，便于直观阅读。

| 类型 | 颜色 | 用途 | 典型示例 |
|------|-------|-----------|----------------|
| `control` | 白色  | 控制流 / 激活。 | 向采集节点发送启动信号。 |
| `exec` | 灰色 | 执行操作或步骤。 | 触发函数或回调。 |
| `data` | 绿色  | 通用数据 / 数字信号。 | 发生器或传感器的输出。 |
| `int` | 蓝色  | 整数。 | 索引、缓冲区大小、ID。 |
| `float` | 青色  | 浮点数。 | 幅度、频率、阈值。 |
| `string` | 紫色  | 文本字符串。 | 文件名、标签。 |
| `bool` | 粉色  | 布尔值（`True`/`False`）。 | 状态标志、启用。 |
| `array` | 深蓝色  | 数组 / 向量。 | 多通道信号、样本列表。 |
| `trigger` | 橙色  | 触发器 / 离散事件。 | 同步脉冲、边沿。 |

**黄金法则：**

- 仅连接**完全相同颜色**的端口（输出 ↔ 同一类别的输入）。
- 系统会阻止无效连接，并在拖动时高亮显示兼容端口。
- 连接线采用所连接端口的颜色；这样每条路径一目了然。

**FloWorks 理念：**
数据端口**保留数组的维度**。从不应用自动展平：如果输入矩阵，则输出矩阵，保持多维信号的完整性。

## 🖱️ 浏览画布

使用以下手势掌握工作区：

| 操作 | 操作方法 |
|--------|--------------|
| **缩放** | 鼠标滚轮或 `Ctrl + 滚轮` |
| **平移（滚动）** | 按住 `空格` 并拖动，或使用鼠标中键 |
| **选择节点** | 在节点上左键单击 |
| **多选** | 用左键拖动一个矩形，或在多个节点上 `Ctrl + 单击` |
| **移动选择** | 拖动任何选定的节点 |
| **打开配置** | 双击节点 |

**提示：** 左侧面板会自动更新所选节点的配置，无需打开额外的窗口。

## ⚡ 键盘快捷键和高级操作

这些快捷键可将普通用户转变为**高级用户**：

| 快捷键 | 操作 |
|-------|--------|
| `F5` | 运行流 |
| `Ctrl + S` | 保存项目（`.sflow`） |
| `Ctrl + 单击` | 连接节点（单击输出端口 → 单击输入端口） |
| `Ctrl + C` / `Ctrl + V` | 复制 / 粘贴选定节点 |
| `Ctrl + Z` / `Ctrl + Y` | 撤消 / 重做 |
| `Ctrl + Shift + L` | 在画布上自动组织节点 |
| `Del` | 删除选定节点 |
| `Ctrl + A` | 选择所有节点 |

**高级操作：**

- **复制流：** 选择一组节点，`Ctrl + C`，`Ctrl + V` 并将副本拖到另一个区域。
- **清理网格：** 使用 `Ctrl + Shift + L` 通过单个命令整理整个画布。
- **快速连接：** 在输出端口上 `Ctrl + 单击`，然后在输入端口上正常单击；FloWorks 会自动绘制连接。

## 🎨 环境自定义

FloWorks 适应您，而不是相反。

### 热主题切换
从顶部栏的**视图 → 主题**菜单中，在浅色、深色或其他主题之间进行选择。界面会**即时**更改，无需重新启动或丢失工作流。

### 字体大小
在**视图 → 字体大小**中，选择预设值或自定义值。整个界面会立即调整。

### 语言
在**视图 → 语言**中选择所需语言。FloWorks 支持**热切换**：菜单、按钮和消息会被翻译，而无需重新启动应用程序。

## ❗ 常见问题的故障排除

| 问题 | 可能原因 | 解决方案 |
|----------|---------------|----------|
| 流无法运行 | 存在未配置的节点或连接断开 | 检查所有节点是否具有有效参数，并且连接是否在兼容端之间 |
| 图表未更新 | 流已暂停或没有数据流动 | 确保您已按 `F5` 或 ▶，并且源节点正在生成数据 |
| 无法连接两个节点 | 端口类型不同 | 验证两个端口是否均为**数据**或均为**控制** |
| 程序在处理大型流时变慢 | 节点或实时图表过多 | 关闭未使用的分析面板或降低源节点的采样频率 |
| 主题未更改 | 某些小部件可能未注册 | 重新启动应用程序，然后重试（将在未来版本中解决） |

## 🧪 快速实践示例

除了初始的正弦波流之外，还可以尝试这些迷你项目来掌握 FloWorks：

| 示例 | 涉及节点 | 预期结果 |
|---------|-------------------|--------------------|
| **低通滤波器** | 发生器 → 滤波器 → 图形查看器 | 您将看到滤波后的信号 |
| **模拟采集** | 发生器 → THD 分析仪 | 信号的 THD 值 |
| **手动控制** | 发生器 → 数据检查器 | 包含发生器发送的信号值的表格 |
| **信号比较** | 两个发生器 → 加法器 → 图形查看器 | 两个波形运算（加、减、乘或除）的结果显示在单个表中 |

这些流中的每一个都可以在一分钟内组装完成，展示了 FloWorks 相对于传统代码的敏捷性。

!!! warning "兼容性和使用说明"
    1. **Python 版本：** 您可以使用 3.9+ 和 64 位系统。
    2. **Windows 防火墙：** 如果您使用真实硬件（VISA/SCPI 示波器），请在防火墙中允许 `FloWorks.exe`。如果连接被阻止，应用程序会显示一个自定义对话框（在 `--windowed` 模式下不会出现操作系统对话框）。
    3. **关键快捷键：** `F5`（运行）、`Ctrl+S`（保存 `.sflow`）、`Ctrl+单击`（连接）、`空格+单击`（自由平移）、`Ctrl+Shift+L`（自动布局）。
    4. **数据保留：** 引擎**从不**对数组应用 `flatten()`。如果需要矢量化，请使用本地副本。
