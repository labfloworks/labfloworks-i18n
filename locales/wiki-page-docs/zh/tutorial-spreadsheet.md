# 📊 电子表格教程

轻量级、Excel 风格的电子表格，可嵌入。

---

## 1. 什么是 Spreadsheet？

它是一个电子表格组件，提供：

- 支持公式的单元格（以 `=` 开头）
- 预定义函数（SUM、AVERAGE、CONDITIONAL 等）
- 算术、逻辑和比较运算符
- 极简界面，非常适合集成到 Qt 应用程序中

---

## 2. 基本导航

- 单击单元格以选中它。
- 直接输入以输入文本或数字。
- 要编写**公式**，请以 `=` 开头（例如 `=SUM(A1:A5)`）。
- 按 **Enter** 确认编辑。
- 使用方向键或鼠标移动。

---

## 3. 公式：可用函数

所有函数均以大写形式书写，并支持范围（例如 `A1:A5`）或以逗号分隔的参数。

| 函数                     | 功能                             | 示例                           |
| ------------------------ | -------------------------------- | ------------------------------ |
| `SUM`                    | 求和                             | `=SUM(A1:A5)`                  |
| `AVG` / `AVERAGE`        | 平均值                           | `=AVG(A1:A5)`                  |
| `COUNT`                  | 计数（非空）                     | `=COUNT(A1:A5)`                |
| `MAX`                    | 最大值                           | `=MAX(A1:A5)`                  |
| `MIN`                    | 最小值                           | `=MIN(A1:A5)`                  |
| `ABS`                    | 绝对值                           | `=ABS(A1)`                     |
| `ROUND`                  | 四舍五入（第二个参数 = 小数位）  | `=ROUND(A1, 2)`               |
| `IF`                     | 条件（如果，那么，否则）         | `=IF(A1>10, "是", "否")`      |
| `CONCAT` / `CONCATENATE` | 连接文本                         | `=CONCAT(A1, " ", B1)`         |
| `LEN`                    | 文本长度                         | `=LEN(A1)`                     |
| `INT`                    | 整数部分                         | `=INT(A1)`                     |
| `SQRT`                   | 平方根                           | `=SQRT(A1)`                    |

### 3.1. 关于函数的说明

- 范围用**冒号**表示：`A1:A5` 包括从 A1 到 A5 的所有单元格。
- 函数可以嵌套：`=SUM(A1:A5) + MAX(B1:B5)`。
- 文本参数必须用双引号或单引号括起来。

---

## 4. 非函数运算符

除了函数之外，您还可以直接在公式中使用运算符。语法类似于 Python。

### 4.1. 算术运算符

| 运算           | 示例                      |
| -------------- | ------------------------- |
| 加法           | `=A1+A2+A3`               |
| 减法           | `=A1-A2`                  |
| 乘法           | `=A1*B1`                  |
| 除法           | `=A1/B1`                  |
| 取模           | `=A1%B1`                  |
| 幂运算         | `=A1**2`  (或 `=A1^2`)   |

### 4.2. 比较运算符

它们返回 `True` 或 `False`（显示为 `真` / `假`）。

| 运算符 | 含义             | 示例               |
| -------- | ---------------- | ------------------ |
| `>`      | 大于             | `=A1>B1`           |
| `<`      | 小于             | `=A1<B1`           |
| `>=`     | 大于或等于       | `=A1>=10`          |
| `<=`     | 小于或等于       | `=A1<=10`          |
| `==`     | 等于             | `=A1==B1`          |
| `!=`     | 不等于           | `=A1!=B1`          |

### 4.3. 逻辑和条件运算符

您可以使用 `and`、`or`、`not` 组合条件。

```excel
= A1>5 and B1<10
= not(A1==0)
= 10 if A1>5 else 0
```

三元运算符 `if` `else` 也直接支持。

## 5. 实际示例

### 5.1. 销售总和

假设您在 `B2:B10` 中有销售额，并且想要总计：

```excel
=SUM(B2:B10)
```

### 5.2. 条件折扣

如果总计（在 `B12` 中）超过 100，则应用 10% 的折扣；否则为 0：

```excel
= IF(B12>100, B12*0.9, B12)
```

### 5.3. 平均值和计数

`C2:C20` 中成绩的平均值，但仅当至少有 5 个值时：

```excel
= IF(COUNT(C2:C20)>=5, AVG(C2:C20), "数据不足")
```

### 5.4. 组合文本

将名字 (A2) 和姓氏 (B2) 用空格连接：

```excel
= CONCAT(A2, " ", B2)
```

### 5.5. 数字的平方根

```excel
= SQRT(A1)
```

### 5.6. 保留两位小数

```excel
= ROUND(A1, 2)
```

## 6. 提示和技巧

- **相对/绝对引用：** 目前，所有引用是相对的（如 Excel）。尚不支持 `$A$1`。
- **动态范围：** 您可以使用诸如 `A:A`（整列）或 `1:1`（整行）之类的范围。
- **自动完成：** 键入 `=` 时，会出现一个包含可用函数的菜单。
- **错误：** 如果公式无效，单元格将显示 `#ERROR`，并在状态栏中显示详细消息。
- **重新计算：** 修改依赖单元格时，公式会自动更新。

---

## 8. 常见问题

**如何导出数据？**
目前还没有原生导出功能，但您可以通过内部模型访问数据。

**支持图表吗？**
不支持，这是一个基本的电子表格。您可以将其与其他小部件结合使用以进行可视化。
