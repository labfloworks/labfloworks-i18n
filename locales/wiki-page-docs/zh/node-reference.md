# 🧩 技术节点参

FloWorks 不依赖于静态目录。它使用基于清晰约定的**动态注册系统**。这允许在不接触拓扑引擎的情况下扩展平台。以下是已实现的目录、真实技术能力以及安全扩展它的协议。

---

## 📂 核心类别

=== "📦 按层查看"
    <div class="grid cards" markdown>

    - **📥 源/输入**
      生成或捕获初始信号。支持集成仿真、真实硬件（VISA/SCPI）和多通道模式。
    - **⚙️ 处理**
      转、组合或分析数据。保留维度并在必要时自动插值。
    - **🔀 控制/流**
      分支、迭代或条件执行。包括对激活信号的原生支持。
    - **🐍 脚本/高级**
      使用参数端口（`# @param`）、动态端口（`# @input`/`# @output`）和状态持久化（`persist`）执行动态 Python 代码。
    - **🔌 硬件/仪器**
      示波器、LCR 表和发生器的接口。
    - **📤 输出/导出**
      可视化、导出或归档结果。支持视觉主题、用户配置文件和专业格式（PNG/PDF/SVG）。

    </div>

## 📋 已实现的技术目录

| 节点 | 类型 | 主要职责 | 关键特性 |
|------|------|---------------------------|------------------------|
| `SumNode` | 处理 | 两个输入的算术运算符（+、-、*、/）。 | 自动对不同分辨率（FFT）的信号进行插值。保留维度。 |
| `RhombusNode` | 控制 | 条件（是/否分支）。 | 两个输出端口。通过阈值或布尔逻辑评估条件。 |
| `TriggerNode` | 控制 | 具有外部激活功能的迭代器/累加器。 | 接收 `(x, y, "trigger")`。累积最多 N 次迭代并发出堆叠/平均结果。 |
| `ScriptNode` | 高级 | 集成 Python 脚本环境。 | QScintilla、自动完成、`# @param`、动态端口、`persist`、模板、错误控制台、带超时的外部解释器。 |
| `OscilloscopeNode` | 硬件 | 从示波器（SDS）或 LCR 表捕获。 | 仿真模式、集成防火墙对话框、**多通道支持**（`out_primary`、`out_secondary`）、"显示通道"菜单。 |
| `GeneratorNode` | 源 | 向发生器（SDG）发送信号或模拟输出。 | 调制/扫描配置、集成仿真对话框。 |
| `GraphExporterNode` | 输出 | 专业图形导出器。 | 双击配置、自定义轴、主题、已保存的配置文件等。 |

## 🔍 ScriptNode：基本功能

> **🐍 集成脚本环境**
>
> - **内置代码编辑器：** 基本语法高亮、行号和代码折叠。
> - **动态参数面板：** 指令 `# @param NAME : type = value` 将可编辑控件（微调框、文本字段等）注入侧面板。
> - **动态端口：** `# @input name` 和 `# @output name` 实时创建端口。脚本接收 `inputs` 字典并返回 `outputs`。
> - **状态持久化：** 全局 `persist` 字典，在运行之间保持值。
> - **模板和导入/导出：** 带有基础脚本的下拉菜单。用户可以将脚本保存在 `nodes/script_node/templates/` 中或导入/导出外部 `.py` 文件。
> - **内置错误控制台：** 显示语法/执行失败，并在编辑器中高亮显示确切的行。
> - **帮助和 i18n：** 上下文工具提示、带快速指南的 `?` 按钮，以及所有使用 `tr()` 进行翻译的文本。
> - **带超时的外部解释器：** 可配置路径（`# @python_path` 或"浏览…"按钮）。具有时间限制的隔离执行，并回退到内部解释器。
> - **完整序列化：** 保存脚本、参数、动态端口和 `persist` 状态。加载 `.sflow` 时，它会自动重建端口和参数。
