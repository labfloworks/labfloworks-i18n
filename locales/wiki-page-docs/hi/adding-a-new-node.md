# 📘 डेवलपर्स के लिए गाइड: FloWorks में एक नया नोड कैसे जोड़ें

## 1. वास्तुकला का परिचय

FloWorks PySide6 पर बना है और एक कनेक्टेबल नोड मॉडल का उपयोग करता है जो सिग्नल प्रोसेसिंग के एक फ्लो का प्रतिनिधित्व करता है।

---

## 2. `template_node.py` टेम्पलेट का उपयोग

नए नोड्स बनाने में सुविधा के िए, `nodes/template_node.py` फ़ाइल प्रदान की गई है। इस टेम्पलेट में शामिल हैं:
- अंतर्राष्ट्रीयकरण के लिए पूर्ण समर्थन (`languageChanged` से कनेक्शन, `update_language` विधि)।
- थीम के लिए पूर्ण समर्थन (`update_theme` विधि)।
- तीन खंडों के साथ HTML प्रारूप में एकीकृत सहायता।
- कई विन्यास योग्य इनपुट/आउटपुट पोर्ट का प्रबंधन।
- `get_output_for_port` के साथ कई आउटपुट।
- `get_display_signal` के माध्यम से प्लॉट में विज़ुअलाइज़ेशन।
- अनुवाद योग्य संदर्भ मेनू।

नया नोड विकसित करते समय हमेशा इस टेम्पलेट से शुरुआत करने की सलाह दी जाती है।

---

## 3. चरण दर चरण: एक कस्टम नोड बनाना

### 3.1. टेम्पलेट की प्रतिलिपि बनाना और नाम बदलना
1. `nodes/template_node.py` की प्रतिलिपि बनाएँ अपने नए नोड के नाम से, उदाहरण के लिए `nodes/mi_nodo.py`।
2. `TemplateNode` क्लास का नाम बदलकर कुछ वर्णनात्मक नाम रखें, जैसे `MiNodoNode`।
3. यदि आवश्यक हो तो आयात समायोजित करें।

### 3.2. पोर्ट और लेबल परिभाषित करना
!!! warning "महत्वपूर्ण: नामों का मिलान"
    `PORTS`, `PORT_LABELS` में पोर्ट के नाम और `execute_program` द्वारा लौटाए गए शब्दकोश की कुंजियाँ **बिल्कुल समान** होनी चाहिए (बड़े/छोटे अक्षर सहित)। ेम्पलेट अब अधिक मज़बूती के लिए एक उपनाम मैपिंग (`'data_in'` → पहला बायाँ पोर्ट) शामिल करता है।

फ़ाइल के शीर्ष पर `PORTS` शब्दकोश संपादित करें। प्रत्येक प्रविष्टि का प्रारूप है:
```python
"पोर्ट_नाम": ("पक्ष", अंश)
```
- **संभावित पक्ष:** `"left"`, `"right"`, `"top"`, `"bottom"`।
- **अंश:** `0.0` और `1.0` के बीच का मान जो पक्ष के साथ स्थिति को इंगित करता है।

**एक इनपुट और दो आउटपुट वाले नोड के लिए उदाहरण:**
```python
PORTS = {
    "input":     ("left",  0.5),
    "magnitude": ("right", 0.35),
    "phase":     ("right", 0.65),
}
```
`PORT_LABELS` शब्दकोश में वह टेक्स्ट होता है जो प्रत्येक पोर्ट के बगल में दिखाई देगा। अनुवाद कुंजियों का उपयोग स्थिर टेक्स्ट के बजाय करने की सलाह दी जाती है (अंतर्राष्ट्रीयकरण अनुभाग देखें)।

### 3.3. प्रसंस्करण तर्क लागू करना
मुख्य विधि `execute_program(self, input_data)` है। यह विधि फ्लो इंजन द्वारा तब बुलाई जाती है जब नोड डेटा प्राप्त करता है।

**`input_data` हो सकता है:**
- `None` यदि कोई इनपुट नहीं है।
- समय-सिग्नल के लिए एक ट्यूपल `(x, y)`।
- एक 1D सरणी।
- कई इनपुट्स वाले नोड्स के लिए एक शब्दकोश `{पोर्ट_नाम: डेटा}`।

**प्रतिफल:**
- एकल आउटपुट वाले नोड्स के लिए, सीधे डेटा लौटाएँ (उदा. ट्यूपल `(x, y)`)।
- कई आउटपुट्स वाले नोड्स के लिए, एक शब्दकोश लौटाएँ जिसकी कुंजियाँ `PORTS` में परिभाषित आउटपुट पोर्ट के नामों से मेल खाती हों।

```python
def execute_program(self, input_data):
    # input_data को संसाधित करें और परिणाम उत्पन्न करें
    resultado_magnitud = (freq, mag)
    resultado_fase = (freq, phase)
    return {
        "magnitude": resultado_magnitud,
        "phase": resultado_fase
    }
```

!!! tip "सामान्य पोर्ट नामों पर टिप्पणी"
    फ्लो इंजन कभी-कभी पोर्ट के वास्तविक नाम के बजाय `'data_in'` जैसी कुंजियों वाला एक शब्दकोश भेज सकता है (विशेष रूप से यदि उपयोगकर्ता ने सटीक रूप से गोले पर क्लिक नहीं किया है)। टेम्पलेट पहले से ही इस मामले को संभालने के लिए कोड शामिल करता है:
    ```python
    if isinstance(input_data, dict):
        if 'data_in' in input_data:
            input_data = input_data['data_in']
    ```
    यह एक अशुद्ध कनेक्शन के कारण नोड की विफलता को रोकता है।

टेम्पलेट पहले से ही एक टिप्पणी किया हुआ उदाहरण शामिल करता है। इसके अलावा, `get_output_for_port(self, port_name)` लागू करें ताकि इंजन प्रत्येक आउटपुट को रूट कर सके:
```python
def get_output_for_port(self, port_name):
    return self.output_data.get(port_name)
```

### 3.4. स्वरूप को अनुकूलित करना (वैकल्पिक)
`paint()` विधि पृष्ठभूमि, शीर्षक, स्थिति और किसी भी अतिरिक्त टेक्स्ट बनाती है। आप संशोधित कर सकते हैं:
- रंग (स्वचालित रूप से `update_theme` के साथ अपडेट होते हं)।
- स्थिति टेक्स्ट (`self._status` विशेषता का उपयोग करके)।
- सारांश जानकारी (उदा. परिमाण चरम)।

टेम्पलेट एक बुनियादी उदाहरण दिखाता है।

### 3.5. विन्यास योग्य पैरामीटर जोड़ना (वैकल्पिक)
यदि आपके नोड को उपयोगकर्ता द्वारा समायोज्य पैरामीटर की आवश्यकता है (उदा. विंडो आकार, कटऑफ़ आवृत्ति), तो आप:
1. `__init__` में विशेषताएँ जोड़ सकते हैं (उदा. `self.window_size = 512`)।
2. एक कॉन्फ़िगरेशन संवाद बना सकते हैं (`QDialog` से विरासत में लें)।
3. संवाद को `open_config_dialog()` में कनेक्ट कर सकते हैं (विधि पहले से ही टेम्पलेट में मौजूद है)।
4. संवाद से पैरामीटर अपडेट कर सकते हैं और `self.update()` कॉल कर सकते हैं।

### 3.6. नोड को क्रमबद्ध योग्य बनाना (कॉन्फ़िगरेशन सहेजना / लोड करना)
ताकि नोड कॉपी/पेस्ट, अंडू/रीडू, या फ़ाइल मेनू के सहेजें/खोलें कमांड का उपयोग करते समय अपने पैरामीटर सहेज और पुनर्प्राप्त कर सके, उसे क्रमबद्धता मिक्सिन से विरासत में लेना चाहिए और अपनी विशेषताएँ घोषित करनी चाहिए।

1. अपनी फ़ाइल में मिक्सिन आयात करें:
    ```python
    from nodes.serializable import SerializableMixin
    ```
2. क्लास के वंशानुक्रम को `QGraphicsObject` से पहले इसे शामिल करने के लिए बदलें:
    ```python
    class MiNodoNode(SerializableMixin, QGraphicsObject):
    ```
3. क्लास स्तर पर `SERIALISABLE` सूची को उन विशेषता नामों के साथ परिभाषित करें जिन्हें आप बनाए रखना चाहते हैं। केवल सरल प्रकार (`int`, `float`, `str`, `bool`), सूचियाँ, शब्दकोश, या NumPy सरणियाँ स्वीकार्य हैं (बाद वाले स्वचालित रूप से `.sflow` के अंदर `.npy` फ़ाइलों के रूप में संग्रहीत होते हैं)।
    ```python
    class MiNodoNode(SerializableMixin, QGraphicsObject):
        SERIALISABLE = ['frecuencia', 'amplitud', 'configuracion']
    ```
4. सुनिश्चित करें कि ये विशेषताएँ `__init__` में प्रारंभ की जाती हैं:
    ```python
    self.frecuencia = 1000.0
    self.amplitud = 1.0
    self.configuracion = {'tipo': 'seno', 'fase': 0}
    ```

इसके साथ, आपको `serialize`/`deserialize` विधियाँ लिखने की आवश्यकता नहीं है; मिक्सिन स्वचालित रूप से मानों को सहेजने और पुनर्प्राप्त करने का ध्यान रखता है।

यदि आपके नोड को लोड करते समय अतिरिक्त तर्क की आवश्यकता है (उदाहरण के लिए, एक हार्डवेयर उपकरण को फिर से कनेक्ट करना), तो आप पहले पैतृक विधि को कॉल करके `deserialize` को ओवरराइड कर सकते हैं:
```python
def deserialize(self, data):
    super().deserialize(data)   # SERIALISABLE की विशेषताएँ पुनर्स्थापित करता है
    self._iniciar_dispositivo()
```

## 5. अंतर्राष्ट्रीयकरण (i18n)

सभी दृश्यमान टेक्स्ट `tr("कुंजी", default="...")` के माध्यम से अनुवाद योग्य होने चाहिए। टेम्पलेट पहले से ही इसे लागू करता है। आपको `locales/` के अंदर JSON फ़ाइलों में संबंधित कुंजियाँ जोड़नी होंगी।

**अनुशंसित संरचना:**
```json
{
   "nodes": {
     "mi_nodo": {
       "title": "Mi Nodo",
       "tooltip": "Descripción emergente",
       "ports": {
         "input": "Entrada",
         "output1": "Salida 1",
         "output2": "Salida 2"
      },
       "status": {
         "no_data": "Sin datos",
         "ready": "Listo"
      },
       "menu": {
         "show_output": "Mostrar salida",
         "configure": "Configurar..."
      },
       "help_title": "Ayuda - Mi Nodo",
       "help_html": "<h3>🎛️ Filter Node</h3>\n<p>Applies a <b>digital filter</b>...</p>"
    }
  },
   "toolbar": {
     "add_mi_nodo": "Mi Nodo"
  }
}
```

HTML सहायता सभी नोड्स के लिए सामान्य तीन-खंड प्रारूप का अनुसरण करती है (विशिष्ट विवरण + "प्रणाली में कैसे सोचें" + "शॉर्टकट और युक्तियाँ")। टेम्पलेट पहले से ही `get_help_text()` में संरचना शामिल करता है।

## 6. विज़ुअल थीम

`update_theme(self, theme)` विधि को वर्तमान थीम द्वारा परिभाषित रंगों वाला एक शब्दकोश प्राप्त होता है। टेम्पलेट स्वचालित रूप से अपडेट करता है:
- नोड पृष्ठभूमि (`node_normal_bg`)
- बॉर्डर (`node_selected_border`)
- शीर्षक और टेक्स्ट रंग (`node_normal_text`)
- पोर्ट रंग (`port_circle`, `port_outline`, `port_inline`, `port_text`)

सुनिश्चित करें कि `MainWindow` (या `ThemeUpdater`) में थीम बदलने पर प्रत्येक नोड के लिए `node.update_theme()` को कॉल किया जाता है।

- [ ] नोड टूलबार से सही ढंग से बनता है।
- [ ] पोर्ट अपेक्षित स्थितियों में दिखाई देते हैं और कनेक्शन (`Ctrl+क्लिक`) के लिए पता लगाने योग्य हैं।
- [ ] इनपुट डेटा प्राप्त करने पर, `execute_program` बुलाया जाता है और सिग्नल संसाधित होता है।
- [ ] आउटपुट सही ढंग से जुड़े हुए नोड्स तक प्रसारित होते हैं।
- [ ] संदर्भ मेनू दृश्यीकरण चैनल बदलने की अनुमति देता है (यदि कई आउटपुट हैं)।
- [ ] नोड पर क्लिक करने पर, चयनित सिग्नल प्लॉट विजेट पर ग्राफ़ किया जाता है।
- [ ] डबल-क्लि उचित प्रारूप में सहायता खोलता है।
- [ ] भाषा सही ढंग से बदलती है (शीर्षक, पोर्ट, मेनू टेक्स्ट)।
- [ ] थीम सही ढंग से बदलती है (नोड और पोर्ट के रंग)।
- [ ] कॉपी/पेस्ट बिना त्रुटियों के काम करता है।

!!! tip "पोर्ट का सटीक कनेक्शन"
    नोड्स को कनेक्ट करते समय, सुनिश्चित करें कि आप लक्ष्य पोर्ट के गोले पर ठीक से क्लिक करें। यदि आप नोड के शरीर पर क्लिक करते हैं, तो प्रणाली एक सामान्य नाम (`'data_in'`) का उपयोग करेगी। टेम्पलेट अब इन नामों को सहन करता है, लेकिन यह एक अच्छा अभ्यास है क कई आउटपुट के सही रूटिंग की गारंटी के लिए सीधे गोले से कनेक्ट करें।

### 🐛 सामान्य समस्याएँ

| लक्षण | संभावित कारण | समाधान |
|---------|---------------|---------|
| कनेक्शन तीर पोर्ट पर लंगरित नहीं होती है। | पोर्ट गोले में `setData(0, port_name)` नहीं है या `get_port_scene_pos` लागू नहीं किया गया है। | सत्यापित करें कि `_create_ports` में `circle.setData(0, port_name)` किया जाता है और `get_port_scene_pos` उस नाम का उपयोग करता है। |
| आउटपुट जुड़े हुए नोड्स तक नहीं पहुँचते। | `execute_program` शब्दकोश नहीं लौटाता (कई आउटपुट के लिए) या `get_output_for_port` लागू नहीं किया गया है। | सुनिश्चित करें कि `execute_program` `{पोर्ट_नाम: डेटा}` लौटाता है और `get_output_for_port` संबंधित मान लौटाता है। |
| नोड पर क्लिक करने पर प्लॉट पर कुछ नहीं ग्राफ़ होता। | `get_display_signal` एक वैध ट्यूपल `(x, y)` नहीं लौटाता या `display_channel` एक मौजूदा आउटपुट से मे नहीं खाता। | सत्यापित करें कि `get_display_signal` चयनित चैनल का उपयोग करता है और डेटा NumPy सरणियाँ हैं। |
| भाषा बदलने पर टेक्स्ट अपडेट नहीं होते। | `languageChanged` सिग्नल कनेक्ट नहीं किया गया या `update_language` तत्वों को अपडेट नहीं करता। | `__init__` में कनेक्शन सत्यापित करें: `language_manager.languageChanged.connect(self.update_language)`। |
| थीम लागू नहीं होती। | नोड बनाते या थीम बदलते समय `update_theme` नहीं बुलाया जाता। | `MainWindow` में, नोड बनाने के बाद, `node.update_theme(self.theme_manager.current_theme())` को कॉल करें। |
| तीर नोड के केंद्र की ओर इशारा करती है। | शरीर के बजाय गोले पर क्लिक किया गया, या नाम `PORTS` से मेल नहीं खाता। | सीधे गोले पर क्लिक करें। सत्यापित करें कि `get_port_scene_pos` में उपनाम मैपिंग है। |
| आयात करते समय `NameError: name 'self' is not defined`। | `__init__` के बाहर इंस्टेंस विशेषताएँ घोषित की गईं। | सभी विशेषताएँ जैसे `self.mi_parametro` को `__init__` के अंदर परिभाषित किया जाना चाहिए। |
| `.sflow` को कॉपी/खोलते समय पैरामीटर खो जाते हैं। | नोड `SerializableMixin` से विरासत में नहीं लेता या `SERIALISABLE` परिभाषित नहीं है। | इस गाइड का चरण 3.6 लागू करें। |
