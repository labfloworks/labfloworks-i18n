# 🧪 FloWorks कंसोल का इंटरैक्टिव ट्यूटोरियल

FloWorks प्रयोगशाला में आपका स्वागत है। यह अधिक उन्नत उपयोगकर्ताओं के लिए एक अनुभाग है, यह एक **Python** टर्मिनल है जो कैनवास से जुड़ी सब कुछ को नियंत्रित करने के लिए है, यानी नोड्स और उनके कनेक्शन, क्रमिक और कोड की पंक्तियों द्वारा, यह ्रोग्राम से जुड़ा एक टर्मिनल है जो इसे नियंत्रित कर सकता है और अधिक मांग वाले उपयोगकर्ताओं की सुविधा के लिए व्यवहार या दिनचर्या निर्धारित कर सकता है।

यह गाइड **चरण दर चरण** दिखाएगी कि माउस को छुए बिना अपने फ़्लो चार्ट को कैसे नियंत्रित और विश्लेषित करें। प्रत्येक उदाहरण इंटरैक्टिव कंसोल में मान्य किया गया था और प्रोग्राम के वास्तविक डेटा संरचना को प्रतिबिंबित करता है।

## 2. माउस के बिना नोड्स और कनेक्शन में हेरफेर करें

### एक नया नोड बनाएँ

आपको नोड की कक्षा का सटीक नाम जानना हगा (कैटलॉग में ठीक वैसे ही)। तर्क हैं: `(प्रकार, x, y)`।

```python
>>> graph.add_catalog_node('SumNode', 300, 200)
```

नोड कैनवास पर निर्देशांक (300, 200) पर दिखाई देता है। यदि आप सटीक नाम नहीं जानते हैं, तो श्रेणियाँ सूचीबद्ध करें (अनुभाग 7 देखें)।

#### विकल्प: एक साथ कई नोड्स बनाएँ

```python
>>> for i, tipo in enumerate(['SignalSourceNode', 'FFTNode', 'OscilloscopeNode']):
...     graph.add_catalog_node(tipo, 100 + i*200, 300)
```

### नोड्स को मैन्युअल रूप से कनेक्ट करें

वाक्यविन्यास: `graph.connect_nodes(स्रोत, गंतव्य, 'आउटपुट_पोर्ट', 'इनपुट_पोर्ट')`। पोर्ट प्रत्येक नोड पर निर्भर करते हैं; कभी भी नाम न मान लें।

```python
>>> graph.connect_nodes(graph.nodes[0], graph.nodes[2], 'output', 'port_a')
```

> **💡 नोट:** कनेक्ट करने से पहले हमेशा `graph.nodes[N].PORTS` की जाँच करें। एक FFT नोड में `'input'` और `'magnitude'` होते हैं; एक जनरेटर में `'output'` होता है।

#### विकल्प: डिफ़ॉल्ट पोर्ट से कनेक्ट करें

यदि आप इनपुट पोर्ट का सटीक नाम नहीं जानते हैं, तो कुछ नोड्स पहले उपलब्ध का उपयोग करने के लिए `None` स्वीकार करते हैं:

```python
>>> graph.connect_nodes(graph.nodes[0], graph.nodes[2], 'output', None)
```

### एक नोड हटाएँ

```python
>>> graph.remove_node(graph.nodes[2])
```

नोड और उससे जुड़े सभी कनक्शन हटाता है। `graph.nodes` के सूचकांक पुनर्गठित हो जाते हैं, इसलिए पुराने संदर्भ न रखें।

#### विकल्प: एक श्रेणी के सभी नोड्स हटाएँ

```python
>>> for n in list(graph.nodes):
...     if n.META.get('category') == 'Processing':
...         graph.remove_node(n)
```

### एक नोड के पोर्ट देखें

```python
>>> graph.nodes[1].PORTS
```

**उदाहरण आउटपुट:**
```
{'input': ('left', 0.5), 'output': ('right', 0.25), 'magnitude': ('right', 0.5), 'phase': ('right', 0.75)}
```

कुंजी पोर्ट का नाम (स्ट्रिंग) है। मान दृश्य स्थिति के साथ एक ट्यूपल है। कनेक्ट करने के लिए केवल कुंजियाँ ही आपके लिए महत्वपूर्ण हैं।

#### विकल्प: सरल सूच के रूप में पोर्ट देखें

```python
>>> list(graph.nodes[1].PORTS.keys())
```

## 3. प्रवाह निष्पादित करें और परिणाम देखें

### पूरे ग्राफ को निष्पादित करें

```python
>>> graph.execute_flow()
```

यह विधि आरेख (`graph`) से संबंधित है, मुख्य विंडो से नहीं। यह सभी नोड्स को टोपोलॉजिकल क्रम में पार करता है, प्रत्येक को निष्पादित करता है और परिणामों को कैश करता है। कुछ भी नहीं लौटाता है; डेटा आंतरिक रूप से संग्रहीत होता है।

#### विकल्प: एक विशिष्ट शाखा का परिकलन बलपूर्वक करें

```python
>>> result = graph.get_node_branch_value(graph.nodes[1])
```

यह संकेत नोड के ऊपर की पूरी वृक्ष की पुनर्गणना करता है और सीधे परिणाम लौटाता है, वैश्विक कैश को संशोधित किए बिना।

### एक नोड के कैश किए गए डेटा देखें

यदि आपको किसी विशिष्ट नोड के संसाधित डेटा तक पहुँचने की आवश्यकता है, तो आप इसे दो तरीकों से कर सकते हैं:

#### प्रत्यक्ष तरीका (वस्तु द्वारा)
```python
>>> graph.node_values[graph.nodes[1]]
```

**उदाहरण आउटपुट:**
```
{'output': None, 'magnitude': (array([0., 78.125, ...]), array([0.0013, 0.0183, ...])), 'phase': (array([0., 78.125, ...]), array([0., 0.687, ...]))}
```

> **⚠️ चेतावनी:** यदि दृश्य में नोड्स का क्रम बद गया है (उदाहरण के लिए, नोड्स हटाने या जोड़ने पर) या यदि वस्तु उदाहरण शब्दकोश में सहेजी गई कुंजी के साथ ठीक से मेल नहीं खाता है, तो यह तरीका `KeyError` के साथ विफल हो सकता है।

#### वैकल्पिक तरीका (स्थिति द्वारा)
```python
>>> list(graph.node_values.values())[1]
```

यह तरीका **अधिक स्थिर** है क्योंकि यह वस्तु की सटीक पहचान पर निर्भर नहीं करता है। मानों का क्रम उस क्रम का अनुसरण करता है जिसमें नोड्स को अंतिम `graph.execute_flow()` के दौरान निष्पादित किया गया था। सूकांक `[1]` उस क्रम मं दूसरे नोड से मेल खाता है।

> **💡 नोट:** यदि आप प्रत्येक नोड का निष्पादन क्रम में सूचकांक देखना चाहते हैं, तो आप उपयोग कर सकते हैं:
> ```python
> >>> list(graph.node_values.keys())
> ```

> **⚠️ सावधानी:** `graph.node_values` हमेशा सीधे एक सरणी नहीं लौटाता है। प्रोसेसर नोड्स (FFT, फ़िल्टर, आदि) के लिए यह एक **शब्दकोश** लौटाता है जहाँ प्रत्येक कुंजी एक आउटपुट पोर्ट है। स्रोत नोड्स के लिए, यह एक ट्यूपल `(x, y)` लौटाता है।

#### विकल्प: सभी नोड्स का डेटा एक पंक्ति में देखें
```python
>>> {n.name: type(v).__name__ for n, v in graph.node_values.items()}
```

### एक स्रोत नोड की Y अक्ष तक पहुँचें

जनरेटर नोड्स (SignalSourceNode, FileInputNode, आदि) निष्पादन पर एक ट्यूपल `(समय, सिग्नल)` लौटाते हैं। केवल Y अक्ष प्राप्त करने के लिए:

```python
>>> result = graph.get_node_branch_value(graph.nodes[0])
>>> y = result[1]
>>> y.max()
```

**उदाहरण आउटपुट:**
```
Scalar NumPy (float64): 1.0
```

#### विकल्प: X अक्ष (समय) प्राप्त करें

```python
>>> x = result[0]
>>> x[:5]
```

### Python में असाइनमेंट: एक महत्वपूर्ण विवरण

Python में, असाइनमेंट (`=`) **स्टेटमेंट** हैं, अभिव्यक्ति नहीं। कंसोल `x, y = ...` के बाद ुछ भी नहीं प्रिंट करता है क्योंकि कोई रिटर्न मान नहीं है।

```python
>>> x, y = graph.get_node_branch_value(graph.nodes[0])
```

यह सत्यापित करने के लिए कि यह काम कर गया, अगली पंक्ति में चर का मूल्यांकन करें:

```python
>>> x
>>> y.shape
```

या समान पंक्ति में एक अभिव्यक्ति जोड़ने के लिए `;` का उपयोग करें:

```python
>>> x, y = graph.get_node_branch_value(graph.nodes[0]); y.max()
```

या स्पष्ट `print()` का उपयोग करें:

```python
>>> x, y = graph.get_node_branch_value(graph.nodes[0]); print(y.max())
```

## 4. मुख्य ग्राफ पर आरेखित करें

### ग्राफ साफ़ करें

```python
>>> app.plot_widget.clear_plot()
```

#### विकल्प: तुरंत साफ़ करें और पुनराकृति करें

```python
>>> app.plot_widget.clear_plot(); graph.execute_flow()
```

### कंसोल से एक मनमाना सिग्नल आरेखित करें

आप NumPy के साथ सरणियाँ बना सकते हैं और उन्हें सीधे प्लॉटिंग विजेट पर भेज सकते हैं, किसी भी नोड से गुज़े बिना।

```python
>>> import numpy as np
>>> x = np.linspace(0, 1, 1000)
>>> y = np.sin(2 * np.pi * 10 * x)
>>> app.plot_widget.plot_waveform(x, y)
```

#### विकल्प: साइन योग आरेखित करें

```python
>>> y = np.sin(2*np.pi*5*x) + 0.3*np.sin(2*np.pi*50*x) + 0.1*np.random.randn(1000)
>>> app.plot_widget.plot_waveform(x, y)
```

### एक स्रोत नोड के परिणाम को आरखित करें

चूँकि स्रोत नोड `(x, y)` लौटाता है, आप सीधे अनपैक कर सकते हैं:

```python
>>> x, y = graph.get_node_branch_value(graph.nodes[0])
>>> app.plot_widget.plot_waveform(x, y)
```

### एक FFT नोड के परिणाम को आरेखित करें (बहु-पोर्ट)

बहु-आउटपुट वाले नोड्स (FFT, समय-आवृत्ति विश्लेषण, आदि) एक सरल ट्यूपल नहीं लौटाते हैं। वे एक `dict` लौटाते हैं जहाँ प्रत्येक कुंजी एक आउटपुट पोर्ट है।

```python
>>> result = graph.get_node_branch_value(graph.nodes[1])
>>> result.keys()
```

**उदाहरण आउटपुट:**
```
dict_keys(['output', 'magnitude', 'phase'])
```

ध्यान दें कि यदि नोड के पास एक सामान्य पोर्ट नहं है तो `'output'` `None` हो सकता है। उपयोगी आउटपुट `'magnitude'` और `'phase'` हैं, जो बदले में `(frequencies, values)` के ट्यूपल हैं:

```python
>>> f, mag = result['magnitude']
>>> app.plot_widget.plot_waveform(f, mag)
```

#### विकल्प: परिमाण के बजाय चरण आरेखित करें

```python
>>> f, phase = result['phase']
>>> app.plot_widget.plot_waveform(f, phase)
```

#### विकल्प: दो सिग्नल ओवरले करें

```python
>>> x1, y1 = graph.get_node_branch_value(graph.nodes[0])
>>> app.plot_widget.plot_waveform(x1, y1)
>>> x2, y2 = graph.get_node_branch_value(graph.nodes[2])  # एक अन्य नोड
>>> app.plot_widget.plot_waveform(x2, y2)  # ओवरले हो जाता है
```

> **💡 नोट:** यदि आप dict के साथ `x, y = result` करने का प्रयास करते हैं, तो Python `ValueError: too many values to unpack` उठाएगा। अनपैक करने से पहले हमेशा `type(result)` और `result.keys()` के साथ निरीक्षण करें।

## 5. उड़ान भरने के दौरान एप्लिकेशन संशोधित करें

### पार्श्व पैरामीटर तालिका अपडेट करें

यदि आप कोड द्वारा एक पैरामीटर संशोधित करते हैं और चाहते हैं कि पार्श्व तालिका परिवर्तन को प्रतिबिंबित करे:

```python
>>> app.workspace_table.populate()
```

इस विधि में कोई तर्क नहीं है। यह चयनित नोड के वर्तमान मानों के साथ तालिका को ताज़ करती है।

#### विकल्प: दूरे नोड का चयन बलपूर्वक करें और ताज़ा करें

```python
>>> graph.nodes[1].setSelected(True)
>>> app.workspace_table.populate()
```

### टूलबार से एक नोड जोड़ें

```python
>>> app.add_node('SignalSourceNode')
```

यह टूलबार में "+" बटन दबाने के बराबर है। नोड कैनवास पर एक पूर्वनिर्धारित स्थिति में रखा जाता है।

### विंडो शीर्षक बदलें

`setWindowTitle` Qt का मूल विधि है। यह काम करता है, लेकिन ध्यान रखें कि एप्लिकेशन में एक टाइमर या घटना हो सकता है जो `update_title()` को कॉल करता है और इसे स्वचालित रूप से अधिलेखित कर देगा।

```python
>>> app.setWindowTitle('मेरा सिग्नल लेब')
>>> app.windowTitle()
```

ऐप द्वारा अपनी आंतरिक स्थिति (प्रोजेक्ट का नाम, फ़ाइल, आदि) से गणना किए गए "आधिकारिक" शीर्षक को पुनर्स्थापित करने के लिए:

```python
>>> app.update_title()
```

#### विकल्प: प्रोजेक्ट नाम के साथ शीर्षक

```python
>>> app.setWindowTitle(f'FloWorks — {graph.nodes[0].name}')
```

## 7. उन्नत रेसिपी

### एक नोड के आंतरिक पैरामीटर को बदलें

नोड के पैरामीटर सपाट विशेषताएँ नहीं हैं। वे `params` शब्दको के भीतर नेस्टेड हैं, जिसमें `'preset'`, `'formula'` या `'advanced'` जैसे उप-अनुभाग हैं। कभी भी `node.amplitude = 3.0` न करें; यह वस्तु में एक नई विशेषता बनाता है लेकिन वास्तविक पैरामीटर को संशोधित नहीं करता है।

#### मामला A: एक प्रीसेट संशोधित करें (साइन, वर्, आदि)

```python
>>> selected_node.params['mode'] = 'preset'
>>> selected_node.params['preset']['type'] = 'SINE'
>>> selected_node.params['preset']['amplitude'] = 2.0
>>> selected_node.params['preset']['frequency'] = 1000.0
>>> selected_node._generate_signal()
>>> graph.execute_flow()
```

#### मामला B: एक कस्टम सूत्र का उपयोग करें

```python
>>> selected_node.params['mode'] = 'formula'
>>> selected_node.params['formula']['expr'] = '2 * sin(2*pi*1000*t)'
>>> selected_node.params['formula']['vars'] = {'amp': 2.0, 'freq': 1000.0, 'offset': 0.0}
>>> selected_node._generate_signal()
>>> graph.execute_flow()
```

अभिव्यक्ति समय चर के रूप में `t` का उपयोग करती है। `vars` में मान वे प्रतीक हैं जिन्हें आप सूत्र में संदर्भित कर सकते हैं यदि आप `vars` छोड़ देते हैं, तो नोड डिफ़ॉल्ट मानों का उपयोग करेगा और सूत्र परिवर्तन को प्रतिबिंबित नहीं कर सकता है।

#### मामला C: उन्नत पैरामीटर बदलें (नमूनादर, अवधि)

```python
>>> selected_node.params['advanced']['duration'] = 0.02
>>> selected_node.params['advanced']['sample_rate'] = 44100
>>> selected_node._generate_signal()
>>> graph.execute_flow()
```

#### मामला D: एक गैर-जनरेटर नोड का पैरामीटर बदलें (उदा. FFT)

```python
>>> selected_node.params['window'] = 'hann'
>>> graph.execute_flow()
```

> **💡 नोट:** `getattr(obj, '_generate_signal', lambda: None)()` एक सुरक्षित पैटर्न है: यदि विधि मौजूद है (जनरेटर नोड्स), तो य इसे कॉल करता है; यदि नहीं, तो यह कुछ नहीं करता है और कोई त्रुटि नहीं उठाता है। प्रोसेसर नोड्स के लिए, केवल `graph.execute_flow()` ही पर्याप्त है।

### उपलब्ध सभी नोड श्रेणियों की सूची बनाएँ

आयात कैटलॉग लोड करता है, लेकिन इसे स्वचालित रूप से प्रदर्शित नहीं करता है। याद रखें कि Python में एक सफल आयात कुछ भी नहीं प्रिंट करता है; आपको वस्तु का मूल्यांकन करना होगा।

```python
>>> from nodes.node_catalog import NODE_CATEGORIES
>>> NODE_CATEGORIES
```

पठनीय सारांश के लिए:

```python
>>> for cat, nodos in NODE_CATEGORIES.items():
...     print(f"{cat}: {len(nodos)} नोड्स")
```

#### विकल्प: श्रेणी के अनुसार नोड नामों की सूची बनाएँ

```python
>>> {cat: [n.__name__ for n in nodos] for cat, nodos in NODE_CATEGORIES.items()}
```

## 8. यदि कुछ गलत हो जा तो क्या करें?

- **कंसोल में लाल रंग की त्रुटि:** ट्रेसबैक पूर्ण रूप से प्रदर्शित होता है। एप्लिकेशन बंद नहीं होता है; आप कमांड को सही कर सकते हैं और फिर से प्रयास कर सकते हैं।
- **इंटरफ़ेस जम जाता है:** संभवतः आपने एक अनंत लूप लिखा है। कंसोल एक अलग धागे में निष्पादित होता है, लेकिन यदि लूप GUI थ्रेड को प्रभावित करता है, तो एप्लिकेशन को पुनरारंभ करें।
- **अप्रत्याशित `None`:** यदि एक नोड डेटा के बजाय `None` लौटाता है, तो सत्यापित करें कि यह अपस्ट्रीम से जुड़ा हुआ है (`graph.connections`) और प्रवाह निष्पादित हुआ है (`graph.execute_flow()`).
- **`ValueError: too many values to unpack`:** आप एक dict को ट्यूपल के रूप में अनपैक करने का प्रयास कर रहे हैं। पहले `result.keys()` का उपयोग करें।
- **`ValueError: not enough values to unpack`:** आप 2 मानों की अपेक्षा कर रहे हैं लेकिन नोड 1 (dict) या 3 (स्पेक्ट्रोग्राम) लौटाता है। अनपैक करने से पहले `type(result)` के साथ निरीक्षण करें।
- **`AttributeError`:** वस्तु में वह विशेषता नहीं है। सही नाम की खोज के लिए `dir(obj)` या `[a for a in dir(obj) if 'शब्द' in a.lower()]` का उपयोग करें।
- **निष्पादित करने पर कुछ नहीं होता:** सत्यापित करें कि श्रृंखला से जुड़ा कम से कम एक स्रोत नोड है और `graph.execute_flow()` को कॉल किया गया है। प्रोसेसर नोड्स अकेले डेटा उत्पन्न नहीं करते हैं।
- **प्लॉट नहीं बदलता:** सुनिश्चित करें कि पैरामीटर संशोधित करने के बाद `graph.execute_flow()` को कॉल किया गया है। केवल `params` बदलना स्वचालित रूप से पुर्परिकलित नहीं करता है।
