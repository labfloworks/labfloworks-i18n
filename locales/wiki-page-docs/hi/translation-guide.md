# 🌐 अंतर्राष्ट्रीयकरण गाइड (i18n)

यह दस्तावेज़ बताता है कि FloWorks में एक नई भाषा कैसे जोड़ें और अनुवाद फ़ाइलों को प्रभावी ढंग से कैसे प्रबंधित करें।

---

## ➕ एक नई भाषा कैसे जोड़ें

### चरण 1: JSON फ़ाइल बनाएँ
`locales/` फ़ोल्डर पर जाएँ। `en.json` की प्रतिलिपि बनाएँ और इसे संबंधित दो-अक्षरीय [ISO 639-1](https://es.wikipedia.org/wiki/ISO_639-1) कोड का उपयोग करके नाम बदलें (उदा. फ्रेंच के लिए `fr.json`, जर्मन के लिए `de.json`)।

### चरण 2: स्ट्रिंग का अनुवाद करें
नई JSON फ़ाइल को एक टेक्स्ट संपादक में खोलें।

!!! warning "कुंजियाँ न बदलें"
    **कभी भी कुंजियाँ न बदलें** (प्रत्येक युग्म का बायाँ पक्ष)। केवल मानों का अनुवाद करें (दायाँ पक्ष)।

**मूल (`en.json`):**
```json
{
  "app_title": "FloWorks",
  "menu": {
    "file": "File",
    "edit": "Edit"
  }
}
```

**अनुवादित उदाहरण (`es.json`):**
```json
{
  "app_title": "FloWorks",
  "menu": {
    "file": "Archivo",
    "edit": "Editar"
  }
}
```
सुनिश्चित करें कि मूल कुंजी `"language_name"` में भाषा का मूल नाम हो (उदा. `"Français"`, `"Deutsch"`, `"Español"`)।

### चरण 3: JSON को मान्य करें
सत्यापित करें कि फ़ाइल वैध JSON है (कोई अंतिम अल्पविराम नहीं, सही उद्धरण चिहन, उचित एस्केप)। आप [JSONLint](https://jsonlint.com) जैसे ऑनलाइन सत्यापकों का उपयोग कर सकते हैं, या चला सकते हैं:
```bash
python -m json.tool locales/es.json
```

### चरण 4: नई भाषा का परीक्षण करें
1. FloWorks प्रारंभ करें।
2. **INFO → भाषा** पर जाएँ और नई भाषा चुनें।
3. सत्यापित करें कि इंटरफ़ेस के सभी तत्व तुरंत अपडेट होते हैं (मेनू, पैनल, संवाद, नोड लेबल, आदि)।

### चरण 5: स्वचालित पता लगाना (वैकल्पिक)
यदि उपयोगकर्ता की सिस्टम लोकेल नई भाषा के कोड से मेल खाती है, तो FloWorks इसे पहले प्रारंभ पर स्वचालित रूप से उपयोग करेगा (बशर्ते `QSettings` में कोई पिछली वरीयता सहेजी न गई हो)।

---

## 🌍 उपलब्ध भाषाएँ
- **अंग्रेज़ी** (`en`) – आधार / फ़ॉलबैक भाषा
- **स्पेनिश** (`es`)

---

## ⚙️ महत्वपूर्ण नोट्स और सर्वोत्तम अभ्यास

!!! info "फ़ॉलबैक तंत्र"
    आधार भाषा **अंग्रेज़ी** है। यदि किसी भाषा फाइल में कोई अनुवाद कुंजी गायब है, तो FloWorks स्वचालित रूप से अंग्रेज़ी स्ट्रिंग को फ़ॉलबैक के रूप में उपयोग करता है।

!!! warning "UI ओवरफ़्लो की रोकथाम"
    लेआउट टूटने से बचने के लिए अनुवाद संक्षिप्त रखें। यदि कोई अनुवादित पाठ काफ़ी लंबा है, तो संक्षिप्त रूप का उपयोग करने पर विचार करें या गतिशील स्केलिंग को संभालने के लिए थीम प्रणाली पर भरोसा करें।

!!! tip "HTML और प्लेसहोल्डर संरक्षित करें"
    - **HTML टैग:** सभी HTML टैगों को ठीक वैसे ही संरक्षित करें जैसे वे हैं (उदा. `<h3>`, `<b>`, `<pre>`, `<br>`)।
    - **प्लेसहोल्डर:** जहाँ भी उपयोग किया जाए, `{variable}` सिंटैक्स बनाए रखें (उदा. `"भाषा बदली गई: {name} ({code})"`)। उन्हें पुनर्व्यवस्थित न करें या हटाएँ नहीं।
