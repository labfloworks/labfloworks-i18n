# 📊 स्प्रेडशीट ट्यूटोरियल

Excel-शैली की हल्की, एम्बेड करने योग्य बेसिक स्प्रेडशीट।  

---

## 1. स्प्रेडशीट क्या है?

यह एक स्प्रेडशीट घटक है जो प्रदान करता है:

- सूत्रों के समर्थन वाले सेल (`=` से शुरू)
- पूर्वनिर्धारित कार्य (SUM, AVG, शर्तबद्ध, आदि)
- अंकगणितीय, तार्किक और तुलना ऑपरेटर
- न्यूनतम इंटरफ़ेस, Qt अनुप्रयोगों में एकीकरण के लिए आदर्श

---

## 2. बुनियादी नेविगेशन

- एक सेल का चयन करने के लिए उस पर क्लिक करें।
- टेक्स्ट या संख्याएँ दर्ज करने के लिए सीधे लिखें।
- **सूत्र** लिखने के लिए, `=` से शुरू करें (उदा. `=SUM(A1:A5)`).
- संपादन की पुष्टि के लिए **Enter** दबाएँ।
- स्थानांतरित करने के लिए तीर कुंजियों या माउस का उपयोग करें।

---

## 3. सूत्र: उपलब्ध कार्य

सभी कार्य बड़े अक्षरों में लिखे जाते हैं और सीमा (उदा. `A1:A5`) ा अल्पविराम द्वारा अलग किए गए तर्कों का समर्थन करते हैं।

| कार्य                  | क्या करता है                          | उदाहरण                        |
| ------------------------ | --------------------------------- | ------------------------------ |
| `SUM`                    | संख्याओं का योग                      | `=SUM(A1:A5)`                  |
| `AVG` / `AVERAGE`        | औसत                          | `=AVG(A1:A5)`                  |
| `COUNT`                  | संख्याओं की गणना (रिक्त नहीं)        | `=COUNT(A1:A5)`                |
| `MAX`                    | अधिकतम मान                      | `=MAX(A1:A5)`                  |
| `MIN`                    | न्यूनतम मान                      | `=MIN(A1:A5)`                  |
| `ABS`                    | निरपेक्ष मान                    | `=ABS(A1)`                     |
| `ROUND`                  | पूर्णांकित करता है (2रा तर्क = दशमलव) | `=ROUND(A1, 2)`               |
| `IF`                     | शर्तबद्ध (अगर, तो, अन्यथा) | `=IF(A1>10, "हाँ", "नहीं")`       |
| `CONCAT` / `CONCATENATE` | टेक्स्ट जोड़ता है                        | `=CONCAT(A1, " ", B1)`         |
| `LEN`                    | टेक्स्ट की लंबाई                 | `=LEN(A1)`                     |
| `INT`                    | पूर्णांक भाग                      | `=INT(A1)`                     |
| `SQRT`                   | वर्गमूल                     | `=SQRT(A1)`                    |

### 3.1. कार्यों के बारे में नोट्स

- सीमा **उपविराम** के साथ इंगित की जाती है: `A1:A5` A1 से A5 तक की सभी सेल शमिल करता है।
- कार्यों को नेस्ट किया जा सकता है: `=SUM(A1:A5) + MAX(B1:B5)`।
- टेक्स्ट तर्ग दोहरे या एकल उद्धरण चिह्नों में होने चाहिए।

---

## 4. कार्यों के बिना ऑपरेटर

कार्यों के अलावा, आप सीधे सूत्र में ऑपरेटरों का उपयोग कर सकते हैं। वाक्यविन्यास Python के समान है।

### 4.1. अंकगणितीय

| ऑपरेशन      | उदाहरण                   |
| -------------- | ------------------------- |
| योग           | `=A1+A2+A3`               |
| घटाव          | `=A1-A2`                  |
| गुणा | `=A1*B1`                  |
| भाग       | `=A1/B1`                  |
| मॉड्यूलो         | `=A1%B1`                  |
| घात       | `=A1**2`  (या `=A1^2`)     |

### 4.2. तुलनाएँ

`True` य `False` लौटाते हैं (जो `सत्य` / "असत्य" के रूप में प्रदर्शित होते हैं)।

| ऑपरेटर | अर्थ       | उदाहरण            |
| -------- | ----------------- | ------------------ |
| `>`      | से बड़ा         | `=A1>B1`           |
| `<`      | से कम         | `=A1<B1`           |
| `>=`     | से बड़ा या बराबर     | `=A1>=10`          |
| `<=`     | से कम या बराबर     | `=A1<=10`          |
| `==`     | बराबर             | `=A1==B1`          |
| `!=`     | बराबर नहीं          | `=A1!=B1`          |

### 4.3. तार्किक और शर्तबद्ध

आप `and`, `or`, `not` के साथ शर्तों को जोड़ सकते हैं।

```excel
= A1>5 and B1<10
= not(A1==0)
= 10 if A1>5 else 0
```

`if` `else` टर्नरी ऑपरेटर भी सीधे समर्थित है।

## 5. व्ावहारिक उदाहरण

### 5.1. बिक्री का योग

मान लीजिए `B2:B10` में बिक्री है और आप कुल चाहते हैं:

```excel
=SUM(B2:B10)
```

### 5.2. शर्तबद्ध छूट

यदि कुल (`B12` में) 100 से अधिक है, तो 10% छूट लागू करें; अन्यथा 0:

```excel
= IF(B12>100, B12*0.9, B12)
```

### 5.3. औसत और गिनती

`C2:C20` में ग्रेड का औसत, लेकिन केवल यदि कम से कम 5 मान हैं:

```excel
= IF(COUNT(C2:C20)>=5, AVG(C2:C20), "अपर्याप्त डेटा")
```

### 5.4. संयुक्त टेक्स्ट

नाम (A2) और उपनाम (B2) को एक रिक्त स्थान के साथ जोड़ें:

```excel
= CONCAT(A2, " ", B2)
```

### 5.5. एक संख्या का वर्गमूल

```excel
= SQRT(A1)
```

### 5.6. 2 दशमलव स्थानों तक पूर्णांकन

```excel
= ROUND(A1, 2)
```

## 6. सुझाव और तरकीबें

- **रिश्तेदार/निरपेक्ष संदर्भ:** अभी के लिए, सभी संदर्भ रिश्तेदार हैं (Excel की तरह)। `$A$1` अभी तक समर्थित नहीं है।
- **गतिशील सीमा:** आप `A:A` (पूरा स्तंभ) या `1:1` (पूरी पंक्ति) जैसी सीमा का उपयोग कर सकते हैं।
- **स्वतः पूर्णता:** `=` लिखने पर उपलब्ध कार्यों के साथ एक मेनू दिखाई देता है।
- **त्रुटियाँ:** यदि कोई सूत्र अमान्य है, तो सेल `#ERROR` दिखाएगा और विस्तृत संदेश स्थिति पट्टी में होगा।
- **पुनर्गणना:** सूत्र निर्भर सेलों में संशोधन पर स्वचालित रूप से अपडेट होते हैं।
