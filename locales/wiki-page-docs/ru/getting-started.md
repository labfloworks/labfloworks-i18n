# 🚀 Первые шаги с FloWorks

Это руководство проведёт вас от нуля до запуска вашего первого потока обработки сигналов. FloWorks — это приложение для потоковых диаграмм сигналов, построенное на Python и PySide6, поддерживающее реальное оборудование (VISA/SCPI), встроенное моделирование, расширенные скрипты и смену языка на лету.

---

## 🌊 Ваш первый пример потока

Давайте создадим простой поток: сгенерируем синусоидальный сигнал и визуализируем его в реальном времени.

1. **Добавление узлов**
   На верхней панели инструментов выберите `Источник` → выберите `Расширенный генератор сигналов`. Затем из `Обработка` → выберите, например, `Спектральный`.
2. **Соединение**
   Нажмите `Ctrl+Щелчок` на выходном порту (`справа`) генератора. Затем щёлкните на входном порту (`слева`) осциллографа. Или просто щёлкните на выходном порту и перетащите (удерживая нажатой кнопку мыши) к входному порту следующего узла.
3. **Настройка (опционально)**
   Щелчок по узлу, в левой боковой панели появится редактор с параметрами выбранного узла для настройки условий работы. В нижней части находится график визуализации, который визуально предсавляет данные, сгенерированные или полученные узлами.
4. **Запуск**
   Нажмите `F5` или кнопку ▶ на панели инструментов. Топологический движок вычислит порядок выполнения, обработает данные, и вы увидите волну на графической панели. Соединитель анимируется, показывая активный поток!

## 🧠 Понимание портов: категории по цвету

В FloWorks каждый порт принадлежит **функциональной категории**, идентифицируемой цветом. Допустимые соединения выполняются **всегда между портами одного цвета**: выход категории подключается только ко входу той же категории. Кроме того, соединительная линия автоматически принимает цвет соединяемых портов, облегчая визуальное чтение.

| Тип | Цвет | Назначение | Типичный пример |
|------|-------|-----------|----------------|
| `control` | Белый | Поток управления / активация. | Сигнал запуска к узлу сбора данных. |
| `exec` | Серый | Выполнение операций или шагов. | Запуск функции или обратного вызова. |
| `data` | Зелёный | Общие данные / числовые сигналы. | Выход генератра или датчика. |
| `int` | Синий | Целые числа. | Индекс, размер буфера, ID. |
| `float` | Голубой | Числа с плавающей точкой. | Амплитуда, частота, порог. |
| `string` | Пурпурный | Текстовые строки. | Имя файла, метка. |
| `bool` | Розовый | Логические значения (`True`/`False`). | Флаг состояния, включение. |
| `array` | Тёмно-синий | Массивы / векторы. | Многоканальный сигнал, список выборок. |
| `trigger` | Оранжевый | Триггеры / дискретные события. | Синхроимпульс, фронт. |

**Золотое правило:**

- Соединяются только порты **точно одного цвета** (выход ↔ вход одной категории).
- Система предотвращает недопустимые соединения и визуально выделяет совместимые порты при перетаскивании.
- Соединительная линия принимает цвет соединённых портов; таким образом, каждый путь идентифицируется одним взглядом.

**Философия FloWorks:**  
Порты данных **сохраняют размерность** массивов. Никогда не применяется автоматическое выравнивание: если входит матрица, выходит матрица, сохраняя целостность многомерных сигнало.

## 🖱️ Навигация по Canvas

Освойте рабочее пространство с помощью этих жестов:

| Действие | Как выполнить |
|--------|--------------|
| **Масштаб** | Колёсико мыши или `Ctrl + колёсико` |
| **Панорамирование (прокрутка)** | Удерживайте `Пробел` и перетаскивайте, или используйте среднюю кнопку мыши |
| **Выбрать узел** | Левый щелчок по узлу |
| **Множественный выбор** | Перетащите прямоугольник левой кнопкой мыши, или `Ctrl + щелчок` по нескольким узлам |
| **Переместить выделение** | Перетащите любой из выбранных узлов |
| **Открыть конфигурацию** | Двойной щелчок по узлу |

**Совет:** Левая панель автоматически обновляется конфигурацией выбранного узла, без необходимости открывать дополнительные окна.

## ⚡ Горячие клавиши и продвинутые приёмы

Эти сочетания превращают обычного пользователя в **опытного**:

| Сочетание | Действие |
|-------|--------|
| `F5` | Запустить поток |
| `Ctrl + S` | Сохранить проект (`.sflow`) |
| `Ctrl + Щелчок` | Соединить узлы (щелчок на выходном порту → щелчок на входном порту) |
| `Ctrl + C` / `Ctrl + V` | Копировать / вставить выбранные узлы |
| `Ctrl + Z` / `Ctrl + Y` | Отменить / повторить |
| `Ctrl + Shift + L` | Автоупорядочивание узлов на холсте |
| `Supr` | Удалить выбранные узлы |
| `Ctrl + A` | Выбрать все узлы |

**Продвинутые приёмы:**

- **Дублировать поток:** выберит группу узлов, `Ctrl + C`, `Ctrl + V` и перетащите копию в другую зону.
- **Очистить сетку:** используйте `Ctrl + Shift + L`, чтобы упорядочить весь холст одной командой.
- **Быстрое соединение:** `Ctrl + Щелчок` на выходном порту, затем обычный щелчок на входном порту; FloWorks нарисует соединение автоматически.

## 🎨 Настройка окружения

FloWorks адаптируется к вам, а не наоборот.

### Смена темы на лету
Из верхней панели, меню **Вид → Тема**, выберите светлую, тёмную или другую. Интерфейс меняется **мгновенно**, без перезапуска и без потери рабочего потока.

### Размер шрифта
В **Вид → Размер шрифта** выберите предустановленное значение или пользовательское. Весь интерфейс моментально подстраивается.

### Язык
В **Вид → Язык** выберите желаемый язык. FloWorks поддерживает **смену на лету**: меню, кнопки и сообщения переводятся без перезапуска приложения.

## ❗ Решение распространённых проблем

| Проблема | Возможная причина | Решение |
|----------|---------------|----------|
| Поток не запускается | Есть ненастроенные узлы или разорванные соединения | Проверьте, что все узлы имеют допустимые параметры и соединения между совместимыми портами |
| График не обновляется | Поток на паузе или данные не текут | Убедитесь, что нажали `F5` или ▶, и что исходные узлы генерируют данные |
| Не моу соединить два узла | Порты разных типов | Проверьте, что оба порта относятся к **данным** или оба к **управлению** |
| Программа тормозит с большими потоками | Слишком много узлов или графиков в реальном времени | Закройте неиспользуемые панели анализа или уменьшите частоту дискретизации исходных узлов |
| Тема не меняется | Некоторые виджеты могут быть не зарегистрированы | Перезапустите приложение и попробуйте снова (в будущих версиях будет решено) |

## 🧪 Быстрые практические примеры

Помимо начального синусоидального потока, попробуйте эти мини-проекты, чтобы освоить FloWorks:

| Пример | Задействованные узлы | Ожидаемый результат |
|---------|-------------------|--------------------|
| **Фильтр нижних частот** | Генератор → Фильтр → Визуализатор графиков | Вы увидите отфильтрованный сигнал |
| **Имитированное считывание** | Генератор → Анализатор THD | значение гармонического искажения сигнала |
| **Ручное управление** | Генератор → Инспектор данных | таблица со значениями сигнала, отправленного генератором |
| **Сравнение сигналов** | Два генератора → Сумматор → Визуализатор графиков | результат операции (сложение, вычитание, умножение или деление) двух волн на одном графике |

Каждый из этих потоков можно собрать менее чем за минуту, демонстрируя проворство FloWorks по сравнению с традиционны кодом.
