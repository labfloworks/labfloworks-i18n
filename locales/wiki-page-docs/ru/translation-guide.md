# 🌐 Руководство по интернационализации (i18n)

Этот документ объясняет, как добавить новый язык в FloWorks и эффективно управлять файлами перевода.

---

## ➕ Как добавить новый язык

### Шаг 1: Создать JSON-файл
Перейдите в папку `locales/`. Скопируйте `en.json` и переименуйте, используя соответствующий двухбуквенный код [ISO 639-1](https://es.wikipedia.org/wiki/ISO_639-1) (например, `fr.json` для французского, `de.json` для немецкого).

### Шаг 2: Перевести строки
Откройте новый JSON-файл в текстовом редакторе.

!!! warning "Не изменяйте ключи"
    **Никогда не меняйте ключи** (левую сторону каждой пары). Переводите только значения (правую сторону).

**Оригинал (`en.json`):**
```json
{
  "app_title": "FloWorks",
  "menu": {
    "file": "File",
    "edit": "Edit"
  }
}
```

**Пример перевода (`es.json`):**
```json
{
  "app_title": "FloWorks",
  "menu": {
    "file": "Archivo",
    "edit": "Editar"
  }
}
```
Убедитесь, что корневой ключ `"language_name"` содержит родное название языка (например, `"Français"`, `"Deutsch"`, `"Español"`).

### Шаг 3: Проверить JSON
Убедитесь, что файл является допустимым JSON (без завершающих запятых, с првильными кавычками, с соответствующими экранированиями). Вы можете использовать онлайн-валидаторы, такие как [JSONLint](https://jsonlint.com), или выполнить:
```bash
python -m json.tool locales/es.json
```

### Шаг 4: Протестировать новый язык
1. Запустите FloWorks.
2. Перейдите в **INFO → Язык** и выберите новый язык.
3. Проверьте, что все элементы интерфейса обновляются немедленно (меню, панели, диалоги, метки узлов и т.д.).

### Шаг 5: Автоматическое определение (опционально)
Если языковой стандарт системы пользователя совпадает с кодом нового языка, FloWorks автоматически использует его при первом запуске (если ранее не была сохранена предпочтительная настройка в `QSettings`).

## 🌍 Доступные языки
- **Английский** (`en`) – Базовый / резервный язык
- **Испанский** (`es`)

---

## ⚙️ Важные замечания и хорошие практики

!!! info "Механизм резерва"
    Базовым языком является **английский**. Если в языковом файле отсутствует ключ перевода, FloWorks автоматически использует английскую строку в качестве резерва.

!!! warning "Предотвращение переполнения интерфейса"
    Держите переводы краткими, чтобы избежать нарушений макета. Если переведённый текст значительно длиннее, рассмотрите возможность сокращения или полагайтесь на систему тем для обработки динамического масштабирования.

!!! tip "Сохранение HTML и заполнителей"
    - **HTML-теги:** Сохраняйте все HTML-теги точно в том виде, в каком они есть (например, `<h3>`, `<b>`, `<pre>`, `<br>`).
    - **Заполнители:** Сохраняйте синтаксис `{variable}` там, где он используется (например, `"Язык изменён на: {name} ({code})"`). Не изменяйте их порядок и не удаляйте.
