# Sticky Notes (Липкие заметки) – Руководство пользователя

## Что такое липкие заметки?

Липкие заметки (или *sticky notes*) — это небольшие текстовые блоки, которые можно свободно размещать на диаграмме. Они служат для:

- Добавления напоминаний, заголовков или пояснений прямо на холсте.
- Создания пошаговых руководств, которые помогают пользователю работать с проектом.
- Документирования частей рабочего процесса без необходимости выходить из FloWorks.
- Оставления комментариев для себя или других участников.

Заметки можно изменять в размере (потянув за уголки), перемещать в любое место диаграммы и сохранять вместе с проектом. При открытии файла `.sflow` все заметки появляются точно там, где вы их оставили.

---

## Новинка: многоязычные заметки

Липкие заметки могут автоматически отображать текст на языке, который вы выбрали для приложения.  
Вместо того чтобы писать сообщение на одном языке, вы можете вставить **специальные маркеры**, которые автоматически переведутся при смене языка FloWorks.

Таким образом, одна и та же заметка может читаться на испанском, английском или любом другом доступном языке без необходимости редактировать текст каждый раз.

---

## Как написать многоязычную заметку

Внутри заметки (создайте её двойным щелчком или кнопкой 📝 на панели инструментов) можно использовать два типа маркеров:

### 1. С помощью слова `tr(…)`
Напишите `tr("ключ")` и замените `ключ` описательным именем фразы.

Пример:

```
tr("tutorial.paso1.titulo")
tr("tutorial.paso1.mensaje")
```

### 2. С помощью двойных фигурных скобок `{{…}}`
Напишите `{{ключ}}` аналогичным образом.

Пример:

```
{{tutorial.paso1.titulo}}
{{tutorial.paso1.mensaje}}
```

Оба формата работают одинаково; выберите тот, который вам удобнее (можно даже комбинировать их в одной заметке).

> **Важно**: Текст, который вы видите при редактировании заметки, содержит исходные маркеры (например, `{{tutorial.paso1.titulo}}`).  
> Когда вы закончите редактировать и вернётесь к обычному виду диаграммы, маркеры заменятся на фразу, переведённую на текущий язык приложения.

---

## Поведение при смене языка

- Если вы смените язык в меню FloWorks (например, с испанского на английский), **все липкие заметки, содержащие маркеры, обновятся автоматически**.
- Нет необходимости закрывать и снова открывать проект или редактировать каждую заметку вручную.
- Заметки, содержащие только обычный текст (без маркеров), не изменяются; они отображают одно и то же на любом языке.

---

## Преимущества использования маркеров

- **Мгновенные многоязычные руководства** – Одна и та же заметка подходит для пользователей разных языков.
- **Согласованность** – Если вы измените перевод в одном месте (в языковом файле, который поддерживает ваша команда разработки), все заметки, использующие этот ключ, обновятся.
- **Простота обслуживания** – Вы можете написать содержимое один раз и использовать его повторно в нескольких заметках.
- **Гибкость** – Комбинируйте фиксированный текст с маркерами. Например:

```
🎯 ШАГ 1
{{tutorial.paso1.titulo}}
{{tutorial.paso1.mensaje}}
```

---

## Практический пример: пошаговое руководство

Предположим, вы хотите добавить заметку, объясняющую первый шаг руководства.  
В режиме редактирования вы пишете:

```
🎯 ШАГ 1
{{tutorial.paso1.titulo}}
{{tutorial.paso1.mensaje}}
```

Когда вы закончите редактировать и используете приложение на испанском, увидите:

```
🎯 PASO 1
¡Bienvenido a FloWorks!
Arrastre un nodo fuente de señal para comenzar.
```

Если вы смените язык на английский, та же заметка отобразит:

```
🎯 STEP 1
Welcome to FloWorks!
Drag a signal source node to begin.
```

И так далее для любого другого настроенного языка.

---

## Резюме

- Липкие заметки обогащают диаграммы текстовой информацией.
- Теперь они могут быть **многоязычными** с помощью маркеров `tr("ключ")` или `{{ключ}}`.
- При редактировании вы видит ключи; при просмотре — переведённый текст.
- Смените язык приложения, и все заметки мгновенно адаптируются.
- Идеально подходит для создания визуальной документации, руководств или уведомлений, которые должны работать на нескольких языках.

Используйте эту функцию, чтобы сделать ваши проекты более доступныи и удобными для совместного использования!
