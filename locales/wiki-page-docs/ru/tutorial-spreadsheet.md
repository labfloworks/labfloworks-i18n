# 📊 Руководство по электронной таблице

Базовая электронная таблица в стиле Excel, лёгкая и встраиваемая.  

---

## 1. Что такое Spreadsheet?

Это компонент электронной таблицы, который предлагает:

- Ячейки с поддержкой формул (начинаются с `=`)
- Предопределённые функции (SUM, AVG, УСЛОВНЫЕ и т.д.)
- Арифметические, логические и операторы сравнения
- Минималистичный интерфейс, идеальный для интеграции в приложения Qt

---

## 2. Базовая навигация

- Щёлкните по ячейке, чтобы выбрать её.
- Пишите напрямую, чтобы ввести текст или числа.
- Для ввода **формулы** начните с `=` (например, `=SUM(A1:A5)`).
- Нажмите **Enter**, чтобы подтвердить редактирование.
- Используйте клавиши со стрелками или мышь для перемещения.

---

## 3. Формулы: доступные функции

Все функции пишутся заглавными буквами и поддерживают диапазоны (например, `A1:A5`) или аргументы, разделённые запятыми.

| Функция                  | Что делает                          | Пример                        |
| ------------------------ | --------------------------------- | ------------------------------ |
| `SUM`                    | Суммирует числа                      | `=SUM(A1:A5)`                  |
| `AVG` / `AVERAGE`        | Среднее значение                          | `=AVG(A1:A5)`                  |
| `COUNT`                  | Считает числа (непустые)        | `=COUNT(A1:A5)`                |
| `MAX`                    | Максимальное значение                      | `=MAX(A1:A5)`                  |
| `MIN`                    | Минимальное значение                      | `=MIN(A1:A5)`                  |
| `ABS`                    | Абсолютное значение                    | `=ABS(A1)`                     |
| `ROUND`                  | Округляет (2-й аргумент = десятичные знаки) | `=ROUND(A1, 2)`               |
| `IF`                     | Условие (если, то, иначе) | `=IF(A1>10, "Да", "Нет")`       |
| `CONCAT` / `CONCATENATE` | Объединяет тексты                        | `=CONCAT(A1, " ", B1)`         |
| `LEN`                    | Длина текста                 | `=LEN(A1)`                     |
| `INT`                    | Целая часть                      | `=INT(A1)`                     |
| `SQRT`                   | Квадратный корень                     | `=SQRT(A1)`                    |

### 3.1. Примечания о функциях

- Диапазоны указываются с помощью **двоеточия**: `A1:A5` включает все ячейки от A1 до A5.
- Функции можно вкладывать друг в друга: `=SUM(A1:A5) + MAX(B1:B5)`.
- Текстовые аргументы должны быть в двойных или одинарных кавычках.

## 4. Операторы без функций

Помимо функций, вы можете использовать операторы напрямую в формуле. Синтаксис похож на Python.

### 4.1. Арифметические

| Операция      | Пример                   |
| -------------- | ------------------------- |
| Сложение           | `=A1+A2+A3`               |
| Вычитание          | `=A1-A2`                  |
| Умножение | `=A1*B1`                  |
| Деление       | `=A1/B1`                  |
| Остаток         | `=A1%B1`                  |
| Степень       | `=A1**2`  (или `=A1^2`)     |

### 4.2. Сравнения

Возвращают `True` или `False` (отображаются как `Истина` / `Ложь`).

| Оператор | Значение       | Пример            |
| -------- | ----------------- | ------------------ |
| `>`      | Больше         | `=A1>B1`           |
| `<`      | Меньше         | `=A1<B1`           |
| `>=`     | Больше или равно     | `=A1>=10`          |
| `<=`     | Меньше или равно     | `=A1<=10`          |
| `==`     | Равно             | `=A1==B1`          |
| `!=`     | Не равно          | `=A1!=B1`          |

### 4.3. Логические и условные

Вы можете комбинировать условия с помощью `and`, `or`, `not`.

```excel
= A1>5 and B1<10
= not(A1==0)
= 10 if A1>5 else 0
```

Тернарный оператор `if` `else` также поддерживается напрямую.

## 5. Практические примеры

### 5.1. Сумма продаж

Предположим, у вас есть продажи в `B2:B10`, и вы хотите получить итог:

```excel
=SUM(B2:B10)
```

### 5.2. Условная скидка

Если итог (в `B12`) превышает 100, примените скидку 10 %; иначе 0:

```excel
= IF(B12>100, B12*0.9, B12)
```

### 5.3. Среднее и количество

Среднее оценок в `C2:C20`, но только если есть хотя бы 5 значений:

```excel
= IF(COUNT(C2:C20)>=5, AVG(C2:C20), "Недостаточно данных")
```

### 5.4. Объединение текста

Объединить имя (A2) и фамилию (B2) с пробелом:

```excel
= CONCAT(A2, " ", B2)
```

### 5.5. Квадратный корень числа

```excel
= SQRT(A1)
```

### 5.6. Округление до 2 десятичных знаков

```excel
= ROUND(A1, 2)
```

## 6. Советы и хитрости

- **Относительные/абсолютные ссылки:** пока что все ссылки относительные (как в Excel). `$A$1` пока не поддерживается.
- **Динамические диапазоны:** можно использовать диапазоны типа `A:A` (весь столбец) или `1:1` (вся строка).
- **Автодополнение:** при вводе `=` появляется меню с доступными функциями.
- **Ошибки:** если формула неверна, ячейка покажет `#ERROR`, а подробное сообщение — в строке состояния.
- **Пересчёт:** формулы обновляются автоматически при изменении зависимых ячеек.

**Как экспортировать данные?**  
Пока нет встроенного экспорта, но вы можете получить доступ к данным через внутреннюю модель.

**Поддерживае ли графики?**  
Нет, это базовая электронная таблица. Вы можете комбинировать её с другими виджетами для визуализации.
