# Sticky Notes (스티키 노트) – 사용자 가이드

## 스티키 노트란?

스티키 노트(*sticky notes*)는 다이어그램 위에 자유롭게 배치할 수 있는 작 텍스트 블록입니다. 다음과 같은 용도로 사용됩니다:

- 캔버스에 직접 알림, 제목 또는 설명을 추가합니다.
- 프로젝트를 사용하는 사람을 안내하는 단계별 튜토리얼을 만듭니다.
- FloWorks를 종료하지 않고도 워크플로의 일부를 문서화합니다.
- 자신이나 다른 협력자를 위해 코멘트를 남깁니다.

노트는 크기 조절(모서리를 드래그), 다이어그램의 어느 곳으로든 이동이 가능하며 프로젝트와 함께 저장됩니다. `.sflow` 파일을 열면 모든 노트가 정확히 놓인 위치에 나타납니다.

---

## 새로운 기능: 다국어 노트

스티키 노트는 이제 애플리케이션에서 선택한 언어로 텍스트를 자동으로 표시할 수 있습니다.  
메시지를 하나의 언어로만 작성하는 대신, **특수 마커**를 삽입할 수 있으며, FloWorks의 언어를 변경하면 해당 마커가 자동으로 번역됩니다.

이렇게 하면 동일한 노트를 스페인어, 영어 또는 사용 가능한 다른 언어로 매번 텍스트를 편집하지 않고도 읽을 수 있습니다.

---

## 다국어 노트 작성 방법

노트 내부(노트는 두 번 클릭하거나 도구 모음의 📝 버튼으로 생성)에서 두 가지 유형의 마커를 사용할 수 있습니다:

### 1. `tr(…)` 단어 사용
`tr("키")`를 작성하고 `키`를 문구의 설명적인 이름으로 바꿉니다.

예시:

```
tr("tutorial.paso1.titulo")
tr("tutorial.paso1.mensaje")
```

### 2. 이중 중괄호 `{{…}}` 사용
`{{키}}`를 동일한 방식으로 작성합니다.

예시:

```
{{tutorial.paso1.titulo}}
{{tutorial.paso1.mensaje}}
```

두 형식은 동일하게 작동합니다. 더 편한 것을 선택하세요(같은 노트 안에서 혼합해서 사용할 수도 있습니다).

> **중요**: 노트를 편집할 때 보이는 텍스트는 원래 마커를 포함합니다(예: `{{tutorial.paso1.titulo}}`).  
> 편집을 마치고 다이어그램의 일반 보기로 돌아가면, 마커가 애플리케이션의 현재 언어로 번역된 문구로 대체됩니다.

---

## 언어 변경 시 동작

- FloWorks 메뉴에서 언어를 변경하면(예: 스페인어에서 영어로), **마커가 포함된 모든 스티키 노트가 자동으로 업데이트됩니다**.
- 프로젝트를 닫고 다시 열거나 각 노트를 수동으로 수정할 필요가 없습니다.
- 일반 텍스트만 포함된 노트(마커 없음)는 영향을 받지 않습니다. 어떤 언어에서도 동일하게 표시됩니다.

---

## 마커 사용의 장점

- **즉각적인 다국어 튜토리얼** – 동일한 노트가 여러 언어 사용자를 안내할 수 있습니다.
- **일관성** – 한 곳(개발 팀이 유지 관리하는 언어 파일)에서 번역을 수정하면 해당 키를 사용하는 모든 노트가 업데이트됩니다.
- **간편한 유지 관리** – 콘텐츠를 한 번 작성하고 여러 노트에서 재사용할 수 있습니다.
- **유연성** – 고정 텍스트와 마커를 결합할 수 있습니다. 예를 들어:

```
🎯 1단계
{{tutorial.paso1.titulo}}
{{tutorial.paso1.mensaje}}
```

---

## 실용 예시: 단계별 튜토리얼

튜리얼의 첫 번째 단계 설명하는 노트를 추가하고 싶다고 가정해 보겠습니다.  
편집 모드에서 다음과 같이 작성합니다:

```
🎯 1단계
{{tutorial.paso1.titulo}}
{{tutorial.paso1.mensaje}}
```

편집을 마치고 애플리케이션을 스페인어로 사용 중이라면 다음과 같이 표시됩니다:

```
🎯 PASO 1
¡Bienvenido a FloWorks!
Arrastre un nodo fuente de señal para comenzar.
```

언어를 영어로 변경하면 동일한 노트가 다음과 같이 표시됩니다:

```
🎯 STEP 1
Welcome to FloWorks!
Drag a signal source node to begin.
```

구성된 다른 언어에 대해서도 마찬가지입니다.

---

## 요약

- 스티키 노트는 텍스트 정보로 다이어그램을 풍부하게 만듭니다.
- 이제 `tr("키")` 또는 `{{키}}` 마커를 사용하여 **다국어**가 가능합니다.
- 편집할 때는 키를 보고, 보기 모드에서는 번역된 텍스트가 표시됩니다.
- 애플리케이션 언어를 변경하면 모든 노트가 즉시 적응합니다.
- 여러 언어로 작동해야 하는 시각 문서, 튜토리얼 또는 알림을 만드는 데 이상적입니다.

이 기능을 활용하여 프로젝트를 더 접근하기 쉽고 공유하기 쉽게 만드세요!
