# 📊 스프레드시트 튜토리얼

Excel 스타일의 가벼운 임베드 가능한 기본 스프레드시트입니다.  

---

## 1. 스프레드시트란?

다음을 제공하는 스프레드시트 구성 요소입니다:

- 수식을 지원하는 셀 (`=`로 시작)
- 미리 정의된 함수(SUM, AVG, 조건부 등)
- 산술, 논리 및 비교 연산자
- Qt 애플리케이션에 통합하기에 이상적인 미니멀한 인터페이스

---

## 2. 기본 탐색

- 셀을 클릭하여 선택합니다.
- 텍스트나 숫자를 입력하려면 직접 입력합니다.
- **수식**을 입력하려면 `=`로 시작합니다(예: `=SUM(A1:A5)`).
- 편집을 확인하려면 **Enter**를 누릅니다.
- 이동하려면 화살표 키나 마우스를 사용합니다.

---

## 3. 수식: 사용 가능한 함수

모든 함수는 대문자로 작성되며 범위(예: `A1:A5`) 또는 쉼표로 구분된 인수를 지원합니다.

| 함수                  | 기능                          | 예시                        |
| ------------------------ | --------------------------------- | ------------------------------ |
| `SUM`                    | 숫자 합산                      | `=SUM(A1:A5)`                  |
| `AVG` / `AVERAGE`        | 평균                          | `=AVG(A1:A5)`                  |
| `COUNT`                  | 숫자 개수 세기(비어 있지 않음)        | `=COUNT(A1:A5)`                |
| `MAX`                    | 최댓값                      | `=MAX(A1:A5)`                  |
| `MIN`                    | 최솟값                      | `=MIN(A1:A5)`                  |
| `ABS`                    | 절댓값                    | `=ABS(A1)`                     |
| `ROUND`                  | 반올림(2번째 인수 = 소수점 자리) | `=ROUND(A1, 2)`               |
| `IF`                     | 조건부(만약, 그러면, 그렇지 않으면) | `=IF(A1>10, "예", "니오")`       |
| `CONCAT` / `CONCATENATE` | 텍스트 연결                        | `=CONCAT(A1, " ", B1)`         |
| `LEN`                    | 텍스트 길이                 | `=LEN(A1)`                     |
| `INT`                    | 정수 부분                      | `=INT(A1)`                     |
| `SQRT`                   | 제곱근                     | `=SQRT(A1)`                    |

### 3.1. 함수에 대한 참고 사항

- 범위는 **콜론**으로 표시됩니다: `A1:A5`는 A1부터 A5까지의 모든 셀을 포함합니다.
- 함수는 중첩될 수 있습니다: `=SUM(A1:A5) + MAX(B1:B5)`.
- 텍스트 인수는 큰따옴표나 작은따옴표로 묶어야 합니다.

---

## 4. 함수 없는 연산자

함수 외에도 수식에서 직접 연산자를 사용할 수 있습니다. 구문은 Python과 유사합니다.

### 4.1. 산술

| 연산      | 예시                   |
| -------------- | ------------------------- |
| 덧셈           | `=A1+A2+A3`               |
| 뺄셈          | `=A1-A2`                  |
| 곱셈 | `=A1*B1`                  |
| 나눗셈       | `=A1/B1`                  |
| 나머지         | `=A1%B1`                  |
| 거듭제곱       | `=A1**2`  (또는 `=A1^2`)     |

### 4.2. 비교

`True` 또는 `False`를 반환합니다(표시는 `참` / `거짓`).

| 연산자 | 의미       | 예시            |
| -------- | ----------------- | ------------------ |
| `>`      | 보다 큼         | `=A1>B1`           |
| `<`      | 보다 작음         | `=A1<B1`           |
| `>=`     | 보다 크거나 같음     | `=A1>=10`          |
| `<=`     | 보다 작거나 같음     | `=A1<=10`          |
| `==`     | 같음             | `=A1==B1`          |
| `!=`     | 같지 않음          | `=A1!=B1`          |

### 4.3. 논리 및 조건부

`and`, `or`, `not`으로 조건을 결합할 수 있습니다.

```excel
= A1>5 and B1<10
= not(A1==0)
= 10 if A1>5 else 0
```

`if` `else` 삼항 연산자도 직접 지원됩니다.

---

## 5. 실용 예시

### 5.1. 판매 합계

`B2:B10`에 판매 데이터가 있고 합계를 원한다고 가정합니다:

```excel
=SUM(B2:B10)
```

### 5.2. 조건부 할인

합계(`B12`)가 100을 초과하면 10% 할인을 적용하고, 그렇지 않으면 0:

```excel
= IF(B12>100, B12*0.9, B12)
```

### 5.3. 평균 및 개수

`C2:C20`의 성적 평균이지만 값이 5개 이상인 경우에만:

```excel
= IF(COUNT(C2:C20)>=5, AVG(C2:C20), "데이터 부족")
```

### 5.4. 결합된 텍스트

이름(A2)과 성(B2)을 공백으로 연결:

```excel
= CONCAT(A2, " ", B2)
```

### 5.5. 숫자의 제곱근

```excel
= SQRT(A1)
```

### 5.6. 소수점 2자리 반올림

```excel
= ROUND(A1, 2)
```

---

## 6. 팁과 요령

- **상대/절대 참조:** 현재로서는 모든 참조가 상대적입니다(Excel과 동일). `$A$1`은 아직 지원되지 않습니다.
- **동적 범위:** `A:A`(전체 열) 또는 `1:1`(전체 행)과 같은 범위를 사용할 수 있습니다.
- **자동 완성:** `=`를 입력하면 사용 가능한 함수 목록이 나타납니다.
- **오류:** 수이 잘못되면 셀에 `#ERROR`가 표시되고 자세한 메시지는 상태 표시줄에 나타납니다.
- **재계산:** 수식은 종속 셀을 수정하면 자동으로 업데이트됩니다.
