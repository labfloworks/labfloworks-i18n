## 주 도구 모음: 구성 및 철학

상단 도구 모음은 FloWorks의 **빠른 명령 센터**입니다. 디자인은 워크플로 논리를 따릅니다: 왼쪽에서 오른쪽으로, 세션 중에 필요한 순서대로 작업을 찾을 수 있습니다.

```mermaid
graph LR
    A[로고 / 아이덴티티] --> B[프로젝트<br/>파일 · 편집 · 보기]
    B --> C[노드<br/>소스 · 처리 · 제어 · ...]
    C --> D[빠른 도구<br/>노트 · 자동 정렬]
    D --> E[주요 작업<br/>흐름 실행]
    E --> F[도움말<br/>정보 · 단축키 · 튜토리얼]
```

![그룹이 강조 표시된 전체 도구 모음](assets/FloWorks_GUI_6.PNG)

### 그룹별 구성

도구 모음은 **6개의 기능 그룹**으로 나뉘어 있으며, 미세한 수직선으로 구분됩니다. 각 그룹은 관련 작업을 함께 묶어 흩어진 메뉴를 검색할 필요가 없도록 합니다.

---

### 1. 아이덴티티 (로고)

가장 왼쪽 끝에 **FloWorks 로고**가 보입니다. 단순한 장식이 아닙니다: 클릭하 **환영 대화 상자**가 열리며, 일반 정보와 사용 철학이 포함되어 있습니다.

- **툴팁:** "FloWorks 정보 및 환영".

**철학:** 로고는 메뉴 공간을 차지하지 않고 아이덴티티와 초기 도움말에 접근할 수 있는 지점 역할을 합니다.

![도구 모음의 로고 및 선택적으로 열린 환영 대화 상자](assets/FloWorks_Welcome.PNG)

---

### 2. 프로젝트: 파일, 편집 및 보기

프로젝트 관리 및 인터페이스 모양과 관련된 작업을 그룹화합니다.

#### 📁 파일
- **새로 만들기**: 빈 흐름을 만듭니다.
- **열기**: 기존 프로젝트를 로드합니다.
- **저장 / 다른 이름으로 저장**: 현재 흐름을 저장합니다.
- **종료**: 애플리케이션을 닫습니다.

#### ✂️ 편집
- **실행 취소 / 다시 실행**: Canvas에서 변경 사항을 되돌리거나 복원합니다.
- **잘라내기 / 복사 / 붙여넣기**: 선택한 노드를 조작합니다.
- **환경 설정**: 전역 구성 창을 엽니다.

#### 👁️ 보기
이 메뉴는 인터페이스가 사용자 환경 설정 맞게 표시되고 조정되는 방식을 제어합니다:

- **언어**: 전체 애플리케이션의 언어를 변경합니다(메뉴, 버튼, 메시지).
- **테마**: 시각적 테마(밝음, 어두움 등) 간에 즉시 전환합니다.
- **글꼴 크기**: 사전 설정 및 사용자 정의 옵션으로 전체 인터페이스의 텍스트 크기를 조정합니다.
- **로그 뷰어**: 애플리케이션의 내부 로그를 표시합니다(고급 디버깅에 유용).

**철학:** "내 프로젝트와 내 작업 환경"과 관련된 모든 것이 함께 있지만, 노드를 추가하거나 실행하는 작업과는 분리되어 있습니다.

---

### 3. 노드 (범주별)

이 그룹은 FloWorks에서 사용 가능한 **노드 카탈로그에서 자동 생성**됩니다. 수동으로 코딩되지 않습니다: 프로그램에 새 노드가 추가되면 해당 범주가 여기에 자동으로 나타납니다.

일반적인 범주는 다음과 같습니다:

- **소스** (신호 생성기, 데이터 입력).
- **처리** (필터, 수학적 변환).
- **제어** (흐름 논리, 조건부).
- **출력** (싱크, 시화 도구, 익스포터).
- 커뮤니티 또는 사용자 정의 노드에 의해 정의된 기타 범주.

**지능형 동작:**

- 범주에 **노드가 하나**만 포함된 경우, 도구 모음은 해당 이름의 버튼을 직접 표시합니다. 클릭하면 해당 노드가 Canvas에 추가됩니다.
- **여러 노드**가 포함된 경우, 모든 노드를 포함하는 드롭다운 메뉴가 표시됩니다. 하나를 선택하면 Canvas에 배치됩니다.

**철학:** 노드에 대한 액세스는 항상 표되며, 측면 패널을 열 필요가 없습니다. 도구 모음은 카탈로그에 맞게 조정되며 일관성을 유지하고 수동 구성을 피합니다.

---

### 4. 빠른 도구

직접적인 생산성을 위한 두 개의 버튼:

- **📝 스티키 노트**: 흐름의 일부를 문서화하기 위해 Canvas에 시각적 노트를 추가합니다.
- **🔧 자동 정렬**: 한 번의 클릭으로 Canvas의 모든 노드를 정돈되고 읽기 쉬운 순서로 재배치합니다.

**철학:** 이 작업은 자주 사용되며 메뉴에 숨겨질 가치가 없습니다. 한 번 클릭하면 완료됩니다.

![노트 및 정렬 버튼 강조 표시](assets/FloWorks_GUI_7.PNG)

### 5. 주요 작업: 흐름 실행

**실행** 버튼은 색상 테두리(일반적으로 녹색)와 "재생" 아이콘으로 시각적으로 강조 표시됩니다. 이는 도구 모음에서 가장 눈에 띄는 버튼입니다. FloWorks의 핵심 작업인 **데이터 흐름 시작**을 나타내기 때문입니다.

- 클릭하면 **현재 흐름이 실행**되고 하단 그래프 및 데이터 테이블이 업데이트됩니다.
- 버튼을 누르면 외관이 약간 변경되어 촉각적 피드백을 제공합니다.

**철학:** 가장 중요한 작업은 가장 눈에 띄어야 합니다. 실행하려면 메뉴를 탐색할 필요가 없습니다. 항상 한 번의 클릭으로 가능합니다.

![실행 버튼 강조 표시, 그리고 실행 중인 흐름](assets/FloWorks_GUI_9.PNG)

---

### 6. 도움말

도구 모음의 끝에 **도움말** 메뉴가 있으며, 다음으로 직접 액세스할 수 있습니다:

- **정보**: 버전 및 프로젝트에 대한 세부 정보.
- **키보드 단축키**: 고급 사용자를 위한 조합 목록.
- **튜토리얼**: FloWorks를 배우기 위한 단계별 가이드.

**철학:** 도움말은 항상 사용 가능하지만 워크플로우에서 벗어나 방해가 되지 않습니다.

![열린 도움말 메뉴](assets/FloWorks_GUI_10.PNG)

---

### 적응형 기능

- **즉각적인 번역**: 보기 메뉴에서 언어를 변경하면 **도구 모음의 모든 텍스트가 즉시 업데이트**되며, 재시작이 필요 없습니다.
- **테마 및 글꼴 크기**: 도구 모음은 즉시 새로운 시각적 스타일로 다시 그려집니다.
- **동적 카탈로그**: 프로그램에 새 노드가 추가되면 해당 범주가 도구 모음에 자동으로 나타납니다. 수동 개입이 필요 없습니다.

**요약:** 도구 모음은 **직관적이고 빠르며 적응 가능**하도록 설계되었습니다. 자연스러운 워크플로를 따릅니다: 프로젝트 구성 → 편집 → 노드 추가 → 실행 → 도움말 참조. 나머지는 길에서 벗어나 있지만 필요할 때 액세스할 수 있습니다.
