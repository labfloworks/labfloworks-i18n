# FloWorks 아키텍처 – 사용자 관점

FloWorks는 플로우 다이어그램을 통해 신호 처리 체인을 구축할 수 있는 데스크톱 애플리케이션입니다. 인터랙티브한 Canvas에서 블록(노드)을 연결하고 실시간으로 결과를 확인할 수 있습니다. 이를 가능하게 하기 위해 애플리케이션은 여러 모듈로 구성되어 함께 작동합니다. 아래에서는 기술적 세부 사항 없이 각 부분이 무엇을 하는지, 그리고 서로 어떻게 관련되는지 설명합니다.

---

## 전체 구조

애플리케이션은 다음과 같은 기능 영역으로 구성됩니다:

| 영역 | 기능 |
|------|------|
| **시작 및 메인 윈도우** | 프로그램을 시작하고, 윈도우와 메뉴를 표시하며, 사용자의 모든 작업을 조율합니다. |
| **실행 엔진** | 노드가 실행되어야 할 순서를 계산하고, 의존성과 루프를 감지하며, 데이터를 한 노드에서 다른 노드로 전달합니다. |
| **씬 및 다이어그램** | 노드를 배하고, 노드 간 연결, 스티키 노트, 실행 취소/다시 실행 작업을 관리하는 Canvas를 관리합니다. |
| **노드 및 처리** | 사용할 수 있는 모든 블록 유형을 포함합니다: 신호 소스, 수학 연산, 사용자 정의 스크립트, 그래프 내보내기 등. |
| **시각적 커넥터** | 노드를 연결하는 선(부드러운 곡선 또는 직교 경로)을 그리고, 데이터 흐름을 보여주기 위해 애니메이션을 적용하며, 겹침을 방지합니다. |
| **사용자 인터페이스** | 다이어그램 뷰(줌, 이동), 도구 모음, 매개변수 테이블, 분석 패널(통계, 커서), 구성 대화 상자를 포함합니다. |
| **실제 하드웨어 지원** | 실제 신호를 캡처하거나 생성하기 위해 실험실 기기(오실로스코프, 생성기, LCR 멀티미터)와 통신할 수 있게 합니다. |
| **그래프 내보내기** | 완전한 시각적 사용자 정의를 통해 고품질 이미지(PNG, PDF, SVG)를 생성합니다. |
| **테마 및 모양** | 전체 애플리케이션의 모양(어두움, 밝음, 고대비)을 변경하고 글꼴 크기를 조정할 수 있게 합니다. |
| **언어** | 전체 인터페이스를 여러 언어로 번역하고 즉시 언어를 변경할 수 있게 합니다. |
| **프로젝트 관리** | 설정, 스크립트 및 결과를 포함한 전체 다이어그램이 있는 `.sflow` 파일을 저장하고 엽니다. |
| **테스트 및 진단** | 모든 것이 올바르게 작동하는지 확인하는 내부 도구(최종 사용자에게는 보이지 않음). |

## 내부 작동 방식

### 시작 및 메인 윈도우
FloWorks를 열면 그래픽 환경이 구성되고, 화면의 픽셀 밀도가 감지되어(4K 및 일반 모니터에서 모든 것이 선명하게 보이도록) 메인 윈도우가 표시됩니다. 이 윈도우는 모든 요소를 중앙에서 관리합니다: 드로잉 영역, 메뉴, 도구 모음 및 측면 패널.

### 흐름 엔진
사용자가 "실행"을 누르거나(또는 F5를 누르면) 내부 엔진이 연결을 존중하면서 모든 노드를 올바른 순서로 순회합니다. 어떤 노드가 다른 노드에 의존하는지 알고 있으며 무한 루프를 방지합니다. 하나의 노드가 여러 명명된 입력을 받고 여러 출력을 생성하는 것을 지원합니다. 데이터는 원래 구조를 잃지 않고 노드 간에 이동합니다.

### 다이어그램 씬
다이어그램을 구축하는 Canvas는 지능형 씬입니다:

- 노드를 추가, 이동, 연결 및 선택할 수 있습니다.
- 모든 작업에 대해 무제한 실행 취소 및 다시 실행을 지원합니다.
- 프로젝트와 함께 저장되는 자유롭게 배치할 수 있는 크기 조정 가능한 스티키 노트가 포함되어 있습니다.
- Ctrl+Shift+L을 눌러 노드를 정돈된 방식으로 재배치하는 자동 정렬 기능이 있습니다.
- 저장 시 전체 다이어그램이 `.sflow` 파일로 패키지되어 노드 설명, 연결, 노트 및 관련 숫자 데이터를 포함합니다.

### 커넥터
노드를 연결하는 선은 부드러운 곡선 또는 직교 경로로 그려집니다. 점이나 대시의 부드러운 애니메이션이 흐름 방향을 나타냅니다. 레인 관리자는 동일한 노드 간의 여러 연결이 쌓이는 것을 방지하며, 자동으로 분리하여 모든 것을 읽을 수 있게 합니다.

### 노드 유형
노드는 기본 구성 요소입니다. 세 가지 범주로 그룹화됩니다:

- **소스** – 신호를 생성합니다. 파형(정현파, 사각파 등)을 시뮬레이션하거나 연결된 오실로스코프 또는 멀티미터에서 실제 데이터를 읽을 수 있습니다. 동시에 여러 채널을 지원합니다(예: LCR의 임피던스 및 위상).
- **처리** – 데이터를 변환합니다. 산술 연산(덧셈, 뺄셈, 곱셈, 나눗셈), 조건부 결정(예/아니오 분기) 및 시각적 도움말이 있는 사용자 고유의 Python 코드를 작성할 수 있는 강력한 스크립트 노드를 포함합니다.
- **싱크** – 결과를 표시하거나 내보냅니다. 가장 일반적인 것은 그래픽 시각화 도구(가상 오실로스코프)이지만 전문가 수준의 그래프 익스포터도 존재합니다.

각 노드에는 입력 포트(왼쪽/위)와 출력 포트(오른쪽/아래)가 있습니다. 출력 포트를 입력 포트에 연결하면 신호가 그 사이를 흐릅니다.

#### 고급 스크립트 노드
스크립트 노드는 특별히 언급할 가치가 있습니다. FloWorks를 떠나지 않고 자신만의 처리를 추가하려는 고급 사용자를 위해 설계되었습니다. 제공하는 기능:

- 구문 강조, 자동 완성 및 줄 번호가 있는 편집기.
- 코드를 건드리지 않고 노드 패널에서 편집 가능한 매개변수를 정의할 수 있는 기능(예: 스크립트에서 사용되는 숫자 값).
- 동적 입력 및 출력 포트: 스크립트에 특수 주석을 추가하여 새 커넥터를 만들 수 있습니다.
- 영구 메모리: 실행 간에 값을 유지하는 특수 변수(`persist`)로, 누산기 또는 상태 기계에 유용합니다.
- 미리 준비된 스크립트 템플릿 및 자신만의 템플릿을 저장하는 옵션.
- 통합 도움말 시스템 및 실행 오류를 표시하는 콘솔.

### 사용자 인터페이스
Canvas 외에도 인터페이스에는 다음이 포함됩니다:

- 범주별로 정리된 모든 노드, 언어/테마/글꼴 크기 메뉴 및 로그 뷰어에 액세스할 수 있는 **도구 모음**.
- 선택한 노드의 정보를 표시하고 잠재적 비호환성(예: 길이가 다른 신호로 작업하려는 시도)을 강조 표시하는 **매개변수 테이블**.
- **도킹 가능한 분석 패널**: 통계(최대, 최소, RMS), 차이 측정을 위한 A/B 커서, 피크 마커가 있는 크로스헤어.
- 화면 해상도에 맞게 조정되고 초기 옵션을 제공하는 **환영 대화 상자**.

### 실제 기기 연결
호환 가능한 하드웨어가 있는 경우(Siglent SDS 오실로스코프, LCR 멀티미터, SDG 생성기), FloWorks는 표준 VISA/SCPI 프로토콜을 통해 이들과 통신할 수 있습니다. 구성은 애플리케이션 내의 특정 패널에서 수행됩니다. 다중 채널 신호(예: LCR의 크기 및 위상)를 캡처할 때 소스 노드는 모든 채널을 패키징하고 간단한 컨텍스트 메뉴로 어떤 것을 시각화할지 선택할 수 있습니다.

### 전문 그래프 내보내기
그래프 익스포터 노드를 사용하면 보고서나 출판물에 적합한 이미지를 생성할 수 있습니다. 이를 두 번 클릭하면 여러 옵션이 있는 대화 상자가 열립니다: 색상, 선 유형, 레이블, 눈금을 사용자 정하고, PNG, PDF 또는 SVG 중에서 선택하며, 환경 설정을 재사용 가능한 프로필로 저장할 수 있습니다.

### 시각적 사용자 정의
FloWorks에는 여러 테마(어두움, 밝음, 고대비)가 포함되어 있으며, 재시작 없이 즉시 전체 애플리케이션의 모양을 변경합니다. 또한 메뉴에서 전역 글꼴 크기(정보 → 글꼴 크기)를 조정할 수 있으며, 노드 내부 텍스트, 스티키 노트 및 그래프를 포함한 모든 요소가 그에 따라 크기가 조정됩니다.

### 언어 시스템
애플리케이션은 처음 시작할 때 시스템 언어를 자동으로 감지하고 환경 설정을 저장합니다. 메뉴에서 언제든지 언어를 변경할 수 있으며, 모든 텍스트, 메뉴 및 도움말이 즉시 업데이트됩니다.

### 프로젝트 및 `.sflow` 파일
모든 작업은 `.sflow` 확장자를 가진 단일 파일에 저장됩니다. 이 파일에는 전체 다이어그램이 포함됩니다: 노드, 연결, 노트, 설정, 스크립트 및 생성된 숫자 데이터. 다른 사용자와 공유할 수 있으며, 다른 컴퓨터에서 열면 노트 노드가 해당 화면의 픽셀 밀도에 자동으로 맞게 크기가 조정됩니다.

## 일반적인 워크플로

1. **간단한 다이어그램 만들기**  
   도구 모음에서 소스 노드(예: 생성기)와 시각화 노드를 선택합니다.  
   생성기의 출력을 시각화 노드의 입력에 연결합니다(출력 포트에서 Ctrl+클릭, 그런 다음 입력 포트 클릭).  
   실행하려면 F5를 누릅니다. 그래프에서 신호를 볼 수 있습니다.

2. **사용자 정의 스크립트 사용**  
   스크립트 노드를 추가합니다.  
   편집기에 Python 코드를 작성합니다. 편집 가능한 매개변수와 추가 포트를 정의할 수 있습니다.  
   다른 노드와 마찬가지로 입력과 출력을 연결합니다.  
   흐름을 실행합니다. 스크립트가 데이터와 함께 처리됩니다.

3. **실제 오실로스코프에서 데이터 캡처**  
   기기를 연결하고 오실로스코프 노드 패널에서 통신을 구성합니다.  
   노드가 신호를 획득하고 출력 포트(채널당 하나)를 통해 전달합니다.  
   이러한 포트를 다른 처리 노드 또는 시각화 노드에 연결합니다.

4. **보고서용 그래프 내보내기**  
   원하는 신호를 그래프 익스포터 노드에 연결합니다.  
   노드에서(오른쪽 클릭) 그래프의 시각적 모양을 구성합니다.  
   선택한 형식으로 보고서에 적합한 그래프를 빠르게 얻기 위해 프로필을 로드/저장할 수도 있습니다.

## 이 모든 것의 목적

이 아키텍처는 프로그램의 내부 조직에 대해 걱정하 않고 신호 분석에 집중할 수 있도록 설계되었습니다. 각 구성 요소에는 명확한 기능이 있으며, 시뮬레이션부터 실제 기기까지, 시각적 사용자 정의 및 결과 내보내기를 포함하여 원활한 경험을 제공하기 위해 함께 작동합니다.

FloWorks의 기능을 확장해야 하는 경우(예: 새 노드 유형 추가 또는 다른 기기 연결) 모듈식 구조가 이를 허용한다는 것을 알아 두십시오. 그러나 이는 개발자의 영역입니다. 최종 사용자로서 이 설계가 제공하는 유연성을 즐기십시오.
