# 🚀 FloWorks 시작하기

이 가이드는 처음부터 첫 번째 신호 처리 흐름을 실행할 때까지 안내합니다. FloWorks는 Python 및 PySide6으로 구축된 흐름 다이어그램 애플리케이션으로, 실제 하드웨어(VISA/SCPI), 통합 시뮬레이션, 고급 스크립팅 및 핫 언어 변경을 지원합니다.

---

## 🌊 첫 번째 예제 흐름

간단한 흐름을 만들어 보겠습니다: 사인파 신호를 생성하고 실시간으로 시각화합니다.

1. **노드 추가**
   상단 도구 모음에서 `소스` → `고급 신호 생성기`를 선택합니다. 그런 다음 `처리` → 예를 들어 `스펙트럼`을 선택합니다.
2. **연결**
   생성기의 출력 포트(`오른쪽`)에서 `Ctrl+클릭`을 합니다. 그런 다음 오실로스코프의 입력 포트(`왼쪽`)를 클릭합니다. 또는 출력 포트를 클릭하고(클릭을 누른 상태로) 다음 노드의 입력 포트까지 드래그하면 됩니다.
3. **구성 (선택 사항)**
   노드를 클릭하면 왼쪽 사이드 패널에 선택한 노드의 개변수가 있는 편집기가 나타나 작동 조건을 조정할 수 있습니다. 하단에는 노드에서 생성되거나 획득한 데이터를 시각적으로 표현하는 시각화 그래프가 있습니다.
4. **실행**
   `F5`를 누르거나 도구 모음에서 ▶ 버튼을 누릅니다. 토폴로지 엔진이 실행 순서를 계산하고, 데이터를 처리하고, 그래픽 패널에서 파형을 볼 수 있습니다. 커넥터가 활성 흐름을 나타내며 애니메이션됩니다!

---

## 🧠 포트 이해하기: 색상별 범주

FloWorks에서 각 포트는 색상으로 식별되는 **기능 범주**에 속합니다. 유효한 연결은 **항상 동일한 색상의 포트 간에** 이루어집니다. 한 범주의 출력은 동일한 범주의 입력에만 연결됩니다. 또한 커넥터 라인은 연결된 포트의 색상을 자동으로 채택하여 시각적 판독을 용이하게 합니다.

| 유형 | 색상 | 목적 | 일반적인 예 |
|------|-------|-----------|----------------|
| `control` | 흰색 | 제어 흐름 / 활성화. | 수집 노드로의 시작 신호. |
| `exec` | 회색 | 작업 또는 계 실행. | 함수 또는 콜백 트리거. |
| `data` | 녹색 | 일반 데이터 / 숫자 신호. | 생성기 또는 센서의 출력. |
| `int` | 파란색 | 정수. | 인덱스, 버퍼 크기, ID. |
| `float` | 시안 | 부동 소수점 숫자. | 진폭, 주파수, 임계값. |
| `string` | 보라색 | 텍스트 문자열. | 파일 이름, 레이블. |
| `bool` | 분홍색 | 부울 값(`True`/`False`). | 상태 플래그, 활성화. |
| `array` | 짙은 파란색 | 배열 / 벡터. | 다중 채널 신호, 샘플 목록. |
| `trigger` | 주황색 | 트리거 / 이산 이벤트. | 동기화 펄스, 플랭크. |

**황금률:**

- **정확히 동일한 색상**의 포트만 연결됩니다(출력 ↔ 동일한 범주의 입력).
- 시스템은 잘못된 연결을 방지하고 드래그할 때 호환 가능한 포트를 시각적으로 강조 표시합니다.
- 커넥터 라인은 연결된 포트의 색상을 취합니다. 따라서 각 경로를 한눈에 식별할 수 있습니다.

**FloWorks 철학:**  
데이터 포트는 배열의 **차원을 보존**합니다. 자동 평탄화는 절대 적용되지 않습니다: 행렬이 입력되면 행렬이 출력되어 다차원 신호의 무결성을 유지합니다.

## 🖱️ 캔버스 탐색

다음 제스처로 작업 공간을 마스터하세요:

| 작업 | 방법 |
|--------|--------------|
| **줌** | 마우스 휠 또는 `Ctrl + 휠` |
| **패닝 (스크롤)** | `Space`를 누른 상태에서 드래그하거나 마우스 중간 버튼 사용 |
| **노드 선택** | 노드에서 왼쪽 클릭 |
| **다중 선택** | 왼쪽 클릭으로 사각형을 드래그하거나 여러 노드에서 `Ctrl + 클릭` |
| **선택 이동** | 선택한 노드 중 하나를 드래그 |
| **구성 열기** | 노드에서 더블 클릭 |

**팁:** 왼쪽 패널은 추가 창을 열 필요 없이 선택한 노드의 구성으로 자동 업데이트됩니다.

## ⚡ 키보드 단축키 및 고급 동작

이러한 단축키는 일반 사용자를 **파워 유저**로 만듭니다:

| 단축키 | 작업 |
|-------|--------|
| `F5` | 흐름 실행 |
| `Ctrl + S` | 프로젝트 저장(`.sflow`) |
| `Ctrl + 클릭` | 노드 연결(출력 포 클릭 → 입력 포트 클릭) |
| `Ctrl + C` / `Ctrl + V` | 선택한 노드 복사 / 붙여넣기 |
| `Ctrl + Z` / `Ctrl + Y` | 실행 취소 / 다시 실행 |
| `Ctrl + Shift + L` | 캔버스에서 노드 자동 정렬 |
| `Supr` | 선택한 노드 삭제 |
| `Ctrl + A` | 모든 노드 선택 |

**고급 동작:**

- **흐름 복제:** 노드 그룹을 선택하고, `Ctrl + C`, `Ctrl + V`를 누른 다음 복사본을 다른 영역으로 드래그합니다.
- **그리드 정리:** `Ctrl + Shift + L`을 사용하여 단일 명령으로 전체 캔버스를 정렬합니다.
- **빠른 연결:** 출력 포트에서 `Ctrl + 클릭`한 다음 입력 포트에서 일반 클릭; FloWorks가 연결을 자동으로 그립니다.

## 🎨 환경 사용자 정의

FloWorks는 당신에게 맞춰집니다. 그 반대가 아닙니다.

### 핫 테마 변경
상단 표시줄에서 **보기 → 테마** 메뉴를 선택하고 밝음, 어두움 또는 기타 중에서 선택합니다. 인터페이스는 **즉시** 변경되며, 다시 시작하거나 워크플로를 잃지 않습니다.

### 글꼴 크기
**보기 → 글꼴 기**에서 미리 정의된 값 또는 사용자 지정 값을 선택합니다. 전체 인터페이스가 즉시 조정됩니다.

### 언어
**보기 → 언어**에서 원하는 언어를 선택합니다. FloWorks는 **핫 변경**을 지원합니다: 메뉴, 버튼 및 메시지가 애플리케이션을 다시 시작하지 않고 번역됩니다.

## ❗ 일반적인 문제 해결

| 문제 | 가능한 원인 | 해결 방법 |
|----------|---------------|----------|
| 흐름이 실행되지 않음 | 구성되지 않은 노드 또는 끊어진 연결이 있음 | 모든 노드에 유효한 매개변수가 있고 연결이 호환 가능한 포트 간에 있는지 확인 |
| 그래프가 업데이트되지 않음 | 흐름이 일시 중지되었거나 데이터가 흐르지 않음 | `F5` 또는 ▶를 눌렀고 소스 노드가 데이터를 생성하는지 확인 |
| 두 노드를 연결할 수 없음 | 포트 유형이 다름 | 두 포트가 모두 **데이터** 또는 모두 **제어**인지 확인 |
| 큰 흐름에서 프로그램이 느림 | 너무 많은 노드 또는 실시간 그래프 | 사용하지 않는 분석 패널을 닫나 소스 노드의 샘플링 속도를 줄입니다 |
| 테마가 변경되지 않음 | 일부 위젯이 등록되지 않았을 수 있음 | 애플리케이션을 다시 시작하고 다시 시도(향후 버전에서 해결됨) |

## 🧪 빠른 실용 예제

초기 사인파 흐름 외에도 FloWorks를 마스터하기 위해 다음 미니 프로젝트를 시도해 보세요:

| 예제 | 관련 노드 | 예상 결과 |
|---------|-------------------|--------------------|
| **저역 통과 필터** | 생성기 → 필터 → 그래프 시각화 도구 | 필터링된 신호를 볼 수 있습니다 |
| **시뮬레이션된 획득** | 생성기 → THD 분석기 | 신호의 고조파 왜곡 값 |
| **수동 제어** | 생성기 → 데이터 검사기 | 생성기가 보낸 신호 값의 테이블 |
| **신호 비교** | 두 생성기 → 가산기 → 그래프 시각화 도구 | 단일 그래프에서 두 파형의 연산(덧셈, 뺄셈, 곱셈 또는 나눗셈) 결과 |

이러한 각 흐름은 1분 이내에 구축할 수 있으며, 이는 전통적인 코드에 비해 FloWorks의 민첩성을 보여줍니다.

!!! warning "호환성 및 사용 참고 사항"
    1. **Python 버전:** 3.9+ 및 64비트 시스템을 사용할 수 있습니다.
    2. **Windows 방화벽:** 실제 하드웨어(VISA/SCPI 오실로스코프)를 사용하는 경우 방화벽에서 `FloWorks.exe`를 허용합니다. 연결이 차단되면 앱이 사용자 지정 대화 상자를 표시합니다(OS 대화 상자는 `--windowed` 모드에서 표시되 않음).
    3. **핵심 단축키:** `F5`(실행), `Ctrl+S`(`.sflow` 저장), `Ctrl+클릭`(연결), `Space+클릭`(자유 패닝), `Ctrl+Shift+L`(자동 레이아웃).
    4. **데이터 보존:** 엔진은 배열에 **절대** `flatten()`을 적용하지 않습니다. 벡터화가 필요한 경우 로컬 복사본으로 작업하세요.
