# 🧩 노드 기술 참조

FloWorks는 정적 카탈로그에 의존하지 않습니다. 명확한 계약을 기반으로 한 **동적 등록 시스템**을 사용합니다. 이를 통해 토폴로지 엔진을 건드리지 않고도 플랫폼을 확장할 수 있습니다. 아래에 구현된 카탈로그, 실제 기술 기능 및 안전한 확장을 위한 프로토콜이 자세히 설명되어 있습니다.

---

## 📂 핵심 범주

=== "📦 계층별 보기"
    <div class="grid cards" markdown>

    - **📥 소스/입력**
      초기 신호를 생성하거나 캡처합니다. 통합 시뮬레이션, 실제 하드웨어(VISA/SCPI) 및 멀티채널 모드를 지원합니다.
    - **⚙️ 처리**
      데이터를 변환, 결합 또는 분석합니다. 차원을 보존하고 필요할 때 자동으로 보간합니다.
    - **🔀 제어/흐름**
      실행을 분기, 반복 또는 조건화합니다. 활성화 신호에 대한 기본 지원이 포함됩니다.
    - **🐍 스크립팅/고급**
      매개변수 포트(`# @param`), 동적 포트(`# @input`/`# @output`) 및 상태 지속성(`persist`)을 사용하여 동적 Python 코드를 실행합니다.
    - **🔌 하드웨어/계측**
      오실로스코프, LCR 미터 및 생성기를 위한 인터페이스입니다.
    - **📤 출력/내보내기**
      결과를 시각화, 내보내기 또는 보관합니다. 시각적 테마, 사용자 프로필 및 전문 형식(PNG/PDF/SVG)을 지원합니다.

    </div>

## 📋 구현된 기술 카탈로그

| 노드 | 유형 | 주요 책임 | 핵심 특징 |
|------|------|---------------------------|------------------------|
| `SumNode` | 처리 | 두 입력을 위한 산술 연산자(+, -, *, /). | 서로 다른 해상도의 신호(FFT)를 자동으로 보간합니다. 차원을 보존합니다. |
| `RhombusNode` | 제어 | 조건부(예/아니오 분기). | 두 개의 출력 포트. 임계값 또는 부울 논리로 조건을 평가합니다. |
| `TriggerNode` | 제어 | 외부 활성화가 있는 반복기/누적기. | `(x, y, "trigger")`를 수신합니다. N번 반복까지 누적하고 쌓인/평균 결과를 내보냅니다. |
| `ScriptNode` | 고급 | 통합 Python 스크립팅 경. | QScintilla, 자동 완성, `# @param`, 동적 포트, `persist`, 템플릿, 오류 콘솔, 타임아웃이 있는 외부 인터프리터. |
| `OscilloscopeNode` | 하드웨어 | 오실로스코프(SDS) 또는 LCR 미터에서 캡처. | 시뮬레이션 모드, 통합 방화벽 대화 상자, **멀티채널 지원**(`out_primary`, `out_secondary`), "채널 표시" 메뉴. |
| `GeneratorNode` | 소스 | 생성기(SDG)에 신호를 보내거나 출력을 시뮬레이션합니다. | 변조/스윕 구성, 통합 시뮬레이션 대화 상자. |
| `GraphExporterNode` | 출력 | 전문 그래프 내보내기 도구. | 더블 클릭 구성, 사용자 지정 축, 테마, 저장된 프로필 등. |

## 🔍 ScriptNode: 필수 기능

> **🐍 통합 스크립팅 환경**
>
> - **통합 코드 편집기:** 기본 구문 강조, 줄 번호 및 코드 접기.
> - **동적 매개변수 패널:** `# @param NAME : type = value` 지시문은 편집 가능한 컨트롤(스핀박스, 텍스트 필드 등)을 측면 패널에 주입합니다.
> - **동적 포트:** `# @input name` 및 `# @output name`은 실시간으 포트를 생성합니다. 스크립트는 `inputs` 사전을 받고 `outputs`를 반환합니다.
> - **상태 지속성:** 실행 간 값을 유지하는 전역 `persist` 사전.
> - **템플릿 및 가져오기/내보내기:** 기본 스크립트가 있는 드롭다운 메뉴. 사용자는 자신의 스크립트를 `nodes/script_node/templates/`에 저장하거나 외부 `.py` 파일을 가져오기/내보내기할 수 있습니다.
> - **통합 오류 콘솔:** 편집기에서 정확한 줄을 표시하여 구문/실행 오류를 보여줍니다.
> - **도움말 및 i18n:** 상황에 맞는 도구 설명, 빠른 안내를 위한 `?` 버튼, 모든 텍스트는 번역을 위해 `tr()`을 사용합니다.
> - **타임아웃이 있는 외부 인터프리터:** 구성 가능한 경로(`# @python_path` 또는 "찾아보기…" 버튼). 시간 제한이 있는 격리 실행 및 내부 인터프리터로 대체.
> - **전체 직렬화:** 스크립트, 매개변수, 동적 포트 및 `persist` 상태를 저장합니다. `.sflow`를 로드할 때 포트와 매개변수를 자동으로 재구성합니다.

💡 **이 카탈로그에 노드가 부족합니까?**  
FloWorks는 확장 가능하도록 설계되었습니다. 필요한 노드가 없으면 `BaseNode` 계약을 따라 생성하고 등록하세요. 커뮤니티와 미래 마켓플레이스는 호환성을 손상시키지 않고 지속적으로 에코시스템을 확장할 것입니다.
