# 📁 프로젝트 관리

FloWorks는 플로우를 **`.sflow`** 확장자를 가진 파일에 저장합니다. 이 파일에는 프로젝트의 모든 정보가 포함됩니다: 노드, 연결, 구성 및 스티키 노트.

---

## 만들기, 열기 및 저장

| 작업 | 메뉴 | 단축키 |
|--------|------|-------|
| **새 프로젝트** | 파일 → 새로 만들기 | `Ctrl + N` |
| **프로젝트 열기** | 파일 → 열기 | `Ctrl + O` |
| **저장** | 파일 → 저장 | `Ctrl + S` |
| **다른 이름으로 저장…** | 파일 → 다른 이름으로 저장… | `Ctrl + Shift + S` |

**황금률:**  
플로우는 FloWorks의 **모든 버전(Core, Lite, Pro) 간에 완전히 호환**됩니다. 변환이나 수정이 필요 없습니다: 그냥 열고 실행하세요.

---

## 내보내기 및 가져오기

- **플로우를 공유**하려면 `.sflow` 파일을 다른 컴퓨터에 복사하세요.
- **외부 플로우를 가져오**려면 **파일 → 열기**를 사용하고 파일을 선택하세요.
- **숫자 데이터를 내보내**야 하는 경우(예: CSV로), 사이드 패널의 **스프레드시트** 도구를 사용하여 해당 테이블을 저장하세요.

---

## 예기치 않은 종료 시 복구

FloWorks는 **자동 저장하지 않습니다**. 따라서 다음이 중요합니다:

- 자주 저장하세요(`Ctrl + S`), 특히 실제 하드웨어로 플로우를 실행하기 전에.
- 애플리케이션이 예기치 않게 종료되면 저장되지 않은 변경 사항이 손실될 수 있습니다.
- 완전히 안심하고 작업하려면 중요한 수정 후 저장하는 습관을 들이세요.

---

## 권장 구성

- 각 프로트 또는 고객마다 폴더를 만들고 관련 `.sflow`를 모두 거기에 저장하세요.
- 플로우의 섹션을 문서화하려면 캔버스 내에 **스티키 노트**를 사용하세요.
- **노드에 설명적인 이름을 지정**하세요(더블 클릭 → 이름)하면 몇 주 후에도 플로우를 쉽게 찾고 이해할 수 있습니다.

---

## 모범 사례

- 실제 기기로 플로우를 실행하기 전에 파일을 저장하세요.
- 팀으로 작업하는 경우 버전 관리 시스템(Git, 수동 복사본)을 사용하여 중요한 플로우를 덮어쓰지 마세요.
- 보정 또는 진단에 중요한 플로우는 백업하세요.

---

> **팁:** 잘 정리되고 저장된 플로우는 FloWorks에서 전문적인 작업의 기초입니다. 명확한 이름과 정돈된 폴더의 힘을 과소평가하지 마세요.
