# 🌐 국제화 가이드 (i18n)

이 문서는 FloWorks에 새 언어를 추가하고 번역 파일을 효과적으로 관리하는 방법을 설명합니다.

---

## ➕ 새 언어 추가 방법

### 1단계: JSON 파일 생성
`locales/` 폴더로 이동합니다. `en.json`을 복사하고 해당하는 두 글자 [ISO 639-1](https://es.wikipedia.org/wiki/ISO_639-1) 코드를 사용하여 이름을 변경합니다(예: 프랑스어는 `fr.json`, 독일어는 `de.json`).

### 2단계: 문자열 번역
텍스트 편집기에서 새 JSON 파일을 엽니다.

!!! warning "키를 수정하지 마세요"
    **키(각 쌍의 왼쪽)는 절대 변경하지 마세요.** 값(오른쪽)만 번역하세요.

**원본 (`en.json`):**
```json
{
  "app_title": "FloWorks",
  "menu": {
    "file": "File",
    "edit": "Edit"
  }
}
```

**번역 예시 (`es.json`):**
```json
{
  "app_title": "FloWorks",
  "menu": {
    "file": "Archivo",
    "edit": "Editar"
  }
}
```
루트 키 `"language_name"`에 해당 언어의 원어 이름이 포함되어 있는지 확인하세요(예: `"Français"`, `"Deutsch"`, `"Español"`).

### 3단계: JSON 유효성 검사
파일이 유효한 JSON인지 확인하세요(후행 쉼표 없음, 올바른 따옴표, 적절한 이스케이프). [JSONLint](https://jsonlint.com)와 같은 온라인 유효성 검사기를 사용하거나 다음을 실행할 수 있습니다:
```bash
python -m json.tool locales/es.json
```

### 4단계: 새 언어 테스트
1. FloWorks를 시작합니다.
2. **INFO → 언어**로 이동하여 새 언어를 선택합니다.
3. 메뉴, 패널, 대화 상자, 노드 레이블 등 모든 인터페이스 요소가 즉시 업데이트되는지 확인합니다.

### 5단계: 자동 감지 (선택 사항)
사용자의 시스템 로캘이 새 언어 코드와 일치하면 FloWorks가 첫 시작 시 자동으로 해당 언어를 사용합니다(`QSettings`에 이전 저장된 기본 설정이 없는 경우).

---

## 🌍 사용 가능한 언어
- **영어** (`en`) – 기본 / 대체 언어
- **스페인어** (`es`)

---

## ⚙️ 중요 참고 사항 및 모범 사례

!!! info "대체 메커니즘"
    기본 언어는 **영어**입니다. 언어 파일에 번역 키가 누락된 경우 FloWorks는 자동으로 영어 문자열을 대체로 사용합니다.

!!! warning "UI 오버플로 방지"
    레이아웃이 깨지지 않도록 번역을 간결하게 유지하세요. 번역된 텍스트가 상당히 긴 경우 약어를 사용하거나 동적 크기 조정을 처리하도록 테마 시스템에 의존하는 것을 고려하세요.

!!! tip "HTML 및 플레이스홀더 보존"
    - **HTML 태그:** 모든 HTML 태그를 있는 그대로 정확히 보존하세요(예: `<h3>`, `<b>`, `<pre>`, `<br>`).
    - **플레이스홀더:** 사용된 위치에서 `{variable}` 구문을 유지하세요(예: `"언어가 다음으로 변경되었습니다: {name} ({code})"`). 재정렬하거나 제거하지 마세요.
