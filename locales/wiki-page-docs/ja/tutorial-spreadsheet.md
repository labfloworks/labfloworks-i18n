# 📊 Spreadsheet チュートリアル

軽量で、Excel スタイルのスプレッドシート。埋め込み可能。

---

## 1. Spreadsheet とは？

これは、以下を供するスプレッドシートコンポーネントです：

- 数式をサポートするセル（`=` で開始）
- 定義済み関数（SUM、AVERAGE、CONDITIONAL など）
- 算術、論理、比較演算子
- ミニマリストインターフェース、Qt アプリケーションへの統合に最適

---

## 2. 基本的なナビゲーション

- セルをクリックして選択します。
- 直接入力してテキストまたは数字を入力します。
- **数式**を書くには、`=` で開始します（例：`=SUM(A1:A5)`）。
- **Enter** を押して編集を確認します。
- 矢印キーまたはマウスを使用して移動します。

---

## 3. 数式：利用可能な関数

すべての関数は大文字で書かれ、範囲（例：`A1:A5`）またはカンマで区切られた引数をサポートします。

| 関数                     | 機能                             | 例                             |
| ------------------------ | -------------------------------- | ------------------------------ |
| `SUM`                    | 数値の合計                       | `=SUM(A1:A5)`                  |
| `AVG` / `AVERAGE`        | 平均値                           | `=AVG(A1:A5)`                  |
| `COUNT`                  | 数値のカウント（空白以外）       | `=COUNT(A1:A5)`                |
| `MAX`                    | 最大値                           | `=MAX(A1:A5)`                  |
| `MIN`                    | 最小値                           | `=MIN(A1:A5)`                  |
| `ABS`                    | 絶対値                           | `=ABS(A1)`                     |
| `ROUND`                  | 四捨五入（第2引数 = 小数位数）   | `=ROUND(A1, 2)`               |
| `IF`                     | 条件（もし、ならば、そうでなければ） | `=IF(A1>10, "はい", "いいえ")` |
| `CONCAT` / `CONCATENATE` | テキストの結合                   | `=CONCAT(A1, " ", B1)`         |
| `LEN`                    | テキストの長さ                   | `=LEN(A1)`                     |
| `INT`                    | 整数部分                         | `=INT(A1)`                     |
| `SQRT`                   | 平方根                           | `=SQRT(A1)`                    |

### 3.1. 関数に関する注意事項

- 範囲は**コロン**で示します：`A1:A5` は A1 から A5 までのすべてのセルを含みます。
- 関数はネストできます：`=SUM(A1:A5) + MAX(B1:B5)`。
- テキスト引数は二重引用符または単一引用符で囲む必要があります。

---

## 4. 関数以外の演算子

関数に加えて、数式内で直接演算子を使用できます。構文は Python に似ています。

### 4.1. 算術演算子

| 演算           | 例                        |
| -------------- | ------------------------- |
| 加算           | `=A1+A2+A3`               |
| 減算           | `=A1-A2`                  |
| 乗算           | `=A1*B1`                  |
| 除算           | `=A1/B1`                  |
| 剰余           | `=A1%B1`                  |
| 累乗           | `=A1**2`  (または `=A1^2`) |

### 4.2. 比較演算子

これらは `True` または `False` を返します（`真` / `偽` として表示されます）。

| 演算子 | 意味             | 例                 |
| -------- | ---------------- | ------------------ |
| `>`      | より大きい       | `=A1>B1`           |
| `<`      | より小さい       | `=A1<B1`           |
| `>=`     | 以上             | `=A1>=10`          |
| `<=`     | 以下             | `=A1<=10`          |
| `==`     | 等しい           | `=A1==B1`          |
| `!=`     | 等しくない       | `=A1!=B1`          |

### 4.3. 論理および条件演算子

`and`、`or`、`not` を使用して条件を組み合わせることができます。

```excel
= A1>5 and B1<10
= not(A1==0)
= 10 if A1>5 else 0
```

三項演算子 `if` `else` も直接サポートされています。

## 5. 実践的な例

### 5.1. 売上の合計

`B2:B10` に売上があると仮定し、合計が必要な場合：

```excel
=SUM(B2:B10)
```

### 5.2. 条件付き割引

合計（`B12`）が 100 を超える場合、10% の割引を適用します。そうでない場合は 0：

```excel
= IF(B12>100, B12*0.9, B12)
```

### 5.3. 平均とカウント

`C2:C20` の成績平均値ですが、値が少なくとも 5 つある場合のみ：

```excel
= IF(COUNT(C2:C20)>=5, AVG(C2:C20), "データ不足")
```

### 5.4. テキストの結合

名 (A2) と姓 (B2) をスペースで結合します：

```excel
= CONCAT(A2, " ", B2)
```

### 5.5. 数値の平方根

```excel
= SQRT(A1)
```

### 5.6. 小数点以下 2 桁に丸める

```excel
= ROUND(A1, 2)
```

## 6. ヒントとコツ

- **相対/絶対参照：** 現時点では、すべての参照は相対参照です（Excel と同様）。`$A$1` はまだサポートされていません。
- **動的範囲：** `A:A`（列全体）や `1:1`（行全体）などの範囲を使用できます。
- **自動補完：** `=` を入力すると、利用可能な関数のメニューが表示されます。
- **エラー：** 数式が無効な場合、セルには `#ERROR` が表示され、ステータスバーに詳細メッセージが表示されます。
- **再計算：** 依存セル変更すると、数式は自動的に更新されます。
