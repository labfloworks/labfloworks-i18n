# 🧩 技術ノードリファレンス

FloWorks は静的なカタログに依存しません。明確なコントラクトに基づく**動的登録システム**を使用しています。これにより、トロジカルエンジンに触れることなくプラットフォームを拡張できます。以下に、実装されたカタログ、実際の技術機能、および安全に拡張するためのプロトコルを詳述します。

---

## 📂 コアカテゴリ

=== "📦 レイヤー別ビュー"
    <div class="grid cards" markdown>

    - **📥 ソース/入力**
      初期信号を生成または取得します。統合シミュレーション、実ハードウェア（VISA/SCPI）、およびマルチチャンネルモードをサポートします。
    - **⚙️ 処理**
      データを変換、結合、または分析します。次元性を保持し、必要に応じて自動的に間します。
    - **🔀 制御/フロー**
      実行を分岐、反復、または条件付けします。アクティベーション信号のネイティブサポートを含みます。
    - **🐍 スクリプト/高度**
      パラメトリックポート（`# @param`）、動的ポート（`# @input`/`# @output`）、および状態永続化（`persist`）を使用して動的な Python コードを実行します。
    - **🔌 ハードウェア/計測機器**
      オシロスコープ、LCR メーター、およびジェネレーターのインターフェースです。
    - **📤 出力/エクスポート**
      結果を可視化、エクスポート、またはアーカイブします。ビジュアルテーマ、ユーザープロファイル、およびプロフェッショナル形式（PNG/PDF/SVG）をサポートします。

    </div>

## 📋 実装された技術カタログ

| ノード | タイプ | 主な責任 | 主な機能 |
|------|------|---------------------------|------------------------|
| `SumNode` | 処理 | 2 つの入力の算術演算子（+、-、*、/）。 | 異なる解像度（FFT）の信号を自動的に補間します。次元性を保持します。 |
| `RhombusNode` | 制御 | 条件分岐（Yes/No 分岐）。 | 2 つの出力ポート。しきい値またはブール論理によって条件を評価します。 |
| `TriggerNode` | 制御 | 外部アクティベーション付きイテレーター/アキュムレーター。 | `(x, y, "trigger")` を受信します。N 回の反復まで蓄積し、積層/平均化された結果を出力します。 |
| `ScriptNode` | 高度 | 統合された Python スクリプト環境。 | QScintilla、オートコンプリート、`# @param`、動的ポート、`persist`、テンプレート、エラーコンソール、タイムアウト付き外部インタープリター。 |
| `OscilloscopeNode` | ハードウェア | オシロスコープ（SDS）または LCR メーターからの取得。 | シミュレーションモード、統合ファイアウォールダイアログ、**マルチチャンネルサポート**（`out_primary`、`out_secondary`）、「チャンネルを表示」メニュー。 |
| `GeneratorNode` | ソース | ジェネレーターSDG）に信号を送信したり、出力をシミュレートしたりします。 | 変調/スイープ構成、統合シミュレーションダイアログ。 |
| `GraphExporterNode` | 出力 | プロフェッショナルグラフエクスポーター。 | ダブルクリック構成、カスタム軸、テーマ、保存されたプロファイルなど。 |

## 🔍 ScriptNode：重要な機能

> **🐍 統合スクリプト環境**
>
> - **統合コードエディタ：** 基本的なシンタックスハイライト、行番号、およびコード折りたたみ。
> - **動的パラメータパネル：** ディレクティブ `# @param NAME : type = value` は、編集可能なコントロール（スピンボックス、テキストフィールドなど）をサイドパネルに注入します。
> - **動的ポート：** `# @input name` および `# @output name` はリアルタイムでポートを作成します。スクリプトは `inputs` 辞書を受け取り、`outputs` を返します。
> - **状態永続化：** 実行間で値を保持するグローバル `persist` 辞書。
> - **テンプレートおよびインポート/エクスポート：** ベーススクリプト付きのドロップダウンメニュー。ユーザーはスクリプトを `nodes/script_node/templates/` に保存したり、外部 `.py` ファイルをインポート/エクスポートしたりできます。
> - **統合エラーコンソール：** 構文/実行エラーを表示し、エディタで正確な行を強調表示します。
> - **ヘルプと i18n：** コンテキストツールチップ、`?` ボタンによるクイックガイド、および翻訳用の `tr()` を使用するすべてのテキスト。
> - **タイムアウト付き外部インタープリター：** 設定可能なパス（`# @python_path` または「参照…」ボタン）。時間制限付きの分離実行、および内部インタープリターへのフォールバック。
> - **完全なシリアライゼーション：** スクリプト、パラメータ、動的ポート、および `persist` 状態を保存します。`.sflow` を読み込むときに、ポートとパラメータを自動的に再構築します。

💡 **このカタログにノードが足りない場合は？**
FloWorks は拡張可能なように設計されています。存在しないノードが必要な場合は、`BaseNode` コントラクトに従って作成し、登録してください。コミュニティと将来のマーケットプレイスは、互換性を損なうことなくエコシステムを継続的に拡張します。
