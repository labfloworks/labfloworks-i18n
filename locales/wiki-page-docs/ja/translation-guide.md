# 🌐 国際化 (i18n) ガイド

このドキュメントでは、FloWorks に新しい言語を追加し、翻訳ファイルを効果的に管理する方法を説明します。

---

## ➕ 新しい言語を追加する方法

### ステップ 1：JSON ファイルを作成する
`locales/` フォルダーに移動します。`en.json` をコピーし、対応する 2 文字の [ISO 639-1](https://ja.wikipedia.org/wiki/ISO_639-1) コードを使用して名前を変更します（例：フランス語の場合は `fr.json`、ドイツ語の場合は `de.json`）。

### ステップ 2：文字列を翻訳する
新しい JSON ファイルをテキストエディタで開きます。

!!! warning "キーを変更しないでください"
    **キー（各ペアの左側）は絶対に変更しないでください**。値（右側）のみを翻訳してください。

**原文 (`en.json`)：**
```json
{
  "app_title": "FloWorks",
  "menu": {
    "file": "File",
    "edit": "Edit"
  }
}
```

**翻訳例 (`es.json`)：**
```json
{
  "app_title": "FloWorks",
  "menu": {
    "file": "Archivo",
    "edit": "Editar"
  }
}
```
ルートキー `"language_name"` に、その言語のネイティブ名が含まれていることを確認してください（例：`"Français"`、`"Deutsch"`、`"Español"`）。

### ステップ 3：JSON を検証する
ファイルが有効な JSON であることを確認してください（末尾のカンマなし、正しい引用符、適切なエスケープ）。オンライン検証ツール（例：[JSONLint](https://jsonlint.com)）を使用するか、以下を実行できます：
```bash
python -m json.tool locales/es.json
```

### ステップ 4：新しい言語をテストする
1. FloWorks を起動します。
2. **INFO → 言語** に移動し新しい言語を選択します。
3. すべてのインターフェー要素（メニュー、パネル、ダイアログ、ノードラベルなど）が即座に更新されることを確認します。

### ステップ 5：自動検出（オプション）
ユーザーのシステムロケールが新しい言語コードと一致する場合、FloWorks は初回起動時に自動的にその言語を使用します（`QSettings` に以前の設定が保存されていない場合）。

---

## 🌍 利用可能な言語
- **英語** (`en`) – ベース / フォールバック言語
- **スペイン語** (`es`)

---

## ⚙️ 重要な注意事項とベストプラクティス

!!! info "フォールバックメカニズム"
    ベース言語は**英語**です。言語ファイルに翻訳キーが欠落している場合、FloWorks は自動的に英語の文字列をフォールバックとして使用します。

!!! warning "UI オーバーフローの防止"
    レイアウトの崩れを避けるため、翻訳は簡潔に保ってください。翻訳後のテキストが大幅にい場合は、省略形を検討するか、テーマシステムによる動的スケーリングに依存してください。

!!! tip "HTML とプレースホルダーの保持"
    - **HTML タグ：** すべての HTML タグを正確にそのまま保持してください（例：`<h3>`、`<b>`、`<pre>`、`<br>`）。
    - **プレースホルダー：** 使用されている場所では `{variable}` 構文を維持してください（例：`"言語を変更しました: {name} ({code})"`）。並べ替えたり削除したりしないでください。
