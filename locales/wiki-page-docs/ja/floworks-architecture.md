# FloWorks アーキテクチャ – ユーザービュー

FloWorks は、フロー図を使用して信号処理チェーンを構築できるデスクトップアプリケーションです。インタラクティブなキャンバス上でブロック（ノード）を接続し、結果をリアルタイムで確認できます。これを可能にするため、アプリケーションは複数のモジュールに分かれており、それらが連携して動作します。以下では、各パーツの役割とその関係について、非技術的に説明します。

---

## 全体構造

アプリケーションは以下の機能領域で構成されています：

| 領域 | 役割 |
|------|------------|
| **起動とメインウィンドウ** | プログラムを起動し、ウィンドウ、メニューを表示し、すべてのユーザーアクションを調整します。 |
| **実行エンジン** | ノードを実行すべき順序を計算し、依存関係とループを検出し、データをノード間で伝達します。 |
| **シーンとダイアグラム** | ノードを配置するキャンバス、ノード間の接続、付箋、元に戻す/やり直し操作を管理します。 |
| **ノードと処理** | 使用可能なすべてのブロックタイプを含みます：信号源、数学演算、カスタムスクリプト、グラフのエクスポートなど。 |
| **ビジュアルコネクタ** | ノードを結ぶ線（滑らかな曲線または直交パス）を描画し、データフローをアニメーションで示し、重なりを防ぎます。 |
| **ユーザーインターフェース** | ダイグラムビュー（ズーム、パン）、ツールバー、パラメータテーブル、分析パネル（統計、カーソル）、設定ダイアログを含みます。 |
| **実ハードウェアサポート** | 実験室機器（オシロスコープ、ジェネレーター、LCR メーター）と通信し、実際の信号を取得または生成します。 |
| **グラフエクスポート** | 高品質な画像（PNG、PDF、SVG）を、完全なビジュアルカスタマイズで生成します。 |
| **テーマと外観** | アプリケーション全体の外観（ダーク、ライト、ハイコントラスト）を変更し、フォントサイズを調整できます。 |
| **言語** | インターフェース全体を複数言語に翻訳し、言語を即座に切り替えられます。 |
| **プロジェクト管理** | ダイアグラム全体を含む `.sflow` ファイルを保存および開きます。設定、スクリプト、結果も含まれます。 |
| **テストと診断** | すべてが正しく動作しているか確認するための内部ツール（エンドユーザーには非表示）。 |

## 内部の動作

### 起動とメインウィンドウ
FloWorks を開くと、グラフィカル環境が設定され、画面のピクセル密度が検出されます（4K または通常のモニターでもすべてが鮮明に見えるように）。その後、メインウィンドウが表示されます。このウィンドウは、描画領域、メニュー、ツールバー、サイドパネルを一元管理します。

### フローエンジン
"実行" を押す（または F5 を押す）と、内部エンジンが接続関係を尊重しながら、すべてのノードを正しい順序で走査します。どのノードが他のノードに依存しているかを把握し、無限ループを防ぎます。1 つのノードが複数の名前付き入力を受け取り、複数の出力を生成することもサポートしています。データは元の構造を失わずにノード間を移動します。

### ダイアグラムシーン
ダイアグラムを構築するキャンバスはスマートシーンです：

- ノードの追加、移動、接続、選択が可能です。
- あらゆる操作にして無制限の元に戻す/やり直しをサポートします。
- 自由に配置でき、プロジェクトと一緒に保存されるサイズ変更可能な付箋が含まれます。
- 自動整理機能があり、Ctrl+Shift+L でノードをきれいに再配置できます。
- 保存時には、ノードの説明、接続、付箋、関連する数値データを含む `.sflow` ファイルにダイアグラム全体がパッケージ化されます。

### コネクタ
ノードを結ぶ線は、滑らかな曲線または直交パスとして描画されます。点や破線の穏やかなアニメーションがフローの方向を示します。レーン管理機能により、同じノード間の複数の接続が重ならないようにします。自動的に分離され、常に読みやすく保たれます。

### ノードタイプ
ノードは基本単位です。3 つのカテゴリに分類されます：

- **ソース** – 信号を生成します。正弦波、方形波などの波形をシミュレーしたり、接続されたオシロスコープやマルチメータから実データを読み取ったりできます。複数の同時チャンネルをサポートします（例：LCR からのインピーダンスと位相）。
- **処理** – データを変換します。算術演算（加算、減算、乗算、除算）、条件分岐（Yes/No 分岐）、およびビジュアル補助付きで独自の Python コードを記述できる強力なスクリプトノードが含まれます。
- **シンク** – 結果を表示またはエクスポートします。最も一般的なのはグラフビューア（仮想オシロスコープ）ですが、プロ品質のグラフエクスポーターもあります。

各ノードには入力ポート（左/上）と出力ポート（右/下）があります。出力ポートを入力ポートに接続すると、信号がその間を流れます。

#### 高度なスクリプトノード
スクリプトノードは特筆に値します。FloWorks を離れることなく独自の処理を追加したい上級ユーザー向けに設計されています。提供される機能：

- シンタックスハイライト、オートコンプリート、行番号付きのエディタ。
- コードに触れずにノードパネルから編集可能なパラメータを定義できる機能（例：スクリプト内で後に使用される数値）。
- 動的入出力ポート：スクリプト内に特別なコメントを追加することで、新しいコネクタを作成できます。
- 永続メモリ：実行間で値を保持する特別な変数（`persist`）。アキュムレータや状態機械に便利です。
- あらかじめ用意されたスクリプトテンプレートと、独自のテンプレートを保存する機能。
- 組み込みヘルプシステムと、実行時エラーを表示するコンソール。

### ユーザーインターフェース
キャンバスに加え、インターフェースには以下が含まれます：

- **ツールバー**：カテゴリ別に整理されたすべてのノード、言語・テーマ・フォントサイズメニュー、およびログビューアへのアクセス。
- **パラメータテーブル**：選択したノードの情報を表示し、互換性の問題（例：異なる長さの信号に対する演算の試行）を強調表示します。
- **ドッキング可能な分析パネル**：統計（最大値、最小値、実効値）、差分測定用の A/B カーソル、ピークマーカー付きクロスヘア。
- **ウェルカムダイアログ**：画面解像度に適応し、初期オプションを提供します。

### 実機器との接続
互換性のあるハードウェア（Siglent SDS オシロスコープ、LCR メーター、SDG ジェネレーター）がある場合、FloWorks は標準 VISA/SCPI プロトコルを介して通信できます。設定はアプリケーション内の専用パネルから行います。マルチチャンネル信号（例：LCR からのマグニチュードと位相）をキャプチャすると、ソースノードがすべてのチャンネルをパッケージ化し、簡単なコンテキストメニューで表示するチャンネルを選択できます。

### プロフェッショナルグラフエクスポート
グラフエクスポーターノードを使用すると、レポートや出版物用の画像を生できます。ダブルクリックすると、複数のオプションを備えたダイアログが開きます：色、線種、ラベル、目盛りをカスタマイズでき、PNG、PDF、SVG 形式を選択でき、設定を再利用可能なプロファイルとして保存できます。

### ビジュアルカスタマイズ
FloWorks には複数のテーマ（ダーク、ライト、ハイコントラスト）が含まれており、再起動なしでインターフェース全体の外観を即座に変更できます。また、メニュー（情報 → フォントサイズ）らグローバルフォントサイズを調整でき、ノード内のテキスト、付箋、グラフを含むすべての要素がそれに応じてリサイズされます。

### 言語システム
アプリケーションは初回起動時に自動的にシステム言語を検出し、設定を保存します。メニューからいつでも言語を変更でき、すべてのテキスト、メニュー、ヘルプが即座に更新されます。

### プロジェクトと `.sflow` ファイル
すべての作業は `.sflow` 拡張子を持単一ファイルに保存されます。このファイルには、ノード、接続、付箋、設定、スクリプト、および生成された数値データを含む完全なダイアグラムが含まれます。他のユーザーと共有できます。別のコンピューターで開くと、付箋とノードがその画面のピクセル密度に合わせて自動的に再スケールされます。

## 典型的なワークフロー

1. **簡単なダイアグラムを作成する**
   ツールバーからソースノード（例：ジェネレーター）とビューアノードを選択します。
   ジェネレーターの出力をビューアの入力に接続します（出力ポートで Ctrl+クリックし、入力ポートでクリック）。
   F5 を押して実行します。グラフ上に信号が表示されます。

2. **カスタムスクリプトを使用する**
   スクリプトノードを追加します。
   エディタで Python コードを記述します。編集可能なパラメータや追加ポートを定義できます。
   他のノードと同様に入力と出力を接続しす。
   フローを実行します。スクリプトがデータとともに処理されます。

3. **実際のオシロスコープからデータを取得する**
   機器を接続し、オシロスコープノードパネルから通信を設定します。
   ノードが信号を取得し、出力ポート（チャンネルごとに 1 つ）から出力します。
   これらのポートを他の処理ノードまたはビューアに接続します。

4. **レポート用のグラフをエクスポートする**
   目的の信号をグラフエクスポーターノードに接続します。
   ノードを選択し（右クリック）、グラフのビジュアル外観を設定します。
   プロファイルの読み込み/保存も可能で、選択した拡張子の画像ファイルを取得し、レポート対応のグラフを迅速に作成できます。

## これらすべての目的

このアーキテクチャは、プログラムの内部構造を気にせずに信号分析に集中できるように設計されています。各コンポーネントには明確な機能があり、シミューションから実機器、ビジュアルカスタマイズ、結果のエクスポートまで、スムーズな体験を提供するために連携しています。

FloWorks の機能を拡張する必要がある場合（例：新しいノードタイプの追加、異なる機器の接続）、それを可能にするモジュール構造が存在しますが、これは開発者の領域です。エンドユーザーとしては、この設計が提供する柔軟性をお楽しみください。
