# 🔌 VISA/SCPI 計測機器

FloWorks は、**VISA**（Virtual Instrument Software Architecture）抽象化レイヤー上の **SCPI**（Standard Commands for Programmable Instruments）プロトコルを介して、実際の実験室機器との直接通信を統合しています。また、物理的なハードウェアを必要とせずに、フローの開発、テスト、共有を行うための純粋な Python ベースのシミュレーターも提供しています。

---

## 🌐 VISA/SCPI とは？

| 技術 | 説明 |
|------------|-------------|
| **VISA** | 物理インターフェース（USB-TMC、Ethernet/LAN、GPIB、RS‑232）を抽象化する標準レイヤーです。接続文字列を変更するだけで、実機からシミュレートされた機器に切り替えることができます。 |
| **SCPI** | ジェネーター、オシロスコープ、マルチメーター、LCR メーターなどを制御するための標準化された ASCII コマンド言語です。メーカーは標準を拡張しますが、基本は普遍的です。 |
| **PyVISA** | FloWorks が使用する Python バックエンドです。`@py`（純粋なシミュレーション）およびネイティブバックエンド（`@ni`、`@ivi`、`@keysight` など）をサポートしています。 |

---

## ⚙️ 典型的な構成

=== "📍 接続文列 (Resource String)"
    標準 VISA 形式：
    - `USB0::0x1AB1::0x0588::DS1ZA123456789::INSTR`（USB オシロスコープ）
    - `TCPIP0::192.168.1.100::inst0::INSTR`（LAN/Ethernet）
    - `ASRL1::INSTR`（RS-232 シリアルポート）
    - `GPIB0::1::INSTR`（レガシー GPIB）

=== "⏱️ タイムアウトとオプション**"
    - **タイムアウト**：ミリ秒単位で設定可能です。機器に長時間の測定や周波数スイープが必要な場合は増やしてください。
    - **初期化**：一部のノードでは、接続時にカスタム SCPI コマンドを注入できます（例：`CLS`、`SYST:PRES`、`:CHAN1:DISP ON`）。

## 📡 利用可能なハードウェアノード

<div class="grid cards" markdown>

- **🔭 SCPI オシロスコープ**
  時間領域の波形をキャプチャします。マルチチャンネル、自動スケーリング、ハードウェアトリガー、およびホット切り替えで信号を切り替える「チャンネルを表示」メニューをサポートしています。

- **⚡ LCR メータ**
  インピーダンス、インダクタンス、キャピシタンス、レジスタンス、および損失係数を測定します。単一の取得でプライマリデータとセカンダリデータを含む `master_payload` を返します。

- **🎛️ 任意関数ジェネレーター**
  SDG ハードウェアに信号を送信したり、出力をシミュレートしたりします。変調（AM/FM/PM）、線形/対数スイープ、バースト、および位相を設定します。

- **📊 デジタルマルチメーター (DMM)** *(拡張中)*
  DC/AC 電圧、電流、レジスタンス、および周波数測定のための SCPI インターフェースです。Keithley、Agilent、Rigol と互換性があります。

- **🔋 プログラマブル電源** *(拡張中)*
  OVP/OCP 保護付きの出力電圧/電流制御です。自動化されたテストベンチに便利です。

</div>

## 🔄 典型的なワークフロー

1. **ノードを追加する**：ツールバー（`ソース` または `機器`）からキャンバスに追加します。
2. **接続を構成する**：ックエンドを選択し、VISA 文字列を入力し、タイムアウト/初期化を調整します。
3. **フローに接続する**：機器の出力を処理ノード（FFT、フィルター、算術）または可視化にリンクします。
4. **実行 (`F5`)**：トロジカルエンジンが取得を要求し、ドライバーが SCPI 応答を解析してデータをパッケージ化します。
5. **可視化/エクスポート**：データはグラフを流れ、後続のノードによって処理されます。

## 🛠️ トラブルシューティング

!!! warning "1. VISA が機器を見つけられない (`VI_ERROR_RSRC_NFOUND`)"
    - **原因：** 文字列が正しくない、ケーブルが切断されている、またはバックエンドがデバイスを検出していない。
    - **解決策：** `pyvisa-shell` またはメーカーのユーティリティ（NI MAX、Keysight Connection Expert）を実行して、有効なリソースを一覧表示します。ユーザー権限を確認してください。

!!! warning "2. 取得中のタイムアウト"
    - **原因：** スープが遅い、トリガーが満たされていない、または機器が他のタスクでビジー状態。
    - **解決策：** ノードでタイムアウトを増やしてください。オシロスコープのトリガーが正しく構成されていることを確認してください（`AUTO` または `NORMAL`）。起動時に `*CLS` を使用してください。

!!! warning "3. シミュレーションが応答しない、または失敗する"
    - **原因：** `PyVISA-py` がインストールさていないか、別のバックエンドと競合している。
    - **解決策：** `pip install pyvisa-py`。ノードで、バックエンドとして明示的に `@py` を選択してください。

!!! warning "4. SCPI エラー (`Command Error`, `Execution Error`)"
    - **原因：** ファームウェアがコマンドをサポートしていないか、構文が正しくない。
    - **解決策：** お使いの機器の SCPI プログラミングマニュアルを参照してください。一部のメーカーでは `:` プレフィックスや `
` 終端記号が必要です。FloWorks は自動的に `
` を追加しますが、ドライバーで終端記号を調整できます。

!!! info "5. サポートされていない機器のノードを作成する"
    - `BaseNode` を継承し、`instrument/` で `DeviceBase` パターンを使用してください。
    - `(x, y)` タプルまたは `master_payload` を返す `headless` ドライバーを実装してください。
    - [📘 ガイド：新しいノードを追加する](adding-a-new-node.md) に従って、ポート、シリアラゼーション、および i18n を登録してください。
