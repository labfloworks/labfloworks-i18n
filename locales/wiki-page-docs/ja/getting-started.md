# 🚀 FloWorks 入門

このガイドでは、ゼロから最初の信号処理フローが実行されるまでを案内します。FloWorks は、Python と PySide6 で構築された信号用フローダイアグラムアプリケーションで、実際のハードウェア（VISA/SCPI）、統合シミュレーション、高度なスクリプト作成、およびホット言語切り替えをサポートしています。

---

## 🌊 最初のサンプルフロー

簡単なフローを作成しましょう：正弦波信号を生成し、リアルタイムで可視化します。

1. **ノードを追加する**
   上部ツールバーで、`ソース` → `高度な信号ジェネレーター` を選択します。次に、`処理` から 例えば `スペクトル` を選択します。
2. **接続する**
   ジェネレーターの出力ポート（`右`）で `Ctrl+クリック` を行います。次に、オシロスコープの入力ポート（`左`）で `クリック` ます。または、出力ポートをクリックして（クリックを押したまま）次のノードの入力ポートまでドラッグします。
3. **構成（オプション）**
   ノードをクリックすると、左側のサイドパネルに選択したノードのパラメータを持つエディタが表示され、動作条件を調整できます。下部には、ノードによって生成または取得されたデータを視覚的に表す可視化プロットがあります。
4. **実行する**
   `F5` またはツールバーの ▶ ボタンを押します。トポロジカルエンジンが実行順序を計算し、データを処理し、グラフパネルに波形が表示されます。コネクタがアニメーションし、アクティブなフローを示します！

## 🧠 ポートを理解する：色別カテゴリ

FloWorks では、各ポートは色で識別される**機能カテゴリ**に属します。有効な接続は**常に同じ色のポート間で行われます**：あるカテゴリの出力は、同じカテゴリの入力のみに接続されます。さらに、接線は自動的に接続するポートの色を採用し、視覚的な判読を容易にします。

| タイプ | 色 | 目的 | 典型的な例 |
|------|-------|-----------|----------------|
| `control` | 白  | 制御フロー / アクティベーション。 | 取得ノードへの開始信号。 |
| `exec` | グレー | 操作またはステップの実行。 | 関数またはコールバックのトリガー。 |
| `data` | 緑  | 汎用データ / 数値信号。 | ジェネレーターまたはセンサーの出力。 |
| `int` | 青  | 整数。 | インデックス、バッファサイズ、ID。 |
| `float` | シアン  | 浮動小数点数。 | 振幅、周波数、しきい値。 |
| `string` | 紫  | テキスト文字列。 | ファイル名、ラベル。 |
| `bool` | ピンク  | ブール値（`True`/`False`）。 | 状態フラグ、有効化。 |
| `array` | 濃い青  | 配列 / ベクトル。 | マルチチャンネル信号、サンプルリスト。 |
| `trigger` | オレンジ  | トリガー / 離散イベント。 | 同期パルス、エッジ。 |

**黄金律：**

- **まったく同じ色**のポートのみが接続されます（出力 ↔ 同じカテゴリの入力）。
- システムは無効な接続を防ぎ、ドラッグ中に互換性のあるポートを視覚的にハイライト表示します。
- 接続線は接続されたポートの色を取ります。これにより、各経路が一目で識別できます。

**FloWorks の理念：**
データポートは配列の**次元性を保持**します。自動的な平坦化は決して適用されません：行列が入れば行列が出て、多次元信号の整合性が維持されます。

## 🖱️ キャンバスのナビゲーション

以下のジェスチャーでワークスペースをマスターしましょう：

| アクション | 操作方法 |
|--------|--------------|
| **ズーム** | マウスホイールまたは `Ctrl + ホイール` |
| **パン（スクロール）** | `スペース` を押しながらドラッグ、またはマウス中ボタンを使用 |
| **ノードを選択** | ノード上で左クリック |
| **複数選択** | 左クリックで矩形をドラッグ、たは複数のノードで `Ctrl + クリック` |
| **選択を移動** | 選択したノードのいずれかをドラッグ |
| **構成を開く** | ノードをダブルクリック |

**ヒント：** 左パネルは、選択したノードの構成で自動的に更新され、追加のウィンドウを開く必要がありません。

## ⚡ キーボードショートカットと高度な操作

これらのショートカットで、通常のユーザーが**パワーユーザー**に変わります

| ショートカット | アクション |
|-------|--------|
| `F5` | フローを実行 |
| `Ctrl + S` | プロジェクトを保存（`.sflow`） |
| `Ctrl + クリック` | ノードを接続（出力ポートをクリック → 入力ポートをクリック） |
| `Ctrl + C` / `Ctrl + V` | 選択したノードをコピー / 貼り付け |
| `Ctrl + Z` / `Ctrl + Y` | 元に戻す / やり直し |
| `Ctrl + Shift + L` | キャンバス上のノードを自動整理 |
| `Del` | 選択したノードを削除 |
| `Ctrl + A` | すべてのノードを選択 |

**高度な操作：**

- **フローを複製：** ノードグループを選択し、`Ctrl + C`、`Ctrl + V` で別の領域にコピーをドラッグします。
- **グリッドを整理：** `Ctrl + Shift + L` を使用して、1 つのコマンドでキャンバス全体を整頓します。
- **クイック接続：** 出力ポートで `Ctrl + クリック`、次に入力ポートで通常クリック；FloWorks が自動的に接続を描画します。

## 🎨 環境のカスタマイズ

FloWorks はあなたに適応します。その逆ではありません。

### ホットテーマ切り替え
上部バーの**表示 → テーマ**メニューから、ライト、ダーク、またはその他を選択します。インターフェースは**即座に**変更され、再起動やワークフローの損失はありません。

### フォントサイズ
**表示 → フォントサイズ**で、プリセット値またはカスタム値を選択します。インターフェース全体が即座に調整されます。

### 言語
**表示 → 言語**で希望の言語を選択します。FloWorks は**ホット切り替え**をサポートします：メニュー、ボタン、メッセージがアプリケーションを再起動せずに翻訳されます。

## ❗ 一般的な問題のトラブルシューティング

| 問題 | 考えられる原因 | 解決策 |
|----------|---------------|----------|
| フローが実行されない | 未設定のノードや切断された接続がある | すべてのノードが有効なパラメータを持ち、接続が互換性のあるポート間にあることを確認してください |
| グラフが更新されない | フローが一時停止中、またはデータが流れていない | `F5` または ▶ を押し、ソースノードがデータを生成していることを確認してください |
| 2 つのノードを接続できない | ポートのタイプが異なる | 両方のポートが**データ**であるか、両方が**制御**であることを確認してください |
| 大きなフローでプログラムが遅くなる | ノードやリアルタイムグラフが多すぎる | 未使用の分析パネルを閉じるか、ソースノードのサンプリング周波数を下げてください |
| テーマが変更されない | 一部のウィジェットが登録されていない可能性がある | アプリケーションを再起動して再試行してください（将来のバージョンで解決予定） |

## 🧪 クイック実践例

最初の正弦波フローに加えて、FloWorks をマスターするためにこれらのミニプロジェクトを試してください：

| 例 | 関与するノード | 期待される結果 |
|---------|-------------------|--------------------|
| **ローパスフィルタ** | ジェネレーター → フィルター → グラフビューア | フィルタリングされた信号が表示されます |
| **シミュレートされた取得** | ジェネレーター → THD アナライザー | 信号の THD 値 |
| **手動制御** | ジェネレーター → データインスペクター | ジェネレーターが送信した信号値のテーブル |
| **信号比較** | 2 つのジェネレーター → アダー → グラフビューア | 2 つの波形の演算結（加算、減算、乗算、または除算）が 1 つのグラフに表示されます |

これらのフローはそれぞれ 1 分以内に組み立てることができ、従来のコードに比べた FloWorks の俊敏性を実証します。

!!! warning "互換性と使用に関する注意"
    1. **Python バージョン：** 3.9+ および 64 ビットシステムを使用できます。
    2. **Windows ファイアウォール：** 実際のハードウェア（VISA/SCPI オシロスコープ）を使用する場合は、ファイアウォールで `FloWorks.exe` を許可してください。接続がブロックされると、アプリはカスタムダイアログを表示します（`--windowed` モードでは OS ダイアログは表示されません）。
    3. **主要ショートカット：** `F5`（実行）、`Ctrl+S`（`.sflow` を保存）、`Ctrl+クリック`（接続）、`スペース+クリック`（フリーパン）、`Ctrl+Shift+L`（自動レイアウト）。
    4. **データ保持：** エンジンは配列に対して `flatten()` を**決して**適用しません。ベクトル化が必要な場合は、ローカルコピーを使用してください。
