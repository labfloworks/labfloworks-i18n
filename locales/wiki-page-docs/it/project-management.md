# 📁 Gestione dei progetti

FloWorks salva i tuoi flussi in file con estensione **`.sflow`**. Questi file contengono tutte le informazioni del progetto: nodi, connessioni, configurazione e note adesive.

---

## Creare, aprire e salvare

| Azione | Menu | Scorciatoia |
|--------|------|-------|
| **Nuovo progetto** | File → Nuovo | `Ctrl + N` |
| **Apri progetto** | File → Apri | `Ctrl + O` |
| **Salva** | File → Salva | `Ctrl + S` |
| **Salva con nome…** | File → Salva con nome… | `Ctrl + Shift + S` |

**Regola d'oro:**
I flussi sono **completamente compatibili con tutte le versioni** di FloWorks (Core, Lite, Pro). Non è necessario convertire o modificare nulla: basta aprire ed eseguire.

---

## Esportazione e importazione

- Per **condividere un flusso**, copia il file `.sflow` su un altro dispositivo.
- Per **importare un flusso esterno**, usa **File → Apri** e seleziona il file.
- Se hai bisogno di **esportare dati numerici** (ad esempio in CSV), utilizza lo strumento **Foglio di calcolo** nel pannello laterale e salva la tabella da lì.

---

## Recupero in caso di chiusure impreviste

FloWorks **non salva automaticamente**. Per questo è importante:

- Salvare frequentemente (`Ctrl + S`), specialmente prima di eseguire flussi con hardware reale.
- Se l'applicazione si chiude inaspettatamente, le modifiche non salvate potrebbero andare perse.
- Per lavorare con tranquillità, abituati a salvare dopo ogni modifica importante.

---

## Organizzazione consigliata

- Crea una cartella per ogni progetto o cliente e salva lì tutti i file `.sflow` correlati.
- Usa **note adesive** sulla tela per documentare le sezioni del flusso.
- Assegna **nomi descrittivi ai nodi** (doppio clic → nome) per trovare e capire il flusso anche settimane dopo.

---

## Buone pratiche

- Prima di eseguire un flusso con strumenti reali, salva il file.
- Se lavori in team, usa un sistema di controllo versioni (Git, copie manuali) per non sovrascrivere flussi importanti.
- Fai copie di sicurezza dei flussi di calibrazione o diagnostica critici.

---

> **Consiglio:** Un flusso ben organizzato e salvato è la base di un lavoro professionale in FloWorks. Non sottovalutare il potere di un nome chiaro e di una cartella ordinata.
